# 📐 04-发展规划要点与系统架构

> **本节结构**：基本过程(需总构径) → 6大规划要点(战则愿融设保) → 7大架构体系(业数应技安标产)

## 18.3 发展规划要点

### 规划基本过程

> **口诀**：**需总构径**（需求分析 → 总体设计 → 架构设计 → 实施路径设计）

```
需求分析 → 总体设计 → 架构设计 → 实施路径设计
   │           │           │            │
   ▼           ▼           ▼            ▼
城市战略   指导思想与   总体架构     主要任务和
与目标分析  基本原则                 重点工程
城市现状
调研分析
智慧城市                          保障措施
现状评估
```

### 18.3.1 承接城市战略

智慧城市发展规划 = 专项规划，承接上位规划（五年规划/区域规划）。

核心逻辑：
```
城市战略（全局性/长期性）
  → 智慧城市战略框架+定位+举措
    → 指导思想（宏观效果）+ 战略路径（中观机制）
      → 数字政府+数字社会+数字经济+数字基础设施
```

### 18.3.2 确立规划原则

> **口诀**：**人能构新建**（以人为本/技术赋能/规则重构/多元创新/多方共建）

| 原则 | 核心内涵 |
|------|---------|
| **以人为本** | 用户画像→主动服务+全生命周期精准服务+综合聚类服务 |
| **技术赋能** | 新一代ICT+城市数字底座→场景化解决方案激活数据价值 |
| **规则重构** | 体制机制优化+规则创新→数据有效流动化解不确定性 |
| **多元创新** | 业务/产品/场景/商业模式创新→治理/产业/民生整体转变 |
| **多方共建** | 政府引导+市场主导+全社会参与→共建共治共享 |

### 18.3.3 明确目标愿景

> **口诀**：**段量近远接标**（阶段/可衡量/近期为主/中远期展望/衔接战略/指标体系）

| 要求 | 说明 |
|------|------|
| **阶段划分** | 各阶段主要任务、建设内容、建设成果 |
| **可衡量** | 明确性+可衡量性+可达成性+明确时限 |
| **近期为准** | 规划期完成后政务/经济/社会/文化/生态文明成效 |
| **中远期展望** | 较总体目标更为宏观 |
| **衔接战略** | 与城市战略及指导思想匹配 |
| **指标体系** | 定性+定量+约束性+预期性指标 |

### 18.3.4 业务与技术融合规划

> **口诀**：**政社经** — 数字政府 + 数字社会 + 数字经济

#### 数字政府规划：三网合一（★★★★★ 必考）

| 三网 | 聚焦 | 关键词 | 对象 |
|------|------|--------|------|
| **一网协同** | 机关内部办公/办会/办事 | 统一门户、“一件事”集成改革 | 政府内部 |
| **一网统管** | 城市治理/社会治理 | 精细化呈现+智能化分析+精准化预警 | 政府→社会 |
| **一网通办** | 城市综合服务 | 一站式服务体验、渠道资源融合 | 政府→市民/企业 |

#### 数字社会规划

| 领域 | 聚焦方向 |
|------|---------|
| 公共服务 | 普惠化进程 |
| 教育 | 教育数字化战略 |
| 医疗 | 数字健康+互联网诊疗 |
| 社会治理 | 精准化 |
| 数字乡村 | 赋能乡村产业/建设/治理 |
| 便民服务 | 智慧便民生活圈+新型数字消费 |

#### 数字经济规划

| 三大板块 | 内容 |
|----------|------|
| **数字产业化** | 区域定位→产业战略→发展策略→重点项目→实施路径 |
| **产业数字化** | 产业互联网→农业/制造业/服务业升级→数字化转型三步骤 |
| **数据要素市场化** | 技术研发+交易平台+管理配置机制+监测评价体系 |

### 18.3.5 数字基础设施规划

| 三类基础设施 | 内容 |
|-------------|------|
| **信息基础设施** | 云（政务云/行业云/公有云）、网（政务外网/专网/互联网/物联网/算力网）、数（一体化数据资源体系）、智（数字孪生/时空地理/物联感知/AI平台）、安（安全体系+商用密码）、端（摄像头/传感器） |
| **融合基础设施** | 传统基建智能化改造：工业互联网/智慧交通/智慧能源/智慧灯杆等 |
| **创新基础设施** | 国家实验室/前沿科学平台/企业技术中心等公益属性设施 |

> 📌 **信息基础设施口诀**：**云网数智安端**（6要素）

### 18.3.6 组织与保障体系规划

> **总口诀**：**织市才安**（组织体系/市场化生态/人才队伍/信息安全）

#### 组织体系注意事项 → **外贯责融**

| 注意事项 | 说明 |
|----------|------|
| **外** | 不要忽略主体组织外的其他组织与群体 |
| **贯** | 避免职责未有效宣贯 |
| **责** | 责任到人，基于组织架构实现 |
| **融** | 各类角色职责一体化融合 |

#### 市场化生态注意事项 → **容掘产新机**

| 注意事项 | 说明 |
|----------|------|
| **容** | 作为一项工作内容 |
| **掘** | 挖掘经济新模式/市场新业态 |
| **产** | 考虑信息技术产业发展基础 |
| **新** | 覆盖模式革新/技术创新/管理创新 |
| **机** | 明确创新机制/措施/模式 |

#### 人才保障注意事项 → **容能军融社**

| 注意事项 | 说明 |
|----------|------|
| **容** | 人才体系与人才容量的有效性 |
| **能** | 业务人员数字能力（意识/素养/技能） |
| **军** | 领军/标杆创新人才打造 |
| **融** | ICT人才业务认知与融合创新能力 |
| **社** | 社会化智慧城市人才建设 |

#### 信息安全注意事项 → **责析端具审**

| 注意事项 | 说明 |
|----------|------|
| **责** | 全面落实信息安全责任制 |
| **析** | 系统分析安全体系完整性和有效性 |
| **端** | 终端安全(IoT/ICT)提高到新高度 |
| **具** | 确保安全工具有效性（病毒库/威胁情报） |
| **审** | 强化网络行为审计和运维审计 |

## 18.4 系统架构

> **总口诀**：**业数应技安标产** — 7大架构体系

```
         ┌──────────────────────────┐
         │      安全体系+标准体系     │
         │  ┌────────────────────┐  │
         │  │   业务架构（顶）     │  │
         │  │   ↕               │  │
         │  │   应用架构          │  │
         │  │   ↕               │  │
         │  │   数据架构          │  │
         │  │   ↕               │  │
         │  │   技术架构（底）     │  │
         │  └────────────────────┘  │
         │      产业体系（生态）     │
         └──────────────────────────┘
```

### 18.4.1 业务架构
- 以业务为核心，识别核心业务场景
- 四大领域（民生服务/城市治理/产业发展/生态宜居）+ 区域协同
- L1-L3三层业务架构梳理

### 18.4.2 应用架构（5要点）
1. 梳理城市应用系统（新建/改造/利旧）
2. 识别可重用/共用系统模块
3. 设计重点信息系统功能（业务/功能/责任主体/服务对象）
4. 设计跨部门信息系统功能
5. 设计系统间数据交互关系

### 18.4.3 数据架构
- 总体数据模型（基础库/主题库/专题库）
- 数据分布（政府/社会/物联网/外部数据）
- 数据服务（交换共享/开发开放/交易）

### 18.4.4 技术架构（4层）
| 层级 | 内容 |
|------|------|
| **感知层** | 物联感知+视频监控（交通/生态/水务/气象） |
| **数据层** | 汇聚→清洗→分析→共享交换 |
| **平台层** | 共性平台：业务平台+技术平台（统筹集约） |
| **应用层/展示层** | 面向用户的业务系统 |

### 18.4.5 安全体系+标准体系+产业体系

| 体系 | 要点 |
|------|------|
| **安全体系** | 规则（规章制度）+ 技术（GB/T 34678-2017安全防护）+ 管理（组织/制度/措施） |
| **标准体系** | 基础性标准+支撑技术/平台+基础设施+建设宜居+管理服务+产业经济+安全保障 |
| **产业体系** | 基础设施服务商→系统集成商→公共服务平台→专业创新应用商→行业解决方案商 |
