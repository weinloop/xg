# 03 · IT治理任务与方法标准（教材11.1.3—11.1.4）

> 治理体系搭好了，接下来做什么？用五大任务驱动治理活动，用三套标准规范治理行为。

---

## 11.1.3 IT治理任务

IT治理活动定义为四个动作：**统筹、评估、指导、监督**。围绕这四个动作，教材提炼出五大主要任务：

---

### 五大任务详解

| 任务 | 核心要点 | 华航故事 |
|------|------|------|
| **全局统筹** | ①制定可持续IT蓝图；②实施科学决策、集约管理；③建立持续改进和创新机制 | 2024年9月，我在首次数据治理委员会会议上提交了《华航数据治理三年蓝图》，规划了2024基础建设→2025深化应用→2026智能运营三阶段路线 |
| **价值导向** | ①建立IT投资价值框架；②建立价值递送规则；③对关键指标进行设定和监督；④权衡实施成本与预期效益 | 2025年1月评审会上，货运数据前移方案需要追加25万投入，我展示了该方案支撑的「货运仓容动态调配」带来的预期收益（180万/年），获得委员会一致通过 |
| **机制保障** | ①指导规范过程管理和痕迹管理；②评审管理体系适宜性/充分性/有效性；③审计完整性/有效性/合规性；④监督改进内容的实施 | 2024年12月，我发现变更管理流程缺失审批记录。立即建立了变更管理电子流，所有变更必须经过「提交→技术评审→业务评审→委员会审批」四环节 |
| **创新发展** | ①创造技术创新的环境；②确保技术发展/管理创新/模式革新的协调联动；③对创新能力评估并分析关键创新要素；④使创新成为组织文化 | 2025年4月，我们引入AI辅助数据质量检测，将人工审核5000条规则的时间从天级压缩到小时级。这个创新被数据管理办公室推广到所有区域中心 |
| **文化助推** | ①建立与IT发展相适应的文化策略；②营造积极向上的文化氛围；③评估改进文化管理 | 2025年3月，我策划了「数据质量之星」月度评比，将数据质量意识从「被动合规」转变为「主动改善」。三个月后，17个部门主动提交了数据质量改进方案 |

**速记口诀：统价机创文**

> 🎯 **考点提示**：案例题最可能问「IT治理活动的主要任务有哪些？」——全局**统**筹、价**值**导向、**机**制保障、**创**新发展、**文**化助推。

---

### 五大任务的深层关系

```
全局统筹（定方向）
    ↓
价值导向（定目标）→ 机制保障（定规则）
    ↓                    ↓
创新发展（求突破）    文化助推（造氛围）
```

## 11.1.4 IT治理方法与标准

### 三套标准总览

| 标准 | 发布机构 | 定位 | 核心内容 |
|------|------|------|------|
| **ITSS（GB/T 34960）** | 中国 | 我国IT治理国家标准 | 通用要求(34960.1) + 实施指南(34960.2) |
| **COBIT** | ISACA | 国际IT治理框架 | EDM/APO/BAI/DSS/MEA五域 + 7组件 |
| **ISO/IEC 38500** | ISO/IEC | IT治理国际标准 | 6项原则 + 评估/指导/监督三任务 |

---

### 一、ITSS — GB/T 34960 系列

#### GB/T 34960.1《通用要求》

**IT治理模型**：治理主体（以组织章程、监管职责、利益相关方期望、业务压力为驱动力）→ 建立评估/指导/监督的治理过程 → 指导管理者完善管理体系 → 对方案和规划进行评估 → 对绩效和符合性进行监督。

**IT治理框架三大治理域**：

| 治理域 | 包含内容 |
|------|------|
| **顶层设计** | 战略、组织、架构 |
| **管理体系** | 质量管理、项目管理、投资管理、服务管理、业务连续性管理、信息安全管理、风险管理、供方管理、资产管理、其他管理 |
| **资源** | 基础设施、应用系统、数据 |

#### GB/T 34960.2《实施指南》

**实施过程四步**：统筹和规划 → 构建和运行 → 监督和评估 → 改进和优化

**速记口诀：统构建监督，四步实施**

#### 在华航的落地

华航项目以GB/T 34960.1的三大治理域为框架，以34960.2的四步实施过程为方法论：

| 实施步骤 | 时间 | 主要活动 |
|------|:---:|------|
| 统筹和规划 | 2024.07—09 | 现状调研、差距分析、制定治理蓝图 |
| 构建和运行 | 2024.10—2025.05 | 建立三层架构、发布治理制度、部署数据管家 |
| 监督和评估 | 2025.01—06 | 月度评审 + 年度IT审计 |
| 改进和优化 | 持续 | 基于评审和审计结果迭代优化 |

---

### 二、COBIT — 信息和技术治理框架

#### 核心模型：5大领域（40项治理和管理目标）

| 领域 | 全称 | 归属 | 核心职责 |
|:---:|------|:---:|------|
| **EDM** | 评估、指导和监控 | **治理** | 董事会/执行管理层评估战略方案、指导执行、监督实施 |
| **APO** | 调整、规划和组织 | **管理** | IT的整体组织、战略和支持活动 |
| **BAI** | 内部构建、外部采购和实施 | **管理** | IT解决方案的定义、采购、实施及流程整合 |
| **DSS** | 交付、服务和支持 | **管理** | IT服务的运营交付和支持，包括安全 |
| **MEA** | 监控、评价和评估 | **管理** | IT性能监控及其与目标/合规的一致程度 |

**速记口诀：EDM治理APO组织，BAI构建DSS交付，MEA监控五域全**

> 🎯 **考点提示**：这是全章最重要的考点之一！选择题喜欢这样出——「DSS属于治理领域还是管理领域？」（管理）；「EDM的职责是什么？」（评估/指导/监控）

#### COBIT治理系统组件（7个）

| 组件 | 说明 |
|------|------|
| **流程** | 一组为实现目标安排有序的实践和活动 |
| **组织结构** | 组织的主要决策实体 |
| **原则、政策和程序** | 将理想行为转化为日常管理的实用指南 |
| **信息** | 组织生成和使用的全部信息 |
| **文化、道德和行为** | 个人和组织的文化、道德和行为 |
| **人员、技能和胜任能力** | 做出正确决策、完成所有活动的关键 |
| **服务、基础设施和应用程序** | 为组织提供IT治理系统的基础设施和技术 |

**速记口诀：流组原信，文人服**

#### COBIT设计因素（11个）

组织战略 → 组织目标 → 风险概况 → IT相关问题 → 威胁环境 → 合规性要求 → IT角色 → IT采购模式 → IT实施方法 → 技术采用战略 → 组织规模 → 未来因素

#### COBIT设计流程（4步）

| 步骤 | 内容 |
|:---:|------|
| 1 | 了解组织环境和战略 |
| 2 | 确定治理系统的初步范围 |
| 3 | 优化治理系统的范围 |
| 4 | 最终确定治理系统的设计 |

---

### 三、ISO/IEC 38500 — IT治理国际标准

#### 6项指导原则

| 原则 | 说明 | 华航实践 |
|------|------|------|
| **责任** | 个人和团体理解并接受IT供应和需求方面的责任 | 每个区域数据管家签「数据质量责任状」 |
| **战略** | 业务战略考虑IT当前和未来能力 | 三年蓝图逐年更新，随业务战略调整 |
| **收购** | IT收购基于正当理由和透明决策 | 所有新增IT投入需经治理委员会审批 |
| **性能** | IT支持组织，提供满足需求的服务 | 5项绩效指标季度追踪 |
| **一致性** | IT使用符合强制性法律和法规 | 《网络安全法》《数据安全法》《个人信息保护法》合规 |
| **人的行为** | IT政策、实践和决策尊重人的行为 | 数据管家培训计划 + 职业发展通道 |

**速记口诀：责战收性，一行为**

#### 治理机构三任务：评估、指导、监督

| 任务 | 具体活动 |
|------|------|
| **评估** | 审查和判断当前和未来的IT使用，考虑内外部压力和技术变革 |
| **指导** | 负责战略和政策的编制和执行，建立良好的治理文化 |
| **监督** | 通过适当的测量系统监测IT表现，确保符合业务目标和外部义务 |

> 🎯 **考点提示**：ISO 38500的3个任务（评估/指导/监督）和IT治理活动的4个动作（统筹/评估/指导/监督）极易混淆！ISO是3个（没有「统筹」），IT治理活动是4个（多一个「统筹」）。

---

### 三套标准的在华航协同

华航项目不是只选一套标准，而是**三套协同**：

| 标准 | 在华航的角色 |
|------|------------|
| **COBIT** | 治理框架的「骨架」——五域划分治理和管理活动 |
| **ITSS 34960** | 实施落地的「路径」——通用要求定架构 + 实施指南定步骤 |
| **ISO 38500** | 国际对标的「标尺」——6项原则检验治理是否合规 |

> 💡 **论文素材**：「我们以COBIT 2019为框架骨架，以ITSS GB/T 34960为实施路径，以ISO/IEC 38500为对标标尺，构建了三位一体的IT治理标准体系。」
