## 项目核心数据速查（治理视角）

| 维度 | 数据 |
|------|------|
| 项目名称 | 华航集团数据资产智能管理平台 |
| 合同金额 | 580万元/年 |
| 服务期 | 14个月（含3个月试运行） |
| 治理架构 | 数据治理委员会（最高管理层）→ 数据管理办公室（执行管理层）→ 数据管家+运维团队（业务执行层） |
| 治理标准 | COBIT 2019 + ITSS（GB/T 34960）+ ISO/IEC 38500 |
| 治理机制 | 季度例会 + 月度评审 + 年度IT审计 + 5项绩效指标 |
| IT审计范围 | 120+套系统、50PB数据、29个节点 |
