# 02 · IT治理基础与体系实践（教材11.1.1—11.1.2）

> IT治理是什么？为什么要做？怎么搭建体系？前两个小节覆盖了IT治理的一半考点。

---

## 11.1.1 IT治理基础

### 一、IT治理的定义

IT治理是描述组织采用有效的机制对信息技术和数据资源开发利用，平衡信息化发展和数字化转型过程中的风险，确保实现组织的战略目标的过程。

> 💡 核心关键词：**有效机制 + 平衡风险 + 实现战略目标**

| 维度 | 教材定义拆解 | 华航项目对应 |
|------|------------|------------|
| 有效机制 | 三层治理架构 + 6项治理机制 | 数据治理委员会/管理办公室/数据管家 |
| 开发利用 | IT和数据资源 | 10万级资产目录、5000条规则 |
| 平衡风险 | 安全与效率的权衡 | 等保三级 + 四级数据分级 |
| 战略目标 | 与业务目标对齐 | 数据资产化→数据服务化→数据价值化 |

---

### 二、IT治理的驱动因素（8条）

| # | 驱动因素 | 在华航项目的体现 |
|:---:|------|------|
| ① | 确保IT投资的有效性 | 580万年预算，季度治理委员会审查投资回报 |
| ② | IT属于知识密集型领域 | 数据治理需要复合型人才（技术+业务+管理） |
| ③ | IT已融入组织各领域 | 120+套系统覆盖运行、管理、生产、交付全链条 |
| ④ | 新兴技术提供发展空间 | AI辅助决策模块引入大模型技术 |
| ⑤ | 推动充分理解IT价值 | 从「数据管理」到「数据资产」认知转变 |
| ⑥ | IT价值=好技术+价值管理+场景融合 | 血缘图谱+质量管理+业务场景化应用 |
| ⑦ | 高级管理层管理幅度有限 | 三层架构让每层聚焦自身职责 |
| ⑧ | 成熟度高的组织治理方式不同 | 华航从一级架构进化到三层，对标行业领先实践 |

**速记口诀：投密融演进，价值场景高成熟**

> 🎯 **考点提示**：8条驱动因素最容易出多选题——「以下哪些是高质量IT治理的驱动因素？」选5选6都有可能，必须记住全部8条。

### 三、IT治理的内涵（5个方面）

| # | 内涵 | 在华航项目的体现 |
|:---:|------|------|
| ① | 作为组织上层管理的有机组成部分 | 数据治理委员会由集团CIO挂帅 |
| ② | 数字目标与组织战略目标一致 | 数据资产化战略对齐华航数字化转型目标 |
| ③ | 保护利益相关者权益 | 5大区域IT负责人均有投票权 |
| ④ | 是一种制度和机制 | 《数据治理章程》+《标准管理办法》+6项机制 |
| ⑤ | 组成部分包括管理层、组织结构、制度、流程、人员、技术 | 三层+6机制+5绩效指标 |

**速记口诀：上层全局、战略一致、利益风险、制度机制、多面架构**

> 🎯 **考点提示**：5大内涵常与IT治理核心内容6方面混淆出题——内涵回答「IT治理是什么」，核心内容回答「IT治理管什么」。

### 四、IT治理的主要目标（3个）

| 目标 | 教材定义 | 华航故事 |
|------|---------|------|
| **与业务目标一致** | 从组织目标和数字战略中抽取需求 | 2024年7月，我带领团队访谈了华航12个核心业务部门，梳理出数据标准不统一、资产目录缺失、跨系统查询困难等7大痛点，将其转化为IT治理需求 |
| **有效利用信息与数据资源** | 保证投资回收，支持决策 | 2025年3月治理委员会上，我展示了数据资产目录支撑的3个典型业务决策案例——航线优化（节省燃油费120万）、货运仓容动态调配（提升利用率18%） |
| **风险管理** | 制定保护机制，实施有效监控 | 数据安全分类分级（4级）+ 访问控制矩阵 + 操作审计日志，确保航空数据合规 |

**速记口诀：一致利用风险**

> 🎯 **考点提示**：案例题最可能问「IT治理的主要目标是什么？」——致（与业务一致）、用（有效利用资源）、险（风险管理）。

### 五、IT治理的管理层次（3层）

| 层次 | 教材职责 | 在华航的对应 |
|------|---------|------------|
| **最高管理层** | 证实IT战略与业务一致；指导IT战略；平衡投资；指导资源分配 | 数据治理委员会（集团CIO+信息中心主任+5区域IT负责人） |
| **执行管理层** | 制定IT目标；分析新技术机遇风险；建设关键过程与核心竞争力；分配责任、定义规程、衡量业绩；管理风险 | 数据管理办公室（项目经理+数据架构师+质量负责人） |
| **业务与服务执行层** | 信息数据服务的提供和支持；IT基础设施建设维护；IT需求的提出和响应 | 数据管家团队+运维团队+开发团队 |

**速记口诀：高证指分，执目新过责险，业服基建需求**

## 11.1.2 IT治理体系

### 一、IT治理体系构成（5项）

| 构成部分 | 说明 | 华航对应 |
|------|------|------|
| IT定位 | IT应用的期望行为与业务目标一致 | 「数据即资产」的战略定位 |
| IT治理架构 | IT权责边界 | 三层治理架构 |
| IT治理内容 | 决策/投资/风险/绩效/管理 | 季度决策/年度预算/风险清单/5项绩效 |
| IT治理流程 | 统筹/评估/指导/监督 | 季度例会统筹、月度评审评估、年度审计监督 |
| IT治理效果 | 内外评价 | 5项指标+客户满意度 |

**速记口诀：定位架构内容，流程效果五维**

---

### 二、IT治理关键决策（5项）

| 关键决策 | 回答的核心问题 | 华航故事 |
|------|------|------|
| **IT原则** | IT的角色是什么？期望行为是什么？ | 2024年8月，治理委员会确定了华航IT三大原则：数据集中管理、标准统一制定、安全分级管控 |
| **IT架构** | 核心业务流程？数据如何整合？ | 湖仓一体架构，统一数据接入标准，打通120+系统 |
| **IT基础设施** | 哪些基础设施最关键？服务水平？ | 29节点混合云，99.99%可用性，50PB存储 |
| **业务应用需求** | 新业务机会？何时从例外转为标准？ | 2025年1月，货运数据前移需求从临时需求升级为标准数据接入流程 |
| **IT投资和优先顺序** | 投资组合分配？与战略一致？ | 580万分解为：平台建设40% + 数据治理30% + 运维20% + 创新10% |

> 💡 **决策链逻辑**：IT原则驱动IT架构 → 架构决定基础设施 → 基础设施能力决定业务应用 → 投资和优先顺序为前四者驱动。

**速记口诀：原架基需投，五决驱动链**

---

### 三、IT治理体系框架（6部分）

| 组成部分 | 说明 |
|------|------|
| **IT战略目标** | 为实现IT价值和目标，使组织从IT投入获得最大收益 |
| **IT治理组织** | 界定治理范围、责权划分及相互关系 |
| **IT治理机制** | 决策机制、执行机制、风险控制机制、协调机制的综合体 |
| **IT治理域** | 在IT治理规则下，对组织IT资源进行整合与配置 |
| **IT治理标准** | 包括基本规范、实施参照、评价体系和审计方法 |
| **IT绩效目标** | 关注IT价值实现，评价IT规划与构建是否满足业务需求 |

**构成闭环**：战略目标（定方向）→ 治理组织（定权责）→ 治理机制（定规则）→ 治理域（定范围）→ 治理标准（定标尺）→ 绩效目标（定验收）

**速记口诀：标组机域准绩，六部闭环**

> 🎯 **考点提示**：这6部分容易和「IT治理核心内容6方面」（组战资价风绩）混淆。框架6部分是「治理体系的构成部件」，核心内容6方面是「治理要管的事情」。

---

### 四、IT治理核心内容（6个方面）

| 核心内容 | 说明 | 华航故事 |
|------|------|------|
| **组织职责** | 明确信息部门和业务部门关系责任 | 数据管家归属数据管理办公室，但虚线向业务部门汇报 |
| **战略匹配** | IT建设与组织战略相匹配 | 每个季度治理委员会检查IT项目是否仍然对齐华航数字化转型方向 |
| **资源管理** | 优化IT投资和资源分配 | 2025年3月，通过对各区域数据管家工作量的分析，重新调整了5大区域的人员配比 |
| **价值交付** | 全生命周期确保IT实现预期业务价值 | 2024年12月，数据资产目录1.0上线后3个月内，支撑了17个业务决策 |
| **风险管理** | 确保IT资产安全、灾难恢复 | 等保三级 + 业务熔断限流 + 两地三中心灾备 |
| **绩效管理** | 追踪和监视战略/项目/资源/服务绩效 | 5项绩效指标月度跟踪，季度向委员会汇报 |

> 💡 **论文素材**：**价值交付是创造业务价值，风险管理是保护业务价值**——这句话可以直接用在论文中。

**速记口诀：组战资价风绩**

### 五、IT治理机制经验

**三原则：简单、透明、适合**

| 原则 | 含义 | 华航故事 |
|------|------|------|
| **简单** | 明确定义责任和目标 | 每层架构职责清单化，三级各管各的事 |
| **透明** | 正式程序可见 | 所有标准变更需经月度评审并公示 |
| **适合** | 鼓励最佳位置的人决策 | 数据标准由最懂业务的数据管家提出，而非远程的架构师 |

**7条最佳实践：**
1. IT指导委员会吸纳业务经理
2. 谨慎管理IT架构和业务架构
3. 设计严格的架构例外处理流程
4. 建立集中化IT团队
5. 连接IT投资和业务需求的流程
6. 集中协作和核准的IT投资流程
7. 费用分摊和服务水平协议机制

> 🎯 **考点提示**：10种影响力高的治理机制（表11-2）可能出选择题——识别哪些属于「期望行为」、哪些属于「不期望行为」。
