# 22.4-22.5 发展规划要点与信息系统架构

---

## 第一部分：发展规划要点（22.4）

### 一、四大规划原则 ★★★

| 原则 | 核心要求 |
|------|---------|
| **需求驱动** | 针对企业实际生产/管理/经营需求制定，不盲目上马 |
| **投入产出** | 抓关键环节，紧紧围绕提高核心竞争力 |
| **有效性** | 正确性（匹配内外部环境）+ 可行性（匹配企业转型战略）；回答「做什么/能做什么/怎么做」 |
| **全局性** | 从战略目标出发，高层次、全局性分析，有序引导 |

---

### 二、四大规划活动要点 ★★★★★（诊衡破才）

#### 2.1 诊断评估

> 参考CMMM的20个能力子域，从低到高逐级演进，直到找到企业当前所处的成熟度水平。

**三大深度融合特征**：
- 管理与生产过程深度融合
- 信息技术与工业技术深度融合
- 数据应用与制造模式转型深度融合

**诊断评估调研内容示例**（以生产作业/三级为例）：

| 调研内容 | 诊断评估细项 |
|---------|------------|
| 工艺文件管理 | 信息化管理平台情况 |
| 工艺文件下发 | 与生产作业计划同步一致性 |
| 版本控制 | 确保使用最新版本 |
| 下发设备 | 生产单元终端设备 |
| 动态数据监测 | 计划完成情况实时获取 |
| 生产资源 | 重点关注的资源类型 |
| 设备状态 | 动态监测占比 |
| 稼动率统计 | 异常时间分析与优化部门 |

#### 2.2 均衡部署

> **核心逻辑**：优先建设「短板」→ 如无法短期解决 → 「裁剪」（外包）或「避让」（与集团协商）

**目标设定方式**：
- 短期目标 = 企业「最长板」水平
- 中长期目标 = 「最长板」+ 1个等级
- 切忌：超过企业可及的「最高等级」

**系统建设策略**：
- ❌ 不要全模块建设（如首次MES就上全部功能）
- ❌ 不要以部署系统作为分期依据（如MES一期、工艺平台二期）
- ✅ 采用细化模块分期（如MES基础模块 + 同期开展CAPP功能建设）

#### 2.3 重点突破

> 每次企业升级的突破点保持一致（如同企业基因），不建议通过规划强行改变。

| 突破驱动方式 | 含义 | 典型表现 |
|------------|------|---------|
| **技术突破驱动** | 由技术突破引发整体提升 | 产品技术/工艺技术/IT技术突破 |
| **管理突破驱动** | 由管理突破引发提升 | 管理方法/水平/流程变革（注意：局部变化不够） |
| **模式突破驱动** | 由经营/生产模式突破引发 | 柔性生产新模式、数字营销新模式 |

> 规划中突破点部分可超出其他能力子域**最多一个等级**，在补齐短板后优先建设。

#### 2.4 人才保障

| 保障方面 | 要点 |
|---------|------|
| **统筹团队** | 技能覆盖各领域，与日常岗位融合 |
| **专业技术人员** | IT基础/数据分析/应用建设/编程调试/设备维护/系统维护；内部培养或第三方合作 |
| **培训体系** | 三化：组织体系化 + 课程体系化 + 内容体系化 |
| **知识体系** | 全员自我知识管理 + 知识管理制度保障贡献 → 数字化/软件化的知识技能经验 |
| **数字素养** | 面向问题的结构化思维 + ICT理解 + 数据开发利用 + 洞察解决问题的能力 |

### 三、四大规划管理要点 ★★★★（元知控践）

| 要点 | 核心内容 |
|------|---------|
| **多元参与** | 低成熟度→虚拟团队+最高负责人牵头；高成熟度→跨专业「军团」/「工作组」；可引入第三方但需知识传递 |
| **知识传递** | 利用规划活动交流，跨领域知识传播；外部力量通过培训/专题/头脑风暴导入 |
| **目标控制** | 总体目标避免空洞（如「世界一流」），用5年可达状态；分项目标「做一看一」；全员理解一致性宣贯 |
| **实践借鉴** | 四注意：①放大鉴小（场景/局部借鉴）②背景分析（促成因素）③创新借鉴（不照搬）④坚持自主（不迷恋） |

## 第二部分：信息系统架构（22.5）

### 一、总体架构：三维模型 ★★★★★

```
        生命周期维度（X轴）
      ┌──────────────────────┐
      │ 设计→生产→物流→销售→服务 │
      │                      │
      │    ┌──────────┐      │
系统  │    │ 智能特征  │      │
层级  │    │（Y轴）   │      │
(Z轴) │    └──────────┘      │
      │                      │
      └──────────────────────┘
```

| 维度 | 层级 | 内容 |
|------|------|------|
| **生命周期（X轴）** | 5阶段 | 设计→生产→物流→销售→服务 |
| **系统层级（Z轴）** | 5层 | 设备层→单元层→车间层→企业层→协同层 |
| **智能特征（Y轴）** | 5级 | 资源要素→互联互通→融合共享→系统集成→新兴业态 |

#### 系统层级五层详解

| 层级 | 定位 |
|------|------|
| **设备层** | 传感器/仪器仪表/机器/装置，实现物理流程感知与操控 |
| **单元层** | 工厂内处理信息、监测和控制物理流程 |
| **车间层** | 面向工厂/车间的生产管理 |
| **企业层** | 面向企业经营管理 |
| **协同层** | 企业内部和外部信息互联共享 |

#### 智能特征五级

| 等级 | 内涵 |
|------|------|
| **资源要素** | 生产所需资源/工具及其数字化模型 |
| **互联互通** | 有线/无线通信，装备间、装备与控制系统、企业间信息交换 |
| **融合共享** | 在互联互通基础上，云计算/大数据实现信息协同共享 |
| **系统集成** | 智能装备→智能生产单元→智能生产线→数字化车间→智能工厂 |
| **新兴业态** | 企业间价值链整合，形成新型产业形态 |

> 📌 三大集成方向：**纵向集成**（设备→协同五层）、**横向集成**（资源要素→新兴业态五级）、**端到端集成**（设计→服务五阶段）

---

### 二、集成架构：五层金字塔 ★★★★★

```
        ┌───────────────┐
        │   决策层       │ ← 大数据/驾驶舱/数字孪生/AI
        │  (数据驱动决策) │
        ├───────────────┤
        │   业务层       │ ← CRM/PLM/ERP（订单到交付）
        │  (流程管理)     │
        ├───────────────┤
        │   执行层       │ ← MES/MOM/WMS/QMS（生产透明）
        │  (生产执行)     │
        ├───────────────┤
        │   传输层       │ ← 工业互联网/物联网/IoT平台
        │  (数据通道)     │
        ├───────────────┤
        │   设备层       │ ← 自动化设备/检测设备/AGV/立体仓库
        │  (底层设施)     │
        └───────────────┘
```

| 层级 | 核心系统 | 功能定位 |
|------|---------|---------|
| **决策层** | 大数据平台、驾驶舱、数字孪生、AI | 数据驱动决策，提高运营和管理效率 |
| **业务层** | CRM、PLM、ERP | 业务和流程管理，订单到交付全链路数字化 |
| **执行层** | MES/MOM、WMS、QMS | 生产下发、数据上传、开工报工、全过程透明 |
| **传输层** | 工业互联网、物联网、IoT平台 | 打通设备层与执行层的数据通道 |
| **设备层** | 自动化设备、检测设备、AGV、立体仓库 | 智能制造底层基础设施 |

---

### 三、实施路径：全→通→智 ★★★★

```
第一阶段：由缺到全
  ├── 基本信息化系统全覆盖（ERP/MES/WMS等基础模块）
  ├── 设备自动化改造
  └── 对应CMMM 一→二级

第二阶段：由全到通
  ├── 系统间集成互通（ERP↔MES↔WMS）
  ├── 数据共享与协同
  └── 对应CMMM 三→四级

第三阶段：由通到智
  ├── 模型驱动预测与决策
  ├── 数字孪生、AI深度应用
  └── 对应CMMM 四→五级
```

#### 五年实施示例

| 年份 | 重点建设内容 |
|------|------------|
| 第1年 | 技术改造、设备自动化、业务信息化 |
| 第2年 | 设备预测性维护、设备三维化、能源动态优化 |
| 第3年 | 智能物流、生产仿真化、数字孪生平台 |
| 第4年 | 设计知识库、工艺知识库、生产知识库、APS智能排产 |
| 第5年 | 全面监控、自动决策、数据驱动、精准决策 |
