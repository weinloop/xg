# 04-规划要点与系统架构：「控图需案保才」+ 四大架构

> 📌 **本节对应教材 21.4 + 21.5** | 案例分析高频，六大要点必须能展开论述

## 一、21.4 规划要点全景 ←「控图需案保才」

```
规划要点（6个）
  ├── 管控规划活动：织宣标过程果
  ├── 定义数字化蓝图：远高抱势
  ├── 明确数字化需求：诊断评估 + 能力需求
  ├── 制定方案与路径：平台化 + 先易后难
  ├── 确保保障措施：文化量化动态
  └── 规划数字人才：类级阶 + 壁需续
```

## 二、21.4.1 管控规划活动 ←「织宣标过程果」

| 方面 | 核心内容 | 答题关键词 |
|------|----------|-----------|
| **组织** | 业务+技术矩阵式小组（如业财一体化小组）；"作战小队"攻克转型场景；引入外部专家 | "矩阵模式""一体化团队""外部专家" |
| **宣教** | 全员理解急迫性+紧迫性+必要性；融合HR与业务部门职能；注重"软技能"建设（发现问题与解决问题的方法） | "克服变革担忧""数字文化语言语境""场景感+现实感" |
| **目标** | 避免原则性替代时效性；量化到责任人（不只要责任部门）；指标相互关联映衬；考虑阶段性+可持续性 | "量化要求""指标体系""阶段性目标" |
| **过程** | 强调沟通的有效性/系统性/全面性；预设目标引导交流；伴随宣教活动 | "不同角度交流""预设目标路径价值" |
| **成果** | 最终成果+过程成果都重要；重视语言语境一致性检查 | "过程成果""语境一致性""避免定位差异" |

## 三、21.4.2 定义数字化蓝图 ←「远高抱势」

| 要点 | 核心内容 |
|------|----------|
| **目标长远** | 中长期10-15年定性目标；与企业发展目标相辅相成 |
| **战略高度** | 最高决策组织主导；覆盖全部业务活动；与信息化本质区别：数据要素引发治理结构根本变化 |
| **拥抱数字** | 覆盖理念调整/文化重塑/业务变革/管理优化/生产模式/服务效能；考虑短中长周期人才策略 |
| **顺势而为** | 不只是原则，也是蓝图组成内容；定义适应或引导内外部变化的能力+时间表 |

> **信息化 vs 数字化转型的本质区别**：信息化→生产结构变化（效率提升）；数字化→**治理结构**根本变化（无限组织扁平化可能）

## 四、21.4.3 明确数字化发展需求 ★★★★★（案例高频）

### 1. 诊断评估七步法 ←「域尺重调讨因级」

| 步骤 | 内容 |
|------|------|
| ① **域** | 确立能力域、能力子域、能力分项 |
| ② **尺** | 定义成熟度标尺（参考数字化转型/智能制造/IT运维等国家标准） |
| ③ **重** | 明确权重体系（结合发展导向+行业特点+标准实践） |
| ④ **调** | 编制调研表单/问题/计划→实施调研→量化评价 |
| ⑤ **讨** | 重点领域研讨活动（精准把握+知识宣教） |
| ⑥ **因** | 分析能力分布→明确长短板→洞察深层次原因 |
| ⑦ **级** | 逐项分析所处等级与高一级不满足情况→具体到标尺条款 |

### 2. 识别能力需求

```
诊断评估结果 → 设定短/中/长期成熟度目标
→ 逐项分析不足与提升空间
→ 从人/技/资/过/数五要素提出能力需求
→ 按能力要素主线合并整合
→ 基于组织架构拆分 → 分析可行性
→ 不可行→考虑整体环境变化 / 外部资源
→ 最终形成初步能力需求
→ 结合中/长期蓝图验证 → 形成最终能力需求
```

### 3. 常见能力关注要点

| 视角 | 挑战 |
|------|------|
| **横向** | 各板块业务组合协调发展、投资战略优化、战略协同效应培育 |
| **纵向** | 集团总部→产业公司→基础单位三层，管控手段：财务控制+战略规划+人力资源 |
| **外部** | "全球化"与"逆全球化"并存 → 数字化能力建立 |
| **内部** | 管理层级多→管控不到位→经营风险/效率低下 |

## 五、21.4.4 制定解决方案与路径计划

### 1. 平台化发展

- 数字化赋能→业务协同与资产管控→企业平台化
- 构建数据平台生态系统→创造与释放大数据价值
- 三方面推进：**客户体验数字化 + 运营数字化 + 业务模式数字化**
- 以业务为导向、以架构为指引的工作模式
- 各能力领域→拉动业务主责→按职能分工协同规划设计

### 2. 路径与计划

> **三原则**：先易后难、滚动增效；自下而上创新；自上而下变革

> **路径设计**：逐级提升、无跳跃成熟度；平衡短期投入与中长期需求；基于投入内容生存周期确立实施路径

> **计划要求**：明确细则、任务内容/目标/时间/责任人/完成条件/参与人员；责任到人（不用团队责任主体模式）

## 六、21.4.5 确保保障措施有效性

| 措施 | 核心内容 |
|------|----------|
| **重视文化** | 数字文化成为组织文化重要组成；变革普遍性+变化敏捷性+创新价值性冲击传统文化 |
| **措施量化** | 用量化语言表达（区别于常见规划的定性描述）；与企业绩效考核一体化融合；避免职能部门"惰性"和"旁观" |
| **动态监测** | 直接数据（责任主体）+间接数据（态势感知/宏观决策）；两类数据融合应用 |

## 七、21.4.6 规划建设数字人才

### 1. 数字人才三维分类

| 类型 | 角色 | 核心能力 |
|------|------|----------|
| **数字化领导者** | CEO/CDO/CIO等决策者 | 数字化变革思维+数字领导力 |
| **数字应用人才** | 战略/营销/财务/HR等业务骨干 | 数字技术驱动业务创新 |
| **数字技术人才** | 软硬件工程师/数据分析师等 | 大数据/大模型/大平台/物联网等 |

### 2. 分级体系

按"数据价值观、数字知识、数字素养、数字技能、数字绩效"五维构建能力模型 → 初级/中级/骨干/专家

### 3. 阶段推进

盘点人才→大范围数字通识教育→差异化培育方案→内部研讨形成数字文化

### 4. 三大关键控制点 ←「壁需续」

| 控制点 | 核心内容 |
|--------|----------|
| **打破部门壁垒** | 业务部门+技术部门绑定→共同参与项目→共享优质资源→激发创新动力 |
| **满足个性化需求** | 不同场景/知识/层次→不同学习需求→搭建在线学习平台→分层分级选课 |
| **持续推进** | 与企业转型节奏一致→从易到难→从思维到业务→实战项目中培养→螺旋上升 |

## 八、21.5 转型系统架构规划设计

### 架构全景

```
业务架构（引领）
  ↓ 驱动
数据架构（核心）
  ↓ 支撑
应用架构（使能）
  ↓ 承载
技术架构（底座）
```

### 8.1 业务架构（三层）

| 层级 | 视角 | 关注点 |
|------|------|--------|
| **企业级价值链** | 公司领导 | 生态融合发展价值链 |
| **全域业务架构** | 公司领导+部门经理 | 业务能力视图+整体业务域划分及关联 |
| **能力主线业务架构** | 部门经理+业务主管 | 跨职能业务域能力主线+端到端贯通+业务协同 |

> 📌 速记：**线域链**（能力主线→全域→价值链）

### 8.2 数据架构（三步）

| 步骤 | 做法 |
|------|------|
| **①数据主题目录** | 围绕核心业务主线→确立数据主题需求→战略管控层/保障层/业务运营层 |
| **②数据资产目录** | 基于主线流程→识别业务对象→主数据/维度数据/指标数据→分层分级归纳 |
| **③数据分布流转** | 数据资产生产消费关系+关联关系+生命周期→分布流转图 |

### 8.3-8.4 应用架构与技术架构

> 教材侧重于业务架构和数据架构，应用与技术架构作为配套支撑，考查概率较低。
