## 二、数据资源规划的DIKW视角

华航的数据资源规划，本质上是把「DIKW」漏斗在华航场景中走一遍：

```
数据层 → 120套源系统的原始日志、交易记录、传感器数据（50PB）
           ↓ 【数据资源化：采集、清洗、标准化】
信息层 → 按8大业务域组织的数据资产目录（10万条目）
           ↓ 【数据资产化：建模、血缘、质量】
知识层 → 航班延误预测模型、客户画像、维修成本分析
           ↓ 【数据资本化：数据产品、API服务】
智慧层 → 经营驾驶舱、AI辅助决策、实时大屏
```

**数据资源化**（2024.7-2024.9）：我们完成了120套源系统的数据调研，识别出每套系统的数据量级、更新频率和质量基线，建立了首批300个核心数据元标准。

**数据资产化**（2024.10-2025.3）：基于湖仓一体架构，构建了ODS→DWD→DWS→ADS→DIM五层数据分层，打通了8大业务域的端到端数据血缘。

**数据资本化**（2025.4 起）：日均10亿次API调用、5000条实时质量规则、AI辅助决策——数据真正变成了可交易、可变现的第五生产要素。

## 三、数据资源规划的时间线

```
2024.07 ─── 数据资源规划启动
  │  规划方法选型：基于稳定信息结构法（适合业务多变+前期数据积累多的场景）
  │  完成120套源系统调研
  │
2024.08 ─── 初始数据集获取
  │  摸底各系统数据字典、表结构、字段数、存储量
  │  建立「包罗万象」的初始数据集
  │
2024.09 ─── 核心数据集建立 + 架构选型
  │  5层审查（数据项→主题→功能→任务→核心数据集）
  │  确定采用湖仓一体架构（Iceberg + Spark）
  │
2024.10 ─── 数据标准体系建设
  │  发布首批800项数据元标准
  │  建立50套分类编码标准
  │  发布《数据标准执行令》
  │
2024.11-12 ─── 主题数据库设计 + 数据架构落地
  │  8大业务域各建立主题数据库（共建共用，否定自建自用）
  │  ODS层开始接入首批20套核心系统
  │
2025.01 ─── 试运行开始
  │  数据资产目录上线（10万条目）
  │  数据质量平台启动（5000条规则）
  │  标准覆盖率从35%开始攀升
  │
2025.03 ─── 标准覆盖率达成92%
  │  数据治理委员会月度Review常态化
  │  全链路数据血缘打通
  │
2025.05 ─── 正式交付
  │  数据架构、标准体系、治理机制全面验收
```
