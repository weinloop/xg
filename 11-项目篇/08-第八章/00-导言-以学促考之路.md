# 00 · 导言 — 以学促考之路

## 写给自己

我是系统规划与管理师，不是数据工程师。

但第八章偏偏讲的是数据资源规划——这是整个方法篇中唯一专门讨论「数据」的章节。它不教你写SQL，也不教你调Spark参数。它教的是站在系统规划与管理师的高度，用「规划」的眼光审视数据：什么是数据的价值阶梯？三种方法从哪个角度切入会更稳？数据架构怎么选？标准体系怎么建？治理、质量、安全三驾马车怎么拉？

换句话说，这一章不是让你成为数据专家，而是让你成为那个「知道数据规划怎么做」的人。

---

## 第八章的独特定位

和前几章相比，第八章有三个鲜明特点：

1. **纯概念驱动，零计算公式。** 第4章讲方法框架、第5章讲应用设计、第6章讲云资源（vCPU公式）、第7章讲网络（IPv4计算）——都有大量实战操作。第八章几乎全是概念：DIKW模型、CAP理论、元数据结构、数据质量维度……这些概念之间的关系错综复杂，背不下来也推导不出，只能靠理解+口诀取胜。

2. **「方法」和「管理」双线并行。** 8.2讲三种规划方法（怎么做），8.3讲数据架构（建成什么样），8.4讲标准化（用什么规范），8.5讲管理（怎么管好）。前半段是「规划怎么做」，后半段是「规划出来后怎么落地」。这种结构决定了选择题和案例题会交叉考察。

3. **首考出题少但2026年预测权重高。** 2025年11月首考第5-10章各出约1题，第8章也不例外。但DAMA Wheel英文题对应本章、论文万能框架将其列为🟡高风险——2026年出论文题的概率不容小觑。

## 三类题型的差异化策略

### 选择题策略

第八章的选择题集中在概念区分：

| 易混概念对 | 区分要点 |
|-----------|---------|
| 治理 vs 管理 | 治理=监督（定规矩），管理=执行（按规矩做事） |
| 分区 vs 分片 | 分区=表内拆分（按行/列），分片=数据库实例拆分 |
| Lambda vs Kappa | Lambda=批+流两套代码，Kappa=全流一套代码 |
| 数据湖 vs 数据沼泽 | 有治理=湖，无治理=沼泽 |
| 元数据 vs 数据元 | 元数据=关于数据的数据，数据元=数据的基本单元 |

**备考策略**：重点是「三种方法对比」「CAP三选二」「数据质量十大原则」这三组高频考点。

### 案例分析题策略

案例题的出题方式通常是「请简述数据资源规划的XX方法步骤」或「数据XX标准化的内容」，直接背口诀即可拿满分。本章14道案例问答题已在 `06-案例篇/章节整理/第08章_数据资源规划.md` 中完整覆盖。

### 论文题策略

如果考到「论数据资源规划的方法与实践」，你手上有最硬的项目素材：50PB数据量、8大业务域、800项数据元标准、5000条质量规则。论文框架可分三节展开：①规划方法与步骤 ②数据架构设计 ③数据标准体系建设。详见 `06-论文实战范文.md`。

## 学习路线

```
第1-2天：02概述与三种规划方法（DIKW + 3法对比）—— 理清大框架
第3-4天：03数据架构实战（传统+现代）—— 理解CAP和湖仓一体
第5-6天：04标准化与管理实战（标准体系+治理+质量+安全）—— 细嚼慢咽
第7天：  05真题考点+07速记自测 —— 检验+巩固
考前冲刺：06论文范文背诵 —— 论文题准备
```
