# 项目经理的角色与能力

> 教材17.2节 | 515-518页 | 选择题★★★★☆ | 案例★★★☆☆ | 论文★★★★★

## 一、三个角色的区别

| | 项目经理 | 职能经理 | 运营经理 |
|------|------|------|------|
| 聚焦 | 项目目标实现 | 职能领域管理监督 | 业务运营高效性 |
| 管辖 | 临时性项目团队 | 常设职能部门 | 持续性运营 |
| 委派 | 执行组织委派 | 组织架构任命 | 业务线任命 |

```
        │  │ ┌──────────────┐  │  │
        │  │ │ 行业（趋势洞察）│  │  │
        │  │ │ ┌──────┐   │  │  │
        │  │ │ │ 组织  │   │  │  │
        │  │ │ │┌──┐ │   │  │  │
        │  │ │ ││项目││   │  │  │
        │  │ │ │└──┘ │   │  │  │

        │  │ └──────────────┘  │  │

        └──────────────────────────┘
```

| 范围 | 角色定位 | 关键行为 |
|------|---------|---------|
| **项目** | 领导者+沟通者 | 平衡制约因素、使用软技能达成共识 |
| **组织** | 倡导者+协作者 | 与其他PM互动、推动项目管理价值 |
| **行业** | 趋势洞察者 | 关注技术/市场/标准发展趋势 |
| **专业学科** | 知识传递者 | 参与社区、继续教育、分享知识 |
| **跨领域** | 宣传大使 | 让组织认识项目管理的价值 |

## 三、项目经理的三大关键技能

```
        ┌──────────────┐
        │   领导力      │
        │  (指引激励)   │
        │     ↙ ↘      │
        │   ↙     ↘    │
        │  ↙       ↘   │
  ┌─────┴──────┐ ┌─────┴──────┐
  │  项目管理   │ │ 战略和商务  │
  │(专业硬技能) │ │(商业眼光)   │
  └────────────┘ └────────────┘
```

### 1. 项目管理技能

顶尖项目经理的四个特征：
1. 重点关注关键项目管理要素（进度、财务、问题日志）
2. 针对每个项目**裁剪**工具和方法
3. 花时间制订**完整计划**并排定优先顺序
4. 管理项目要素（进度、成本、资源、风险）

### 2. 战略和商务管理技能

**商业因素**：风险问题、财务影响、成本效益分析（NPV/ROI等）、业务价值、效益预期、范围/预算/进度/质量

**核心能力**：能将组织战略翻译为项目行动，能用商业语言与发起人沟通。

### 3. 领导力技能

#### 3.1 领导者品质和技能（14项）

**口诀：远积乐合沟尊诚学果批系能动变团服**

| 序号 | 品质/技能 | 要点 |
|:----:|---------|------|
| 1 | 有**远**见 | 描绘愿景、构建梦想 |
| 2 | **积**极乐观 | 正能量感染团队 |
| 3 | 乐于**合**作 | 协同而非命令 |
| 4 | 管理关系和冲**突** | 信任/共识/协商/妥协 |
| 5 | 多种方式**沟**通 | 90%时间在沟通 |
| 6 | **尊**重他人+诚信正直 | 谦恭、友善、诚实、忠诚 |
| 7 | **诚**信正直 | 遵守职业道德 |
| 8 | 终身**学**习 | 以结果和行动为导向 |
| 9 | 关注重要事**情** | 优先级排序、筛选关键信息 |
| 10 | 整体**系**统视角 | 同等对待内外部因素 |
| 11 | 批判性思维/**变**革推动者 | 分析方法驱动决策 |
| 12 | 创建高效**团**队 | 以**服**务为导向 |
| 13 | 展现幽默 | 与团队有效地分享乐趣 |
| 14 | **能**够筛选信息 | 从大量信息中筛选最重要的 |

#### 3.2 权力类型（13种）

**口诀：位信参情个关专奖惩迎压疚说避**

| 类型 | 来源 | 类型 | 来源 |
|------|------|------|------|
| **位**（地位/正式） | 组织授予的职位 | 惩（处罚/强制） | 纪律处分能力 |
| **信**息 | 控制信息收集分发 | 迎（迎合） | 恭维或赢得青睐 |
| **参**考 | 他人尊重和赞赏 | 压（施加压力） | 限制选择自由 |
| 情（情境） | 危机等特殊情况 | 疚（引发愧疚） | 强加义务或责任 |
| 个（个性/魅力） | 魅力、吸引力 | 说（说服力） | 提供论据 |
| 关（关系） | 人际交往、联系 | 避（回避） | 拒绝参与 |
| 专（专家） | 技能、经验、证书 |  |  |
| 奖（奖励相关） | 表扬、金钱或奖励 |  |  |

::: tip 关键认知
项目经理需要**主动寻求**权力，而不是等待组织授权。
:::

## 四、领导力 vs 管理（必考对比表）

| 维度 | 管理 | 领导力 |
|------|------|--------|
| 权力基础 | 职位权力 | 关系力量 |
| 核心行为 | 维护 | 建设 |
| 工作方式 | 管理 | 创新 |
| 关注对象 | 系统和架构 | 人际关系 |
| 驱动机制 | 依赖控制 | 激发信任 |
| 时间视野 | 近期目标 | 长期愿景 |
| 思维方式 | 了解方式和时间 | 了解情况和原因 |
| 价值取向 | 关注赢利 | 关注范围 |
| 变革态度 | 接受现状 | 挑战现状 |
| 核心理念 | **正确地做事** | **做正确的事** |
| 问题处理 | 可操作性问题解决 | 愿景/一致性/动力/激励 |

## 五、领导力风格（7种）

| 风格 | 特点 | 适用场景 |
|------|------|---------|
| **放任型** | 团队自主决策 | 高度成熟的团队 |
| **交易型** | 目标+反馈+奖励 | 任务明确的项目 |
| **服务型** | 服务优先于领导 | 注重成长的团队 |
| **变革型** | 理想化+激励+创新关怀 | 需要突破性变革 |
| **魅力型** | 精神饱满、说服力强 | 启动/危机时刻 |
| **交互型** | 交易+变革+魅力结合 | 复杂多变的项目 |

## 华航项目经理画像

| 技能维度 | 在华航项目中的体现 |
|---------|------------------|
| **项目管理** | 8里程碑管理、7项风险应对、580万预算控制 |
| **战略和商务** | 将智慧华航战略翻译为数据平台目标、与集团CFO用NPV语言沟通投资回报 |
| **领导力** | 协调23家分公司数据负责人（无直接管理权）、构建12+30人虚拟团队文化 |
| **沟通** | 周报+月报+里程碑评审+分公司现场沟通，覆盖100+干系人 |
| **权力运用** | 主要依赖**专家权力**（数据治理经验）和**关系权力**（与各分公司建立的信任） |
