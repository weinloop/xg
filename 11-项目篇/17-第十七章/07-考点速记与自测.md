# 考点速记与自测

## 二、必背对比表（6组）

### 表1：项目 vs 项目集 vs 项目组合

| | 项目 | 项目集 | 项目组合 |
|------|------|------|------|
| 定义关键词 | 临时、独特 | 关联、协调 | 战略、集合 |
| 管理核心 | 正确地做事 | 正确地做事 | 做正确的事 |
| 组件关系 | 内部依赖 | 组件间依赖 | 不一定关联 |

### 表2：五种组织结构（项目经理权力从低到高）

| 类型 | 权力 | 预算权 | 管理团队 |
|------|:--:|:----:|:------:|
| 职能型 | 极少 | 职能经理 | 兼职 |
| 矩阵-弱 | 低 | 职能经理 | 兼职 |
| 矩阵-均衡 | 低-中 | 混合 | 兼职 |
| 矩阵-强 | 中-高 | 项目经理 | 全职 |
| 项目型 | 高-全部 | 项目经理 | 全职 |

### 表3：预测型 vs 适应型

| | 预测型 | 适应型 |
|------|------|------|
| 需求 | 开发前确定 | 频繁细化 |
| 交付 | 最终一次性 | 频繁交付 |
| 变更 | 严格限制 | 实时融入 |
| 干系人 | 里程碑参与 | 持续参与 |
| 规划 | 前期详细规划 | 高层级→逐步细化 |

### 表4：迭代 vs 增量

| | 迭代型 | 增量型 |
|------|------|------|
| 方式 | 重复循环活动 | 渐进增加功能 |
| 每次产出 | 改进版本 | 新增功能 |
| 最终交付 | 完整的最终版本 | 累积成完整产品 |

### 表5：领导力 vs 管理

| | 管理 | 领导力 |
|------|------|------|
| 核心 | 正确地做事 | 做正确的事 |
| 权力 | 职位权力 | 关系力量 |
| 行为 | 维护 | 建设 |
| 驱动 | 控制 | 信任 |
| 视野 | 近期 | 长期 |
| 态度 | 接受现状 | 挑战现状 |

### 表6：事业环境因素 vs 组织过程资产

| | EEF（事业环境因素） | OPA（组织过程资产） |
|------|------|------|
| 来源 | 内外部环境 | 组织内部积累 |
| 性质 | 制约条件 | 可利用资源 |
| 可改变性 | 通常不可控 | 可更新维护 |
