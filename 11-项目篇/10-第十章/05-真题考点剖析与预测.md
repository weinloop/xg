## 三、易混概念对照表

| 易混概念 | 正确说法 | 常见错误 |
|---------|---------|---------|
| DevOps vs DevSecOps | DevSecOps = DevOps + 安全全流程 | 认为两者相同 |
| 微服务 vs 小服务 | 小服务 = 一组密切微服务的组合 | 认为小服务是微服务的子集 |
| 服务化 vs Mesh化 | 服务化=拆分业务；Mesh化=剥离中间件 | 混淆两者定位 |
| XA vs 消息最终一致 | XA强一致性能差；消息最终一致性能高 | 认为XA性能好 |
| Logging vs Tracing | Logging=离散日志；Tracing=全链路调用 | 混淆两者用途 |
| 韧性 vs 弹性 | 韧性=抵御异常；弹性=自动伸缩 | 两者经常被混淆 |
| TCC vs SAGA | TCC有Try阶段；SAGA无Try，每事务有补偿 | 记混有无Try |
| 容器 vs Serverless | 容器仍需管理；Serverless完全不管理 | 认为Serverless只是轻量容器 |
| 混沌工程 vs 安全测试 | 混沌=注入故障找弱点；安全=防御漏洞 | 混淆测试目的 |
| 多云管理 vs 混合云 | 多云=多个云平台；混合云=公有+私有 | 混淆部署范围 |
| API网关 vs Service Mesh | API网关=南北流量；Service Mesh=东西流量 | 混淆流量方向 |
| OAM vs IaC | OAM=应用模型；IaC=基础设施即代码 | 混淆抽象层次 |
