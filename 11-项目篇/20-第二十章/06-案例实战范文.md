## 案例模拟一：某县数字乡村规划

### 背景材料

B县是中部省份的农业大县，以水稻种植和淡水养殖为主。近年来面临三大问题：
1. 农产品销路不畅，价格波动大，农民增产不增收
2. 年轻人外出务工，留守老人就医难、办事难
3. 村级治理效率低，信息传达靠「大喇叭」

2023年，B县被列入省级数字乡村试点，计划两年内建成数字乡村基础平台。作为系统规划与管理师，你被邀请参与规划。

---

### 问题1：请分析B县数字乡村建设应重点关注的五大焦点，并各举1个具体应用。 (10分)

**参考答案**：

| 焦点 | B县具体应用 |
|------|-----------|
| 乡村数字经济 | 搭建农产品电商平台，利用大数据监测水稻/水产品市场价格，指导农民错峰销售 |
| 乡村数字服务 | 开通「互联网+医疗」远程问诊，让留守老人不出村就能视频连线县医院专家 |
| 乡村数字治理 | 建立「数字乡村一张图」，整合党建/人口/土地/产业数据，实现一图统览 |
| 乡村数字生态 | 在稻田部署土壤传感器+水质监测设备，实时监测氮磷流失和养殖水质 |
| 文化资源数字化 | 将当地传统农耕文化、渔俗文化进行数字化记录，建设村级数字博物馆 |

---

### 问题2：请画出数字乡村信息系统总体参考架构，并简要说明各层功能。 (15分)

**参考答案**：

```
┌──────────────────────────────────────────────┐
│  业务应用层                                   │
│  数字经济(电商/溯源) │ 数字服务(医疗/养老)      │
│  数字治理(一张图/党建) │ 数字生态(水/土监测)     │
├──────────────────────────────────────────────┤
│  平台支撑层                                   │
│  认证 │ 交互 │ 流程 │ GIS │ 区块链 │ 智能分析  │
├──────────────────────────────────────────────┤
│  数据资源层                                   │
│  基础库(农业生产/乡村治理/乡村生活)             │
│  数据治理(采集/归集/清洗/分析)                  │
├──────────────────────────────────────────────┤
│  基础设施层                                   │
│  5G网络 │ 政务一体机 │ 云计算 │ 传感器         │
├──────────────────────────────────────────────┤
│  安全保障体系 │ 运营管理体系 │ 标准规范体系       │
└──────────────────────────────────────────────┘
```

**各层说明**：
- **基础设施层**：提供网络通信、计算存储和感知接入能力，是数字乡村的底座
- **数据资源层**：汇聚农业农村数据，建立基础库和专题库，进行数据治理
- **平台支撑层**：提供认证、流程、GIS、区块链等通用能力，支撑上层业务
- **业务应用层**：面向经济/服务/治理/生态四类场景的具体应用
- **三大体系**：安全保障、运营管理、标准规范贯穿所有层次

---

### 问题3：针对B县「村级治理效率低」的问题，请提出基于数字乡村的治理方案。 (10分)

**参考答案**：

1. **智慧党建**：建立线上党务管理系统，实现「三会一课」线上开展，解决党员分散、流动性大问题
2. **基层网格化治理**：将党建/综治/公安/环保等纳入统一网格，实现「一网统管」
3. **「数字乡村一张图」**：基于三维GIS技术，叠加人/房/事/单位等数据，实现可视化治理
4. **互联网+政务**：将政务服务下移至村级终端，村民不出村即可办理，让「信息跑路」代替「群众跑腿」
5. **综合治理智能化**：部署智能摄像机+AI算法，自动识别异常事件预警，替代传统人工巡查

## 案例模拟二：数字乡村技术选型

### 背景材料

C镇地处丘陵地带，以茶产业为主，有3000亩茶园。镇政府计划建设智慧茶园系统，实现以下目标：
1. 实时监测茶园土壤湿度、气温、光照
2. 及时发现病虫害并预警
3. 实现茶叶从种植到销售的全流程溯源
4. 对茶园周边森林防火进行监控

---

### 问题1：请为C镇智慧茶园推荐适用的关键技术，并说明理由。 (15分)

**参考答案**：

| 目标 | 推荐技术 | 理由 |
|------|----------|------|
| 监测土壤/气候 | **物联网技术** | 部署传感器，按约定协议采集温湿度/光照/土壤数据，实时传输 |
| 病虫害预警 | **空天地一体化智能感知** | 卫星遥感大面积监测 + 无人机搭载多光谱设备近地感知 + 地面智能虫情测报灯 |
| 全流程溯源 | **区块链技术** | 分布式存储+不可篡改，从种植→加工→销售的每个环节上链，消费者扫码可追溯 |
| 森林防火 | **热成像灾害监测感知** | 红外辐射原理，24小时监测温度异常，自动识别火情预警 |

---

### 问题2：上述技术分别属于教材中哪类关键技术？ (5分)

**参考答案**：

| 技术 | 所属类别 |
|------|----------|
| 物联网技术 | 数字乡村信息感知技术【感】 |
| 空天地一体化智能感知 | 数字乡村信息感知技术【感】 |
| 区块链技术 | 数字乡村智能化应用技术【智】 |
| 热成像灾害监测感知 | 数字乡村信息感知技术【感】 |

---

### 问题3：在运营体系设计中，C镇智慧茶园的数据运营应包括哪些内容？ (5分)

**参考答案**：

1. **基础数据采集更新**：茶园地块信息、种植品种、农户信息等基础数据持续更新
2. **业务数据分层分级流转**：镇级采集→县级汇聚→省级共享，建立数据流转机制
3. **全流程数据质量监控**：对传感器数据、溯源数据等建立质量检查规则，确保数据准确性
4. **形成数据全流程闭环**：采集→治理→分析→应用→反馈→优化采集

## 答题模板速记

### 架构设计题三步法

```
第一步：画总体架构（四层+三体系）
第二步：逐层说明功能（每层1-2句话）
第三步：结合案例场景具体化（把案例的业务填进去）
```

### 技术选型题三步法

```
第一步：识别场景需求（监/溯/防/管）
第二步：匹配教材技术（础/感/智/安四类）
第三步：说明选型理由（技术原理+场景适配）
```
