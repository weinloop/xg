# 04 · 无线网与网络整体规划实战（教材7.4+7.5）

> 广域网和局域网解决了「有线」的连通问题，但还有两个关键命题：移动办公的无线覆盖、以及如何管好这一整套复杂的网络。7.4和7.5就是回答这两个问题的。

---

## 7.4 无线网规划

教材将无线网分为三大类：运营商4G/5G移动通信网、NB-IoT等专用无线网、Wi-Fi无线局域网。

### 7.4.1 4G/5G移动通信技术

#### 4G vs 5G 核心对比

| 维度 | 4G | 5G |
|------|-----|-----|
| 峰值速率 | 100Mbps（下行） | 10~20Gbps |
| 时延 | 30~50ms | 1ms（uRLLC场景） |
| 连接密度 | 1万/km² | 100万/km² |
| 核心网架构 | EPC（MME/S-GW/P-GW） | SBA（微服务总线架构） |
| 三大场景 | — | eMBB / uRLLC / mMTC |
| 关键技术 | OFDM / MIMO | 网络切片 / 边缘计算 / Polar码 / 毫米波 |

**华航项目的5G应用**：
- **4G/5G备链路**：MPLS专线故障时，核心路由器自动切换至5G CPE，提供≥300Mbps备份带宽
- **5G专网构想**：机场货站场景规划5G室内小站，实现AGV无人搬运车低延迟控制（uRLLC场景，目标时延<10ms）

#### 5G网络架构（SBA微服务架构）

5G核心网采用总线式微服务架构，关键网元：

| 网元 | 功能 | 相当于4G的什么 |
|------|------|:---:|
| AMF | 接入及移动性管理 | MME（移动性部分） |
| SMF | 会话管理 + UE IP分配 | MME+S-GW+P-GW（会话部分） |
| UPF | 用户面功能（路由转发） | S-GW+P-GW（用户面） |
| UDM | 统一数据管理 | HSS（用户数据） |
| AUSF | 鉴权服务 | MME+HSS（鉴权） |
| PCF | 策略控制 | PCRF |
| NSSF | 网络切片选择 | 4G无对应 |

> **考点提示**：5G三大场景（eMBB/uRLLC/mMTC）+ 5G网络切片功能 + 核心网SBA架构，是选择题高频考点。

### 7.4.2 NB-IoT等专用无线通信网络技术

NB-IoT（窄带物联网）特点：覆盖广、连接多、速率快（相对）、成本低、耗电少，使用授权频谱，半双工通信。

**华航NB-IoT部署——机场货站传感网**：

| 参数 | 取值 |
|------|------|
| 网关数量 | 12台（覆盖首都机场T1/T2/T3 + 大兴机场） |
| 传感器类型 | 温湿度、振动、门磁、烟感 |
| 采集频率 | 每5分钟上报一次 |
| 数据用途 | 货物运输环境监控 → 数据资产质量追溯 |
| 覆盖范围 | 单网关覆盖半径500m |

**项目故事**：2025年1月NB-IoT网关部署时，机场T3航站楼B1货站区域信号极弱，传感器数据丢包率高达40%。排查发现B1层钢筋混凝土结构对NB-IoT的800MHz频段衰减严重。我们采取了两个措施：①在B1层加装信号中继器（Repeater）；②为B1层传感器改用LoRa（非授权频谱，穿透力更强），通过LoRa网关桥接到NB-IoT网关回传。丢包率降至2%。

### 7.4.3 无线局域网技术（Wi-Fi）

瘦AP vs 胖AP：

| 类型 | 管理方式 | 适用场景 | 华航选择 |
|------|---------|------|:---:|
| **瘦AP** | 需AC集中管理 | 大型环境（AP数量多） | ✅ 总部47台AP + AC双机热备 |
| 胖AP | 自带管理平面，分布式 | 小型环境 | 分公司使用（每分公司2-3台） |

Wi-Fi组网架构选择：

| 架构维度 | 华航选型 | 原因 |
|---------|:---:|------|
| 二层 vs 三层组网 | **三层组网** | AP和AC可在不同子网，灵活部署 |
| 直连 vs 旁挂 | **旁挂** | AC不串接在数据路径上，故障不影响业务 |
| 直接转发 vs 隧道转发 | **直接转发** | 数据不经AC，转发效率更高 |

### 7.4.4 无线网规划五大重点

**口诀：频覆容站组**

| 重点 | 华航实践 |
|------|------|
| **无线频率规划** | Wi-Fi 6使用2.4GHz + 5GHz双频，信道规划避免同频干扰（1/6/11交错） |
| **无线传输覆盖范围规划** | 办公楼每层4-6个AP（半径15m），AP间距10-12m |
| **无线传输容量规划** | 高峰期总部1300终端在线 → 47个AP平均28终端/AP（远低于100的上限） |
| **无线基站站址规划** | AP部署避开电梯井、承重墙，天线方向避开金属隔断 |
| **无线组网规划** | AC旁挂核心交换机，CAPWAP隧道走管理VLAN，业务流量本地转发 |

## 7.5 网络整体规划的重点事项

**口诀：管安房线监能**

### 7.5.1 网络管理和维护功能设计（FCAPS）

ISO定义网络管理五大功能：**故障管理、配置管理、性能管理、计费管理、安全管理**。

**口诀：故配性费安**

| FCAPS | 华航网管平台实现 |
|-------|---------------|
| **故障管理**（Fault） | Prometheus AlertManager，分级告警（P0-P3），P0告警5分钟内通知运维群 |
| **配置管理**（Configuration） | Ansible自动化配置推送，设备配置定期备份到Git仓库 |
| **性能管理**（Performance） | Grafana大屏（带宽利用率/延迟/P99/丢包率），2000+监控指标 |
| **计费管理**（Accounting） | 各区域、各业务域的带宽使用量月度统计，为成本分摊提供依据 |
| **安全管理**（Security） | 堡垒机审计、防火墙规则变更审批、SOC日志分析 |

网管系统三层架构：

```
表示层：Grafana Web大屏 + 企业微信告警 + 手机App
  ↓
管理应用层：故障管理 / 配置管理 / 性能管理 / 计费管理 / 安全管理
  ↓
网元/网络层：MIB管理信息库 + SNMP采集（交换机/路由器/防火墙/AP）
```

### 7.5.2 网络安全设计和安全管理

网络安全层面四大手段在华航项目的落地：

| 安全手段 | 华航部署 | 关键数据 |
|---------|------|------|
| **防火墙** | 互联网边界防火墙 + 内网VLAN间防火墙（策略白名单） | 规则数约200条 |
| **VLAN安全域划分** | 6业务域VLAN隔离 + 核心/边缘VPC隔离 | 等保三级合规 |
| **入侵检测/防护（IDS/IPS）** | 网络边界部署IPS + 内网核心部署IDS | 日均告警<10条（误报已优化） |
| **安全审计（SOC）** | 统一日志管理平台（ELK），全网设备日志集中采集 | 日志保留180天 |

安全管理的五大重点：

**口诀：组险急灾运**

| 重点 | 华航实践 |
|------|------|
| **安全组织和责任** | 设立安全管理员（兼职），明确各区域IT负责人的安全责任 |
| **风险管理工作机制** | 月度漏洞扫描 + 季度渗透测试 + 年度等保复评 |
| **应急处理工作机制** | 安全事件分级响应（Ⅰ-Ⅳ级），P0安全事件15分钟内启动应急 |
| **容灾备份工作机制** | RTO≤15分钟、RPO≤5分钟，每季度容灾演练 |
| **上线/切换/安全运维方案** | 网络变更必须经过审批→测试→窗口实施→回退验证四步 |

**项目故事**：2024年10月等保三级初评中，评估机构发现「开发测试环境与生产环境网络隔离不彻底」——测试人员可直连生产数据库。这是一票否决项。我们紧急实施了VPC隔离方案：开发测试区使用独立VLAN（VLAN 70）+ 独立子网（10.0.70.0/24），通过防火墙策略仅允许特定测试数据源（脱敏后的生产数据副本）的单向访问。一周内完成整改，等保复评顺利通过。

### 7.5.3 机房建设

机房建设是综合性系统工程，涵盖装修/空调/电气/接地防雷/消防/环境监控/节能降耗系统。

| 机房要素 | 华航总部机房规格 |
|---------|------|
| 面积 | 主数据中心120㎡（含设备区80㎡+操作区40㎡） |
| 空调 | 精密空调2台（N+1冗余），温度22±2℃，湿度50±10% |
| 电气 | 双路市电 + UPS（满载30min）+ 柴油发电机（自动切换<15s） |
| 接地防雷 | 三级防雷，接地电阻<1Ω |
| 消防 | 七氟丙烷气体灭火 + 极早期烟雾探测（VESDA） |
| 环境监控 | 温湿度/漏水/门禁/视频全覆盖 |
| PUE | 设计目标≤1.5 |

### 7.5.4 综合布线

综合布线系统基本构成：建筑群子系统、干线子系统、配线子系统。

| 子系统 | 华航对应 | 介质 |
|------|------|------|
| **建筑群子系统** | 总部大楼间光缆互联 | 单模光纤12芯 |
| **干线子系统** | 楼层弱电井→机房配线架 | 单模光纤 + 6类双绞线 |
| **配线子系统** | 楼层配线架→工位信息面板 | 6类双绞线（千兆到桌面） |

### 7.5.5 监控系统

机房监控涵盖五类监控对象：

| 监控对象 | 具体内容 | 告警方式 |
|---------|------|------|
| **动力环境** | 温湿度、漏水、UPS状态、空调运行 | 短信+微信 |
| **网络设备** | CPU/内存/端口流量/错误包率 | Grafana大屏 |
| **门禁** | 人员进出记录、非法闯入告警 | 声光报警 |
| **消防** | 烟感、温感、气体灭火状态 | 消防联动 |
| **统一运维平台** | 全量设备自动巡检 | 日巡检报告 |

### 7.5.6 节能降耗

华航机房节能措施：

| 措施 | 效果 |
|------|------|
| 冷热通道封闭 | 空调能效提升约25% |
| 机柜按功率密度分区部署 | 高密度区（GPU推理节点）独立制冷 |
| 智能动态制冷 | 根据实时温度调节空调输出 |
| 虚拟化整合 | 20台物理服务器替代约80台传统服务器，节电约60% |

> **考点提示**：
> - FCAPS五大功能：**故配性费安**
> - 安全五大手段：防火墙/VLAN安全域/IDS-IPS/SOC
> - 安全管理五大重点：**组险急灾运**
> - 机房监控五类对象：动环/网络设备/门禁/消防/统一运维
> - PUE = 数据中心总能耗 / IT设备能耗，数值越低越节能
