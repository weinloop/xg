# 03 · 信息安全架构实战（教材9.2 + 9.4案例）

> 信息安全架构是企业架构的子集，目的是让安全工作以标准和节省成本的方式与业务实践相结合。本节覆盖三道防线、SABSA六层模型、GB/T 20274.1三维保障模型、五级成熟度和9.4规划案例。

---

## 9.2.1 安全架构的定义和范围 —— 三道防线

### 📖 教材知识点

| 防线 | 定义 | 目标 | 口诀 |
|------|------|------|:---:|
| **系统安全架构** | 构建信息系统安全质量属性的主要组成部分 | 从源头打造自身安全，不依赖外部防御 | **源头** |
| **安全技术体系架构** | 构建通用安全技术基础设施 | 系统性地增强各部分安全防御能力 | **基础设施** |
| **审计架构** | 独立审计部门提供的风险发现能力 | 独立评价，覆盖所有风险（含安全风险） | **独立审计** |

### 🏗 华航项目实践

```
第一道防线：系统安全架构（源头加固）
├── 应用层：参数化查询防SQL注入 + CSP策略防XSS
├── 容器层：镜像签名验证 + 运行时安全策略（Seccomp/AppArmor）
├── 数据层：字段级加密 + 静态脱敏
└── 代码层：SAST安全扫描集成到CI/CD流水线

第二道防线：安全技术体系架构（基础设施防御）
├── WAF Web应用防火墙（拦截率99.2%）
├── NGFW 新一代防火墙（3层流量清洗+7层应用识别）
├── IDS/IPS 入侵检测防御
├── 网闸隔离（数据摆渡通道与外网物理隔离）
├── DLP 数据防泄漏
└── SOC+SIEM（日志关联分析，日均10亿条）

第三道防线：审计架构（独立评价）
├── 季度渗透测试（外部安服团队）
├── 年度等保测评
├── 操作审计全覆盖（所有管理员操作全程记录）
└── 合规审计（对标四部法律）
```

> **考点提示**：三道防线的递进关系——第一道靠自己、第二道靠工具、第三道靠独立评价。选择题考过"以下哪项不属于三道防线"。

## 9.2.2 SABSA商业应用安全架构

### 📖 教材知识点

SABSA以业务视角为起点，从6个层面提供完整安全架构。**六层模型**：

| 视图 | 安全架构 | 对应角色 | 回答的核心问题 |
|------|------|------|------|
| 业务视图 | 情境安全架构 | 业务所有者 | 为什么要做安全？ |
| 架构视图 | 概念安全架构 | 架构师 | 安全战略是什么？ |
| 设计视图 | 逻辑安全架构 | 设计师 | 安全服务如何提供？ |
| 构建视图 | 物理安全架构 | 构建者 | 用什么安全机制？ |
| 实施视图 | 组件安全架构 | 实施者 | 用什么安全产品和工具？ |
| 服务管理视图 | 安全服务管理架构 | 运维管理者 | 如何管理与衡量？ |

> **速记口诀**：**情概逻物组营**（情境→概念→逻辑→物理→组件→服务管理）

**SABSA六列矩阵**：每个层次回答6个问题——做什么(资产)、为什么(动机/风险)、如何(流程)、谁(人员)、何处(位置)、何时(时间)

> **速记口诀**：**资动流人位时**

### 🏗 华航项目实践

我们用SABSA框架设计了华航的安全架构：

| SABSA层 | 华航对应内容 |
|------|------|
| **情境（业务视图）** | 华航业务目标：旅客服务不中断、航班数据不泄露、维修记录不可篡改 |
| **概念（架构视图）** | 安全战略：等保三级+ISO 27001，纵深防御，"一中三防"架构 |
| **逻辑（设计视图）** | 安全服务定义：身份认证服务/访问控制服务/加密服务/审计服务/态势感知服务 |
| **物理（构建视图）** | 安全机制：RBAC+ABAC混合授权/AES-256加密/国密SM2-SM4/TLS 1.3传输 |
| **组件（实施视图）** | 产品选型：PaloAlto NGFW/ClamAV防病毒/Ceph加密存储/Vault密钥管理 |
| **服务管理（运维视图）** | SOC运营：24×7监控+月度安全报告+季度渗透测试+年度等保测评 |

> **考点提示**：SABSA六层是选择题热门考点。重点记各层对应的角色和产出的架构类型。

## 9.2.3 信息系统安全保障模型

### 📖 教材知识点

GB/T 20274.1 描述了**三维保障模型**：

| 维度 | 内容 |
|------|------|
| **保障要素** | 技术、工程、管理、人员（四要素综合保障） |
| **生命周期** | 规划组织→开发采购→实施交付→运行维护→废弃（5阶段） |
| **能力成熟度** | 5个等级：从随机被动到持续优化 |

**核心思想**：以**风险和策略为基础**，在整个生命周期中实施技术、管理和工程保障要素，实现信息安全保障的持续性。

**安全能力成熟度五级**：

| 等级 | 名称 | 特征 | 口诀 |
|:---:|------|------|:---:|
| 1 | **基本执行级** | 随机被动，依赖个人经验，无法复制 | **执** |
| 2 | **计划跟踪级** | 主动计划与执行，但未体系化 | **跟** |
| 3 | **充分定义级** | 基本实践规范定义与执行 | **定** |
| 4 | **量化控制级** | 建立量化目标，可度量与预测 | **量** |
| 5 | **持续优化级** | 根据组织目标不断改进和优化 | **优** |

> **速记口诀**：**执跟定量优**（基本执行→计划跟踪→充分定义→量化控制→持续优化）

### 🏗 华航项目实践

**三维保障在华航的落地**：

```
风险与策略
     ↓
┌─────────────────────────────────────┐
│ 保障要素维度                          │
│ ├ 技术：7大安全技术全覆盖             │
│ ├ 工程：安全需求→设计→编码→测试→部署   │
│ ├ 管理：ISO 27001 ISMS + 等保管理制度  │
│ └ 人员：安全培训覆盖100%，持证上岗     │
├─────────────────────────────────────┤
│ 生命周期维度                          │
│ 规划→开发→实施→运维→废弃              │
│ 每个阶段嵌入安全审查门禁               │
├─────────────────────────────────────┤
│ 能力成熟度                            │
│ 阶段一(计划跟踪)→阶段二(充分定义)      │
│ →阶段三(量化控制：SOC上线+月度度量)     │
└─────────────────────────────────────┘
```

**五级成熟度对应华航三阶段**：

| 阶段 | 成熟度 | 判断依据 |
|------|:---:|------|
| 第一阶段（2024.7-10） | 计划跟踪级 | 制度文件已编制、安全培训已开展、流程已建立但尚未体系化 |
| 第二阶段（2024.10-2025.5） | 充分定义级 | 安全策略已规范定义、7大技术全面部署、安全管理文件化 |
| 第三阶段（2025.6-9） | 量化控制级 | SOC上线、安全度量指标体系建立、月度安全KPI看板 |

> **考点提示**：五级成熟度是本章核心考点。注意区分"计划跟踪级"和"充分定义级"——前者"主动但未体系化"，后者"已规范定义"。选择题出题套路：给一个场景描述，问属于哪一级。

## 9.4 信息安全规划案例 —— 三步骤与三报告

### 📖 教材知识点

教材9.4以A公司B信息安全系统为例，将规划过程总结为三大步骤：

```
步骤一：现状调研与需求分析
    ↓ 产出 → 现状调研与需求分析报告
    ↓ 评审 → 安全需求评审

步骤二：总体架构与蓝图设计
    ↓ 产出 → 信息安全体系架构设计报告
    ↓ 评审 → 体系架构评审

步骤三：项目规划与实施设计
    ↓ 产出 → 信息安全体系实施规划报告
    ↓ 评审 → 实施规划评审
```

> **速记口诀**：**调架构实**（调研→架构→实施）

### 🏗 华航项目实践

| 步骤 | 华航实践 | 关键活动 |
|------|------|------|
| **步骤一：现状调研** | 2024年7-8月 | 风险评估（威胁建模+漏洞扫描）→合规差距分析（对标四部法律）→安全需求访谈（6大部门）→产出《安全现状调研与需求分析报告》→安全需求评审 |
| **步骤二：架构设计** | 2024年8-9月 | 确定等保三级基线→设计"一中三防"纵深防御架构→设计四级数据分级体系→产出《信息安全体系架构设计报告》→体系架构评审 |
| **步骤三：实施规划** | 2024年9月+ | 差距分析→安全产品选型（PaloAlto+Ceph加密+Vault）→实施路径规划（8个安全项目优先级排序）→产出《实施规划报告》→实施规划评审 |

> **考点提示**：首考2道选择题都考了"规划评审内容不包括什么"——三阶段评审分别是安全需求评审、体系架构评审、实施规划评审，**不包括等级保护评审**和**安全实现评审**。这个点2026年大概率继续出。
