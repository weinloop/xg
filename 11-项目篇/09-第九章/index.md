## 项目核心数据速查（安全视角）

| 维度 | 关键数据 |
|------|---------|
| **安全等级** | 等保三级（监督保护级） |
| **安全架构** | 「管理体系+技术体系+运营体系」三位一体 |
| **数据分级** | 四级：公开/内部/敏感/机密，含ABAC动态脱敏 |
| **合规体系** | 四部法律对标：《网络安全法》《数据安全法》《个保法》+民航局数据管理规范 |
| **安全技术** | 7大核心技术全覆盖：身份认证/访问控制/入侵检测/防火墙/网闸/防病毒/加密 |
| **SLA** | 99.99%可用性，RTO≤15分钟，RPO≤5分钟 |
| **年度预算** | 安全专项投入约85万/年（约占合同总额15%） |
