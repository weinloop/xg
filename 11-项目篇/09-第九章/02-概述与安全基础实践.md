# 02 · 概述与安全基础实践（教材9.1）

> 教材9.1是本章的知识底座——五大属性、17种威胁、七大原则、四项注意事项。本节用华航项目的真实场景，让每个概念都有落脚点。

## 9.1.1 信息安全的定义与五大基本属性

### 📖 教材知识点

**信息安全**：信息系统（硬件、软件、数据、人、物理环境及基础设施）受到保护，不受偶然或恶意原因破坏、更改、泄露，系统连续可靠运行，信息服务不中断，最终实现业务连续性。

**五大基本属性（CIA++）**：

| 属性 | 定义 | 口诀 |
|------|------|:---:|
| **保密性** | 保证信息为授权者享用而不泄露给未授权者 | **保** |
| **完整性** | 传送过程中没有被非法添加、删除、替换 | **完** |
| **可用性** | 随时为授权者提供服务，不被不合理拒绝 | **用** |
| **可控性** | 管理者能对信息实施必要的控制管理 | **控** |
| **不可否认性** | 人们要为自己的信息行为负责，提供公证仲裁信息证据 | **否** |

> **速记口诀：保完用控否**

### 🏗 华航项目实践

| 属性 | 华航场景 | 具体措施 |
|------|------|------|
| **保密性** | 旅客个人信息不能泄露给无关人员 | ABAC动态脱敏：乘务组见完整数据，地服仅见后四位 |
| **完整性** | 航班维修记录不能被篡改 | 写操作全部上链存证（区块链审计日志），修改留痕 |
| **可用性** | 平台99.99%可用，航班调度不能中断 | 北京-南京主备双活，RTO≤15分钟 |
| **可控性** | 管理员能对数据访问实施必要管控 | 四级分级授权+最小特权+操作全程审计 |
| **不可否认性** | 操作日志不可抵赖，支撑安全审计 | PKI数字签名+操作日志不可篡改时间戳 |

> **考点提示**：五大属性是本章基础中的基础，选择题必考1-2题。重点记每个属性的**关键词**：授权享用（保密）/未添加删除替换（完整）/随时不被拒绝（可用）/管理者控制（可控）/为自己行为负责（不可否认）。

## 9.1.2 信息安全面临的威胁（17种）

### 📖 教材知识点

**六大系统威胁来源**：物理环境、通信链路、网络系统、操作系统、应用系统、管理系统。

**常见安全威胁（17种）**：

| 编号 | 威胁名称 | 关键特征 | 教材举例 |
|:---:|------|------|------|
| 1 | 信息泄露 | 非授权实体获取信息 | 数据库被拖库 |
| 2 | 破坏完整性 | 数据被非授权增删修改 | 交易记录被篡改 |
| 3 | 拒绝服务 | 合法访问被无条件阻止 | DDoS攻击 |
| 4 | 非法使用 | 以非授权方式使用资源 | 越权查询数据 |
| 5 | 窃听 | 窃取传输中的信息 | 线路搭线监听 |
| 6 | 业务流分析 | 统计分析发现规律 | 分析通信频率推断业务 |
| 7 | 假冒 | 冒充合法用户 | 黑客盗用密码登录 |
| 8 | 旁路控制 | 利用系统缺陷绕过防线 | 发现暴露的"特性"入侵 |
| 9 | 授权侵犯 | 被授权者用于非授权目的 | 内部员工倒卖数据 |
| 10 | 特洛伊木马 | 看似无害程序含破坏功能 | 伪装成正常软件的病毒 |
| 11 | 陷阱门 | 特定输入触发违反安全策略 | 系统后门 |
| 12 | 抵赖 | 否认自己发布的消息 | 伪造对方来信 |
| 13 | 重放 | 截获合法通信重新发送 | 重放登录请求 |
| 14 | 计算机病毒 | 传染+侵害功能程序 | 勒索病毒 |
| 15 | 人员渎职 | 为利益或粗心泄露信息 | 泄露客户数据 |
| 16 | 媒体废弃 | 从废弃介质获取信息 | 从丢弃硬盘恢复数据 |
| 17 | 物理侵入 | 绕过物理控制访问系统 | 潜入机房 |
| — | 窃取 | 重要安全物品被盗 | 令牌/身份卡被盗 |
| — | 业务欺骗 | 伪系统欺骗合法用户 | 钓鱼网站 |

> **速记口诀**：**泄完拒非，听流假旁，侵马门赖，放毒渎废，侵窃欺**

### 🏗 华航项目威胁场景

2024年8月安全风险评估中，我们识别出华航项目面临的六大类威胁：

| 威胁来源 | 华航具体场景 | 优先级 |
|------|------|:---:|
| **物理环境** | 北京机房双路市电中断导致服务停摆 | 🔴高 |
| **通信链路** | 专线被中间人攻击窃听传输中的旅客数据 | 🟡中 |
| **网络系统** | DDoS攻击导致Portal不可用 | 🔴高 |
| **操作系统** | 容器镜像被植入后门，K8s节点沦陷 | 🟡中 |
| **应用系统** | SQL注入窃取数据库中的旅客隐私 | 🔴高 |
| **管理系统** | 运维人员因粗心将数据库备份上传到公开存储 | 🔴高 |

> **考点提示**：17种威胁不要求全部背下，但要能区分几组易混概念：①非法使用 vs 授权侵犯（前者"非授权的方式"，后者"被授权但用于非授权目的"）②旁路控制 vs 陷阱门（前者利用已知缺陷，后者特定输入触发）③重放 vs 抵赖（前者技术攻击，后者用户行为）。

## 9.1.3 信息安全规划的七大原则

### 📖 教材知识点

| 原则 | 核心要义 | 关键表述 |
|------|------|------|
| **系统性** | 横向到边，纵向到底，多层纵深防护 | 物理→网络→主机→应用→数据 五层 |
| **适用性** | 上承信息化保障，下启运维日常，横向衔接多管理体系 | 与企业文化、信息化、合规等融合衔接 |
| **时效性** | 短期（方案性）/中长期（1-3年体系化）/远景（3年+战略性） | 不同时间跨度对应不同规划深度 |
| **确定性** | 明确无歧义，不放大缩小，有明确主体和执行对象 | 不能模棱两可、不能推诿 |
| **可行性** | 可指导、可落地，结合实际情况和文化 | 不能与企业文化相违背、不与现有流程冲突 |
| **易用性** | 决策层抓方向；管理层掌全面；执行层照章办事 | 最好有"傻瓜式"流程和操作单 |
| **合规性** | 满足法律法规、国标、行业监管、内部管控制度 | 同类项合并形成整合框架 |

> **速记口诀**：**系适时确，可易合**
> 也可拆开记：系统→适用→时效→确定→可行→易用→合规

### 🏗 华航项目实践

| 原则 | 华航落地实践 |
|------|------|
| **系统性** | 安全规划覆盖全部120+套源系统的接入安全+7大模块的应用安全+混合云基础设施安全+数据全生命周期安全，形成"五层纵深防御" |
| **适用性** | 安全规划与华航已有ITIL运维流程、ISO 9001质量管理体系、内部审计制度充分衔接，不是另起炉灶 |
| **时效性** | 短期：等保三级合规（2024年Q4）；中期：ISO 27001认证（2025年Q2）；远景：智能安全运营（2026年+） |
| **确定性** | 每项安全控制措施都明确了责任主体（安全运维组）、执行对象（具体系统模块）、完成标准（如"高危漏洞7天修复"） |
| **可行性** | 安全措施的强度分级设计：核心系统严格管控，一般查询简化流程，避免"为了安全把系统用到无法工作" |
| **易用性** | 决策层看安全KPI仪表板（风险评分/合规率/事件趋势）；管理员有标准化SOP手册；业务人员只需记住"敏感数据不截屏" |
| **合规性** | 对标《网络安全法》《数据安全法》《个保法》+民航局规范+等保三级，四部法规整合为一个合规检查清单 |

> **考点提示**：七大原则考过选择题，重点区分：①系统性 vs 适用性（前者对内全面，后者对外衔接）②可行性 vs 易用性（前者能否做，后者好不好用）③确定性 vs 合规性（前者表述明确，后者满足法规）。

## 9.1.4 信息安全规划的注意事项

### 📖 教材知识点

| 注意事项 | 核心内容 |
|------|------|
| **1. 追求高效益的安全** | 信息安全不是"为了安全而安全"，要围绕业务展开，带来直接或间接经济效益 |
| **2. 信息安全战略的校准** | 组织战略 → IT战略 + 信息安全战略，三者需保持一致 |
| **3. 基于业务的风险理解** | 关键风险区域（识别→分析→应对→监控→沟通→应急→审计七步）+ 风险偏好 |
| **4. 识别出合规性要求** | 外部合规（法律法规）+ 内部合规（企业制度一致） |

> 💡 **核心论断**：对于信息系统——制度随着技术跑；对于信息安全——技术随着制度跑。

> **速记口诀**：**益校险规**

### 🏗 华航项目实践

**1. 高效益安全**

华航安全管理层最初对85万/年安全投入有疑虑。我们做了ROI分析：

| 安全投入 | 避免的损失 |
|------|------|
| 等保三级建设 35万 | 民航局不合规罚款50-100万 + 停业整改 |
| 数据脱敏系统 20万 | 旅客隐私泄露诉讼 + 品牌损失（参照同行案例≥200万） |
| SOC运营中心 30万 | 安全事件平均MTTD从48小时缩短至30分钟 |

> 「安全不直接赚钱，但一次泄露可以毁掉一个品牌。」——这句话最终说服了管理层。

**2. 战略校准**

华航集团2024年战略关键词是"数字化转型"。信息安全战略必须与之保持一致：
- 组织战略：建设行业领先的数字化运营能力 → 安全战略：等保三级+ISO 27001认证
- IT战略：混合云+微服务架构 → 安全战略：纵深防御+零信任架构

**3. 基于业务的风险理解**

我们对华航120余套业务系统进行了风险影响评估：
- **关键风险区域**：旅客服务系统（PSS）、航班运行系统（FOC）、航空器维修系统——中断1小时损失≥200万
- **风险偏好**：管理层属于"风险厌恶型"（民航业特性），宁可多投入也要确保安全

**4. 合规性要求**

2024年11月民航局数据管理专项检查前，我们逐项梳理合规差距，发现旅客行程数据留存期限不符合"180天"要求，一周内调整策略并补充审计日志，顺利通过检查。

> **考点提示**："技术随着制度跑"是教材核心论断，选择题中容易出现。注意与信息系统相反的逻辑——信息安全是先定制度（要解决什么问题），再决定用什么手段（IT系统或制度）。
