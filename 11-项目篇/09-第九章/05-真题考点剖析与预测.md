## 一、首考真题第九章考点清单

### 2025年11月首考第九章考题

#### 选择题第4题（易错题）

```
信息安全规划评审内容不包括（）。
A. 等级保护      B. 安全实现      C. 安全体系      D. 安全需求
```

**答案**：B（安全实现）

**教材对应位置**：9.4 规划案例 —— 三阶段评审：
1. 安全需求评审（步骤一）
2. 体系架构评审（步骤二）
3. 实施规划评审（步骤三）

**不含**：等级保护评审、安全实现评审。

#### 选择题第25题（相似考点）

```
信息安全规划过程中的评审内容不包括（）。
A. 体系架构评审    B. 安全需求评审    C. 实施规划评审    D. 等级保护评审
```

**答案**：D（等级保护评审）

**分析**：两道题考点完全相同！说明出卷老师非常重视这个知识点。三阶段评审 = 安全需求评审 + 体系架构评审 + 实施规划评审。不含等级保护评审、安全实现评审。

## 三、易混概念对照表（选择题必看）

| 概念对 | 区别关键 |
|------|------|
| **保密性 vs 完整性** | 保密=不被看到（泄露）；完整=不被改（篡改） |
| **可控性 vs 不可否认性** | 可控=管理者能管控；不可否认=使用者要负责 |
| **非法使用 vs 授权侵犯** | 前者"非授权的方式"，后者"被授权但滥用" |
| **旁路控制 vs 陷阱门** | 前者利用已知缺陷绕过，后者特定输入触发 |
| **重放 vs 抵赖** | 前者截获合法数据重发（技术），后者否认自己行为（人） |
| **适用性 vs 可行性** | 前=能不能融入环境，后=能不能落地执行 |
| **确定性 vs 合规性** | 前=表述明确不歧义，后=满足法规要求 |
| **RBAC vs Rule-BAC** | 前=基于角色身份，后=基于规则条件 |
| **DAC vs MAC** | 前=所有者自主决定，后=系统强制标签管控 |
| **因需可知 vs 最小特权** | 前=我能看什么（数据范围），后=我能做什么（操作权限） |
| **岗位轮换 vs 强制休假** | 前=计划性轮岗，后=突然强制 |
| **对称加密 vs 非对称加密** | 前=同密钥快但分发难，后=公私钥慢但管理简单 |

### 案例题（预计0-1题，概率中等）

**可能出题方式**：给一个组织的安全现状描述，要求：
1. 指出存在的安全问题
2. 建议安全规划改进措施

**答题框架**：按「诉织管技运」五方面逐一分析：
- 利益相关方诉求是否被倾听？
- 组织体系是否健全（最协内外）？
- 管理体系是否覆盖等保/ISO 27001？
- 技术体系是否有遗漏（7大技术对照）？
- 运营体系是否有应急响应+培训？
