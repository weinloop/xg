## 三、必考概念对比表

### 👉 易混概念组1：SOP vs 技术手册 vs 服务规范

| 概念 | 是什么 | 关注点 | 典型内容 |
|------|------|------|------|
| SOP | 操作步骤的标准描述 | **怎么操作**（How） | 主从切换6步操作法 |
| 技术手册 | 发现和解决问题的技术文档 | **怎么发现问题+怎么解决**（What+How） | 监控阈值配置 + 故障排查步骤 |
| 服务规范 | 服务应达到的水准和要求 | **应达到什么水准**（What） | SLA指标（可用性≥99.99%） |
| 服务提供规范 | 提供服务的具体方法和手段 | **怎么达到规范要求**（How） | 操作规程、技术操作手册 |

### 👉 易混概念组2：四种知识产权快速区分

| 描述 | 答案 |
|------|:---:|
| 「我发明了一种新的数据压缩算法」 | **专利权** |
| 「这是我们公司的Logo和品牌名称」 | **商标权** |
| 「这是我写的软件源代码」 | **著作权** |
| 「公司内部的客户名单和定价策略」 | **商业秘密** |
| 「我画了一张系统架构图」 | **著作权** |
| 「我们研发的配方从不对外公开」 | **商业秘密** |

### 👉 易混概念组3：服务产品 vs 服务规范 vs 服务工具研发

| 研发类型 | 面向对象 | 核心产出 |
|:---:|------|------|
| 服务产品研发 | 面向需方 | 服务目录 + 交付方式 + 质量管理 |
| 服务规范研发 | 面向内部 | 工作指南 + 过程规范 + 技术手册 |
| 服务工具研发 | 面向运维 | 监控平台 + CI/CD + 自动化工具 |

## 五、出题规律总结

1. **「不包括什么」是经典套路**：5范围/6对象/5角色/4过程——随便抽一个正确选项替换成无关项就是一道题
2. **SOP相关是重中之重**：作用（5条）+ 编写原则（5条）+ 「最基本、最有效」的地位判断，三合一
3. **知识产权重在区分而非背诵**：不会考专利有效期几年，但一定考「这段描述属于哪种知识产权」
4. **与第12章的关联**：技术研发成果（工具/SOP）是第12章设计实现的资源要素，组合出题概率高
