## 🏗️ 项目核心数据速查

| 维度 | 数据 |
|------|------|
| 部署架构 | **核心集中+边缘分布**混合云：总部主中心（20 Worker节点）+ 华东容灾中心 + 5大区域中心边缘节点 |
| 计算资源 | 20个Worker节点（单节点16vCPU/64GB）+ 5个边缘节点 + 2个GPU推理节点 |
| 存储资源 | 50PB总容量：对象存储30PB（非结构化）+ 块存储15PB（数据库）+ 文件存储5PB（共享） |
| 网络带宽 | 总部-容灾中心 10Gbps专线，边缘节点 1Gbps接入 |
| SLA目标 | 99.99%可用性，RTO ≤ 15分钟，RPO ≤ 5分钟 |
| 并发能力 | 峰值5000并发，日均10亿次API调用 |
| 服务模式 | IaaS（基础设施层）+ PaaS（容器云平台）+ SaaS（7大功能模块） |

## 🔑 核心口诀速览

| 知识点 | 口诀 | 解释 |
|--------|------|------|
| 5大目标 | **效本展靠需** | 效率/成本/扩展/可靠/需求 |
| 7大要素 | **需评预安弹优监** | 需求/评估/预算/安全/弹性/优化/监控 |
