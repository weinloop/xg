## 四、案例计算题

### 【情景描述】

某企业计划将在线交易系统迁移至云端，已知以下参数：
- 高峰期QPS：3000请求/秒
- 平均单请求CPU耗时：150毫秒
- 冗余系数：1.4
- 单实例配置：8 vCPU
- 平均CPU利用率上限：75%

### 【问题】

**问题1**（10分）：请计算所需的总vCPU数量，并写出计算过程。

**问题2**（5分）：请计算最少需要多少个实例。

**问题3**（10分）：请列出计算资源规划的7个关键步骤，并简要说明每一步的主要内容。

### 【参考答案】

<details><summary>点击查看答案</summary>

**问题1**：

$$总vCPU = 3000(QPS) \times 0.15(秒)^{[150ms \div 1000]} \times 1.4 = 630\ vCPU$$

**问题2**：

理论实例数 = ⌈630 ÷ 8⌉ = ⌈78.75⌉ = 79个

考虑75%的CPU利用率上限：实际实例数 = ⌈79 ÷ 0.75⌉ = ⌈105.33⌉ = 106个

**问题3**（7个关键步骤）：

| 步骤 | 主要内容 |
|:---:|------|
| ①需求分析 | 了解应用工作负载需求（CPU/内存/存储/带宽），通过性能测试和基准测试完成 |
| ②容量规划 | 基于需求分析，确定所需计算资源容量（工作负载数量、所需资源量） |
| ③云服务选择 | 根据需求和容量规划，选择合适的云服务（IaaS/PaaS/SaaS） |
| ④虚拟化策略 | 考虑是否采用虚拟化技术提高计算资源利用率 |
| ⑤安全性考虑 | 数据加密、访问控制、安全审计等 |
| ⑥成本效益分析 | 比较不同方案的成本和效益，确定最优方案 |
| ⑦持续监控和维护 | 监控资源使用、检测性能瓶颈、定期维护更新 |

</details>
