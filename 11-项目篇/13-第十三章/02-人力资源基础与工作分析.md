# 02 · 人力资源基础与工作分析（教材13.1+13.2）

> 这是人员管理的「地基」——先搞清楚管什么（五大环节），再搞清楚每个岗位到底是什么（工作分析），最后设计出合理的岗位。

---

## 13.1 人力资源管理基础

### 五大环节 —「规聘维升评」

人力资源管理的核心是五个环节，构成完整闭环：

```
规划 ──→ 招聘 ──→ 维护 ──→ 提升 ──→ 评价
  ↑                                      │
  └──────────────────────────────────────┘
              （反馈循环）
```

| 环节 | 教材定义 | 华航项目实践 |
|:---:|------|------|
| **规划** | 确认工作要求，确定人员容量与技术需求 | 2024年7月，基于平台一期主题域规模+二期扩展计划，用转换比率法估算：需增4数据工程师+2数据分析师 |
| **招聘** | 确定最合适人选的过程 | 2024年8-9月：内推+网招补3运维，猎头锁定1架构师，校园招聘补2分析岗，临时雇员做数据标注 |
| **维护** | 维护员工积极性，管理薪酬与安全健康 | 基于能力的薪酬体系，数据工程师按SQL/Spark/建模三技能分级定薪；A/B角轮岗保障工作安全 |
| **提升** | 提高知识、技能和经验 | 数据管家40小时认证培训，工程师「数据+业务」双向培训（跟班运控学航空知识） |
| **评价** | 观察、测量和评估工作结果 | BARS行为锚定评价法，季度考核+月度回顾+反馈面谈 |

### 两大目标

| 目标 | 含义 | 华航体现 |
|------|------|------|
| **广义目标** | 充分利用组织中的人员使各项工作效率水平达到最高 | 12人支撑120+系统数据接入、10万目录、日均10亿调用 |
| **狭义目标** | 帮助各团队负责人更加有效地管理团队成员 | PM李姐通过BARS+月度面谈，使团队满意度从65%提升至92% |

> **考点提示**：广义目标=组织层面效率最大化；狭义目标=管理者层面团队管理有效化。

## 13.2 工作分析与岗位设计

### 13.2.1 工作分析

#### 工作分析的四大作用 —「聘评薪岗」

| 作用 | 教材说明 | 华航实践 |
|:---:|------|------|
| **招聘和选择** | 明确工作要求是有效招聘的前提 | 数据架构师岗位明确了「10年数据经验+航空行业背景」，猎头精准匹配 |
| **发展和评价** | 工作说明书指明培训方向+绩效标准 | 数据工程师的工作说明书列出了SQL/Spark/数据建模三项核心技能→据此设计培训 |
| **薪酬政策** | 确定工作对组织价值的贡献排序 | 通过对8类岗位的工作分析，确定数据架构师>数据工程师>数据管家的薪酬梯次 |
| **组织和岗位设计** | 明确工作间关系，消除盲点减少重复 | 发现数据管家与运维工程师在「系统巡检」上职责重叠→明确归属运维 |

#### 四阶段十步骤 —「围法集评」

```
第一阶段：明确范围    第二阶段：确定方法    第三阶段：收集分析    第四阶段：评价
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│1.确立目的     │    │4.识别信息来源 │    │6.收集工作信息 │    │9.定期检查    │
│2.确定对象     │ →  │5.明确具体步骤 │ →  │7.分析所收集   │ →  │10.评价结果   │
│3.确定信息类型 │    │              │    │   信息        │    │(收益/成本/   │
│              │    │              │    │8.报告结果    │    │ 合规/合法)   │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

#### 核心流程四步骤 —「象人书评」

| 步骤 | 内容 | 华航实践 |
|:---:|------|------|
| ① 明确对象 | 选哪些岗位做工作分析 | 优先选8个核心岗位（影响大、完成难度高、内容变化快） |
| ② 选择人员 | 谁来收集信息 | 架构师岗→专家（客观）+ 数据管家岗→主管（了解深入）+ 运维岗→任职者（熟悉） |
| ③ 编制说明书 | 工作描述+工作规范 | 每岗一份《工作说明书》，含工作设定/工作定义/工作说明+任职资格 |
| ④ 评价分析 | 可靠性+有效性 | 不同分析人员结果一致性>85%，验证有效 |

#### 三类信息收集人员对比

| 类型 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|
| **工作分析专家** | 最客观公正、方法科学、保持一致性 | 成本高、可能忽略无形方面 | 关键重要工作（如数据架构师） |
| **主管人员** | 全面深入了解、速度快 | 需培训、时间负担重、客观性存疑 | 新工作或变动工作（如数据管家） |
| **典型任职者** | 最熟悉工作、速度快 | 标准化差、完整性差 | 相对成熟工作（如平台运维） |

#### 八种工作分析方法

**定性方法（5种）**：

| 方法 | 要点 | 优点 | 缺点 | 华航使用 |
|------|------|------|------|:---:|
| **工作实践法** | 分析人员亲自干 | 准确了解实际要求 | 不适用于需大量训练/危险工作 | ❌ |
| **直接观察法** | 观察工作过程记录 | 全面深入了解 | 不适用于脑力劳动/间歇性工作 | ❌ |
| **面谈法** | 与工作承担者面谈 | 简单迅速、适用面广、发现隐藏问题 | 员工可能夸大难度（误解为变相考核） | ✅ 访谈小赵 |
| **问卷法** | 结构化问卷填写 | 省时省力、样本大、可量化 | 设计耗时、填写质量难保证 | ✅ 团队问卷 |
| **典型事例法** | 积累有效/无效行为描述 | 揭示工作动态性质 | 耗时、难以形成总体概念 | ✅ 收集关键事件 |

**定量方法（3种）**：

| 方法 | 要点 | 华航使用 |
|------|------|:---:|
| **职位分析问卷法（PAQ）** | 6部分、6分制主观评分（信息来源→智力活动→产出→人际关系→环境→其他特征） | ✅ 简化版（太繁重） |
| **管理岗位描述问卷法** | 208问题/13类别，管理人员自填，6分制 | ❌ |
| **功能性工作分析法** | 数据/人/事三要素打分，数值越小等级越高 | ❌ |

> **记忆口诀**：定性5法 — **实观面卷例**（实践/观察/面谈/问卷/典型事例）
> 定量3法 — **职管功**（职位分析问卷/管理岗位问卷/功能性）

### 13.2.2 岗位设计

#### 三大内容 —「容责系」

| 内容 | 核心维度 | 华航实践 |
|------|------|------|
| **工作内容设计** | 广度/深度/完整性/自主性/反馈性 | 数据管家原来5维度全超标→剥离运维→保留治理+培训+巡检 |
| **工作职责设计** | 责任/权利/方法/沟通 | A/B角轮岗制度化，确保责任不落空 |
| **工作关系设计** | 协作/监督/汇报 | 数据管家直接汇报给质量专员，虚线汇报区域IT负责人 |

#### 四种岗位设计方法

| 方法 | 核心理念 | 适用场景 |
|------|------|------|
| **科学管理方法** | 「时间-动作」研究，工作简单化标准化 | 重复性操作岗位（如ETL调度监控） |
| **人际关系方法** | 工作扩大化/工作轮调/工作丰富化 | 数据工程师定期轮换主题域 |
| **工作特征模型** | 5核心维度→3心理状态→个人/工作结果 | 拆分数据管家职责后按模型重构 |
| **高绩效工作体系** | 科学管理+人际关系结合，小组自主决策 | 5大区域数据管家组成虚拟团队自治 |

> **考点提示**：高绩效工作体系 = 科学管理 + 人际关系，适合扁平化和网络化组织。

#### 工作特征模型（赫茨伯格）

```
5个核心维度               3种心理状态            个人和工作结果
────────────────────────────────────────────────────────
技能多样性  ──→
任务完整性  ──→  感受到工作的意义    ──→  高内在工作动力
任务意义    ──→                         高质量工作绩效
                                       高工作满意度
自主性      ──→  感受到工作结果的责任  ──→  低缺勤率和离职率
反馈性      ──→  了解工作结果
```

> **华航实践**：数据工程师原来的工作只有「技能多样性」满足（写ETL/调Spark/搭模型），但「任务完整性」差（只做中间一段，看不到主题域全貌）。通过让工程师端到端负责一个主题域（从需求到上线到运营），4维度显著改善→离职率从40%降至10%。
