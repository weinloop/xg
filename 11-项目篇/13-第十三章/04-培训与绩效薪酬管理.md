# 04 · 培训与绩效薪酬管理（教材13.5+13.6+13.7）

> 人招进来了，下一步：怎么让他们长本事（培训）？怎么评价他们干得好不好（绩效）？怎么给钱让他们愿意留下（薪酬）？怎么让他们看到未来（职业规划）？

---

## 13.5 人员培训

### 培训类型

| 类型 | 特点 | 华航实践 |
|------|------|------|
| **入职培训** | 介绍组织政策/规定/福利 | 每位新员工3天集中入职培训 |
| **员工在职培训** | 节约成本、绩效反馈快 | 数据管家40h认证培训 + 工程师跟班运控学航空业务 |

### 培训四步骤 —「需标项施」

```
需求评估 ──→ 目标设定 ──→ 项目设计 ──→ 实施与评估
```

| 步骤 | 华航实践 |
|------|------|
| ① 需求评估 | 平台二期数据治理能力不足 → 需培训数据管家 |
| ② 目标设定 | 认证考试≥80分、独立完成区域数据标准落地 |
| ③ 项目设计 | 40h混合培训：理论20h+实操15h+考核5h |
| ④ 实施评估 | 首批5人参训，1人未通过→跟岗2周→补考通过 |

### 培训内容分析三层面

| 层面 | 内容 | 华航分析 |
|------|------|------|
| **组织分析** | 组织战略需要什么能力 | 集团要做数据资产化→团队需数据治理能力 |
| **绩效分析** | 员工当前能力差距 | 小赵ETL做得好，但缺业务理解 |
| **任务分析** | 完成具体任务需什么知识技能 | 新工程师需补航空业务知识（航班/旅客/航材） |

### 培训效果评估四层次（柯氏四级） —「反应学为果」

| 层次 | 评估内容 | 华航评估方式 |
|:---:|------|------|
| **反应** | 学员对培训的满意度 | 培训后问卷（平均4.2/5） |
| **学习效果** | 知识/技能掌握程度 | 认证考试（80分及格线） |
| **行为变化** | 培训后工作行为是否改变 | 跟岗2周观察+主管评价 |
| **培训效果** | 对业务结果的影响 | 培训后区域数据质量问题减少60% |

> 🔥 这是一个递进层次模型——越往后越难评估，但越接近培训的真正价值。

### 培训迁移模型

**鲍德温和福特模型**：培训输入（受训者特征+培训设计+工作环境）→ 影响学习、保存和迁移。

> 华航实践：我们不仅关注培训内容，还改变了「工作环境」——给每个数据管家配备导师，建立培训后90天跟踪计划——确保学到的知识真正迁移到工作中。

## 13.6 组织绩效与薪酬管理

### 绩效管理循环四环节 —「划施核谈」

```
绩效计划 ──→ 实施与监控 ──→ 绩效考核 ──→ 反馈面谈
    ↑                                          │
    └──────────────────────────────────────────┘
```

| 环节 | 华航实践 |
|------|------|
| **绩效计划** | 每季度初与每位员工设定3-5个OKR目标 |
| **实施监控** | 月度1对1回顾进展，及时调整 |
| **绩效考核** | BARS行为锚定法，8类角色分别制定锚定等级表 |
| **反馈面谈** | 季度末30分钟面谈：肯定成绩+指出改进+下季计划 |

### 五种绩效考核方法

| 方法 | 核心做法 | 优缺点 |
|------|------|------|
| **员工比较类评价法** | 简单排序/成对比较/**强制分布** | 简单直观 / 可能引发不公感 |
| **关键事件法** | 记录有效/无效行为的典型事例 | 具体可追溯 / 耗时 |
| **行为对照表法** | 对照事先列出的行为描述逐项勾选 | 标准化 / 可能遗漏个性化表现 |
| **等级鉴定法** | 对各维度打分（如1-5分） | 灵活 / 主观性强 |
| **行为锚定评价法（BARS）** ⭐ | 每项指标都有具体行为描述作为评分参照 | 客观公正 / 设计成本高 |

> **华航选择BARS的原因**：数据团队8类角色差异大，用同一套标准打分会不公平。BARS为每类角色定制行为锚点，如数据工程师的「ETL准时率」有一级到五级具体行为描述（如「从不延误且主动优化」=5分，「经常延误且未提前沟通」=1分）。

### 绩效改进三步骤 —「析案施」

分析绩效考核结果→制定改进方案→实施。

---

### 薪酬体系（2类3种）

```
薪酬体系
├── 基于职位的薪酬体系：按岗位价值定薪
└── 基于任职者的薪酬体系
    ├── 技能薪酬体系：按所掌握的技能
    └── 能力薪酬体系：按所具备的能力
```

| 体系 | 华航应用 |
|------|------|
| 基于职位 | 项目经理、安全专员（岗位职责清晰稳定） |
| 基于技能 | 数据工程师按SQL/Spark/数据建模三级递进加薪 |
| 基于能力 | 数据管家按独立负责区域数量和能力定级 |

### 五种工作评价方法 —「排比类点海」

| 方法 | 做法 |
|------|------|
| **工作排序法** | 按工作对组织的相对价值排序 |
| **因素比较法** | 把工作分解为多个报酬因素后比较 |
| **工作分类法** | 预先制定等级标准，把工作归入不同等级 |
| **点数法** | 对各项报酬因素打分，加总确定薪酬 ⭐ |
| **海氏系统法** | 用知识技能/解决问题/应负责任三维度评价 ⭐ |

### 薪酬等级结构五要素 —「等标差幅叠」

| 要素 | 含义 |
|:---:|------|
| **等**级数 | 薪酬分多少个等级 |
| 目**标**薪酬 | 每个等级的中点薪酬 |
| 薪酬级**差** | 相邻等级目标薪酬的差距 |
| 薪酬**幅**度 | 同一等级内最高与最低薪酬的范围 |
| 薪酬**叠**情况 | 相邻等级薪酬范围是否重叠 |

### 分人群薪酬激励

| 人群 | 激励方式 |
|------|------|
| 操作人员 | 计件制 |
| 销售人员 | 佣金制/底薪制 |
| 专业技术人员 | 加薪+非金钱激励（培训/项目署名/技术大会） |
| 高级管理人员 | 5部分：基本薪酬+短期奖金+长期奖励+雇员福利+特殊津贴 |

## 13.7 人员职业规划与管理

### 职业道路设计

- **组织责任**：提供发展通道、晋升机会、轮岗机制
- **管理人员责任**：辅导下属、发现潜力、推荐机会
- **员工责任**：自我评估、主动学习、把握机会

> **华航实践**：我们设计了双通道职业路径——管理通道（数据管家→质量专员→项目经理）和技术通道（数据工程师→高级工程师→数据架构师），让技术人员不必转管理也能有上升空间。
