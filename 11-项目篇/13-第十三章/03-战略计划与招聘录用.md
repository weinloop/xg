# 03 · 战略计划与招聘录用（教材13.3+13.4）

> 岗位定义清楚了，接下来两个核心问题：组织需要什么样的人力资源战略？以及，怎么把合适的人招进来？

---

## 13.3 人力资源战略与计划

### 13.3.1 人力资源战略

#### 战略性人力资源管理过程

```
组织目标 ──→ 战略选择 ──→ 人力资源管理 ──→ 结果评估
              ↑                │                  │
         组织文化            ┌─┴──────────┐        │
                            │ 人力配置    │        │
                            │ 招聘       │ ───→ 人力绩效
                            │ 工作设计   │      组织绩效
                            │ 培训开发   │      财务绩效
                            │ 绩效管理   │
                            │ 薪酬福利   │
                            └────────────┘
```

#### 两种战略分类体系（核心对比）

这是本章最容易混淆的知识点——**两个分类体系，各有三种模式**：

**体系一：戴尔（Dyer）和霍德（Holder）**

| 战略 | 核心特征 | 适用场景 | 华航实践 |
|------|------|------|------|
| **诱因战略** | 高薪留人、纯利益交换、严控成本、绩效薪酬占比大 | 稳定环境、技能高度专业化 | 不适合（数据人才需培养） |
| **投资战略** | 长期雇佣观、雇多于需要、重视培训、鼓励创新、宽松环境 | 成长期/变化环境 | ✅ 主战略（培养稀缺数据人才、数据管家40h培训） |
| **参与战略** | 权力下放、员工参与决策、管理者是教练、注重自我管理和团队 | 创新型组织 | ✅ 辅战略（区域数据管家团队自治、A/B角轮岗） |

> 记忆口诀：**诱投参** —「诱饵」高薪诱惑、「投资」长期培养、「参与」全员决策

**体系二：巴伦（Baron）和克雷普斯（Kreps）**

| 战略 | 核心特征 | 华航实践 |
|------|------|:---:|
| **内部劳动力市场战略** | 层级分明、内部晋升为主（除初级岗）、鼓励长期效力 | 核心岗（数据架构师/数据工程师）内部培养晋升 |
| **高承诺战略** | 扁平化团队、一定流动率获取新知、薪酬体现成果差别 | 部分岗位（数据分析师）外部引进新鲜血液 |
| **混合战略** | 结合两者：有工作保障+内部晋升+基于成果的绩效薪酬 | ✅ 总体采用混合战略 |

> 记忆口诀：**内高混** —「内」部培养、「高」承诺产出、「混」合两者

> 🔥 **考点陷阱**：「高承诺战略」≠ 高员工承诺，而是高产出承诺！它允许一定员工流动率来获取新的知识。

### 13.3.2 人力资源预测

#### 需求预测3法 —「集回转」

| 方法 | 要点 | 适用场景 | 华航实践 |
|------|------|------|------|
| **集体预测法（德尔菲）** | 专家匿名多轮反馈至意见趋同 | 长期趋势预测 | 邀请3位航空数据专家+2位HR专家做3年需求预测 |
| **回归分析法** | 数学回归/趋势分析/计量模型 | 有历史数据的常规预测 | 根据过去3年航空数据量增长趋势预测人力 |
| **转换比率分析法** | 先估关键技能员工数→再估辅助人员 | 快速估算 | 按主题域数量÷人均承载=缺4工程师+2分析师 |

#### 供给预测6法 —「盘图续阵息外」

| 方法 | 要点 | 华航实践 |
|------|------|:---:|
| **人才盘点与技能清单** | 3步：组织岗位盘点→人才测评→行动计划 | ✅ 全员技能盘点 |
| **管理人员置换图** | 记录各管理者绩效/晋升可能/所需培训 | ✅ 关键岗位继任计划 |
| **人力接续计划** | 根据工作要求确定候选员工 | ✅ 每个关键岗至少1名接班人 |
| **转移矩阵法（马尔可夫）** | 用转移率预测人员分布变化 | ✅ 预测分析师年流失40% |
| **人力资源信息系统** | 人事档案+需求预测 | ✅ 建立HR数据库 |
| **外部人力资源供给** | 外部市场人力供给量与特点 | ✅ 对标BAT数据人才市场 |

#### 供给需求对照三种结果

| 结果 | 应对 |
|:---:|------|
| **供需适应** ✅ | 维持现有政策 |
| **需求>供给**（短缺） | ①增加录用数量（扩源/降标/临时/退休）②提高效率（培训/重新设计/补偿/改善关系） |
| **需求<供给**（过剩） | 减少加班/鼓励退休/减少新进/合作伙伴使用/辞退（最后手段） |

> 记忆口诀：短缺→**录率**（增加录用+提高效率），过剩→**减退新借辞**

#### 人力资源计划的整体性

**三份报表**：

| 报表 | 内容 |
|:---:|------|
| **供给报表** | 每个重要员工今后若干年晋升可能性 |
| **需求报表** | 各部门因调遣/离职/新职位等需补充的职位 |
| **人力报表** | 供给+需求结合 = 实际人事计划方案 |

#### 计划评价的8个比较项 —「招效流案果费算益」

实际招聘数量vs预测需求、工作效率实际vs预测、实际流动率vs预测、执行方案vs计划、实际结果vs预期、人力费用vs预算、方案成本vs预算、成本vs收益。

## 13.4 人员招聘与录用

### 13.4.1 招聘五步骤 —「划布申选评」

```
计划制订 ──→ 信息发布 ──→ 应聘申请 ──→ 甄选录用 ──→ 评估反馈
```

#### 招聘计划7要素 —「岗布源法测预时」

| 要素 | 华航实践 |
|------|------|
| **岗**位/数量/要求 | 数据架构师1名：10年数据经验+航空背景 |
| 信息发**布**时间/方式/渠道/范围 | 2024年8月启动，猎头+Boss直聘+校招 |
| 招聘**源**与范围 | 全国范围，重点北上广深 |
| 招聘**方**法 | 笔试+工作样本法+半结构化面试 |
| **测**试实施部门 | HR部门+技术负责人联合 |
| **预**算 | 招聘预算8万（含猎头费5万） |
| 结束**时**间与新员工到位 | 2024年9月底前全部到位 |

### 13.4.2 八大招聘渠道 —「内广介猎校推网临」

| 渠道 | 特点 | 华航使用 |
|------|------|:---:|
| **内**部来源 | 公告内部岗位信息 | ✅ 运维岗优先内部转岗 |
| 招聘**广**告 | 传播快/成本低/可同时发布多岗位 | ✅ Boss直聘+拉勾 |
| 职业**介**绍机构 | 节省时间、急于填空缺时使用 | ✅ 紧急补数据治理岗 |
| **猎**头 | 搜捕高级管理/技术人员 | ✅ 锁定数据架构师 |
| **校**园招聘 | 专业技术人才重要来源 | ✅ 补数据分析师 |
| 员工**推**荐/自荐 | 省钱+忠诚可靠 | ✅ 内推奖励机制 |
| **网**络招聘 | 自建网站/第三方/社交媒体 | ✅ 日常招聘主渠道 |
| **临**时性雇员 | 4选择：内部储备/中介/自由职业/短期雇用 | ✅ 数据标注临时工 |

> 🔥 **职业介绍机构5个适用场景**：①难以吸引足够合格申请人；②只需招很少数量或不值得详设方案；③急于填补关键空缺；④试图招聘在职员工；⑤在目标市场缺乏招聘经验。

### 13.4.3 录用方法

#### 录用测试8种类型

| 类型 | 含义 |
|------|------|
| 能力测试 | 认知能力、专业能力测试 |
| 操作与身体技能测试 | 动手操作能力 |
| 人格与兴趣测试 | 性格、职业兴趣（影射法） |
| 成就测试 | 已掌握的知识技能 |
| **工作样本法** | 让应聘者现场完成一项工作任务 ⭐ |
| 测谎器法 | 测谎 |
| 笔迹判定法 | 通过笔迹判断性格 |
| 体检 | 身体健康检查 |

#### 多元选择的三种原则

| 原则 | 含义 |
|------|------|
| **补偿性原则** | 某项弱可被另一项强补偿 |
| **多元最低限制原则** | 每项都必须达到最低标准 |
| **混合原则** | 先最低限制筛选→再补偿性综合评估 |

#### 面试三类型（按结构化程度）

| 类型 | 特点 |
|------|------|
| **非结构化面试** | 没有固定格式，自由提问 |
| **结构化面试** | 所有应聘者问相同问题，标准评分 |
| **半结构化面试** | 结合两者，有框架但允许追问 ⭐ |

#### 招聘效果评估 —「期完本满录」

招聘周期、招聘完成率、招聘成本、用人部门满意率、录用人员评估。
