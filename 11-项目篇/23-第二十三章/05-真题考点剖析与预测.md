## 🔴 P0 必考考点——必须全文背诵

### 考点1：四大焦点（零网享趣）及应用辨识

**考法**：题干给一个商业场景描述，问「属于新型消费哪个关注焦点」。

**例题**：
> 某超市在店内设置智能触摸屏，消费者扫码即可查看商品溯源信息并线下取货，这体现了新型消费的哪一焦点？
> A. 互联网+服务 B. 新零售业态 C. 共享型消费 D. 兴趣消费

> ✅ 答案：B。线上线下融合+智能技术是「新零售业态」的核心特征。

### 考点2：规划要点注意事项

**考法**：直接考察7注意/5注意/4注意的完整列举或填空。

- **需**求分析7注意 → 「瞻隐景域群变具」
- 用户体**验**5注意 → 「馈引工端视」
- 精准营**销**4注意 → 「接量法据」

### 考点3：四阶段对应技术

| 阶段 | 技术 |
|------|------|
| 电子商务时代 | 互联网、B2C平台 |
| 移动互联网时代 | 3G、智能手机 |
| 智慧消费时代 | AI、大数据 |
| 深度互动阶段 | 5G、边缘计算、VR/AR |

### 考点4：安全保障5措施（密防训备监）

必须能完整列举，案例题常问「请列出新型消费系统安全保障的主要措施」。

## 🟡 P1 高频考点

### 考点5：六大技术（电付大人联X）

| 技术 | 一句话辨识 |
|------|-----------|
| 电子商务技术 | 让消费者能网上购物 |
| 移动支付技术 | NFC/二维码/近场通信 |
| 大数据技术 | 分析挖掘发现价值 |
| 人工智能技术 | 模拟人类智慧 |
| 物联网技术 | 物品互联互通 |
| XR技术 | AR+VR+MR 统称 |

### 考点6：新零售四种模式对比

| 模式 | 一句话关键词 |
|------|-------------|
| 线下变革 | 商超+餐饮（盒马） |
| 线上导流 | 从线上引到线下（小米之家） |
| 一体化 | 大数据驱动推荐 |
| 无人零售 | 自助化+智能化+安全+便捷 |

### 考点7：关键要素四大目标（导活现营）

- **导**流——获客：数据收集→客户识别→精准投放→效果评估
- **活**客——促活：裂变推荐→私域流量池→触点矩阵
- **现**金——变现：家店一体→全渠道带货
- **营**运——精准：会员分层→管理/营销/供应链赋能→数据驱动

1. **场景辨识型**：给一段企业转型材料，要求识别体现了哪些新型消费焦点/特征
