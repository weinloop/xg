# 04 信息系统架构

> 📍 覆盖教材 19.4（信息系统架构）。智慧园区架构与第18章智慧城市类似，本章重点掌握应用架构7大系统、数据架构三层模型、交互体系的统一门户。技术架构和安全架构参见18.4节。

---

## 一、架构总览

智慧园区总体参考架构（图19-2）的三层结构：

```
┌─────────────────────────────────────────────┐
│         智慧园区驾驶舱 + 服务门户              │  ← 展示层
├─────────────────────────────────────────────┤
│  管理服务场景 │ 绿色低碳场景 │ 运维运营场景    │  ← 场景应用层
├─────────────────────────────────────────────┤
│  数据中台 + 能力中台                          │  ← 平台层
│  (服务平台 + 虚拟化平台)                       │
├─────────────────────────────────────────────┤
│  网：园区专线/光纤/WiFi/5G                     │  ← 网络层
│  端：物联感知终端 + 网关平台接入               │  ← 感知层
└─────────────────────────────────────────────┘
```

> 💡 智慧园区的**技术架构、安全架构**与智慧城市内容类似，参见18.4节，本章不重复展开。

## 第二部分：19.4.1 应用架构（7大系统）

> 🧠 **七系统口诀**：**安通设资能环营** — 综合安防→便捷通行→设施管理→资产管理→能耗管理→环境管理→智能运营中心

### 2.1 综合安防

| 要素 | 内容 |
|------|------|
| **定位** | 创建园区"情境智能"整体解决方案 |
| **核心能力** | 实时准确的情境意识，先进安防集成 |
| **技术手段** | 融合不同类型实时传感器和数据采集子系统 |
| **运行模式** | 固定/移动多模式，适应各种环境条件 |

### 2.2 便捷通行

| 维度 | 核心内容 |
|------|------|
| **两大目标** | ①人员体验提升（员工/访客） ②管理效率改进（物业/运营） |
| **系统联动** | 门禁+闸机+访客+一卡通 → 打通联动 |
| **平台支撑** | 大数据/IoT/视频调阅/GIS |
| **四项能力** | 人员无感进出 + 人流统计 + 轨迹查询 + 高效运营 |

### 2.3 设施管理

| 功能 | 说明 |
|------|------|
| 设备运行数据查询 | 实时集成展示设施告警/数据 |
| 工单自动派发 | 事件和告警→自动派发检修维护工单 |
| 移动端闭环 | 移动端完成工单作业闭环 |
| PC端分析 | 工单查询/统计/分析 |

### 2.4 资产管理

| 要素 | 内容 |
|------|------|
| 核心技术 | RFID标签 |
| 管理范围 | 入库→库存盘点→出库全过程 |
| 联动系统 | ERP系统/门禁系统联动 |
| 记录内容 | 档案管理/仓储管理/资产采购/资产维修/资产报废 |

### 2.5 能耗管理

采集公共用水/用电/用气/采暖等能耗数据 → 监测指标 → 指导节能降耗 → 实时管理界面 → 专业指标报表

### 2.6 环境管理

环境监测传感器数据 → 统一采集 → 整理分析 → 数据报表发布

| 子领域 | 内容 |
|------|------|
| 空气监测 | 空气质量指标 |
| 水质监测 | 水质指标 |
| 卫生管理 | 垃圾分类等 |

### 2.7 智能运营中心（IOC）⭐⭐

| 要素 | 核心内容 |
|------|------|
| **定位** | 园区的报告中心/指挥中心/统一入口 |
| **技术** | GIS可视化动态管理 |
| **能力链** | 运营状态可视 → 业务分析预警 → 辅助决策 → 执行 |
| **六大态势** | 综合安防/便捷通行/设施管理/资产管理/能耗管理/环境管理 |
| **最终目标** | 可视、可管、可控 |

## 第三部分：19.4.2 数据架构

### 三层数据架构

```
  大屏应用 (综合态势/安防/停车/设施/安全/空间/资产)
            ↑
    ┌───服务网关(Gateway)───┐
    │                       │
 ┌──┴──┐               ┌───┴──┐
 │专题库│               │数据治│
 │(告警/│               │理工具│
 │人员/ │               │      │
 │车辆/ │               │      │
 │设备) │               │      │
 └──┬──┘               └───┬──┘
    │                      │
 ┌──┴──────────────────────┴──┐
 │         主题库             │
 └────────────┬───────────────┘
              │
 ┌────────────┴───────────────┐
 │         数据湖             │  ← 原始数据汇聚
 └────────────┬───────────────┘
              │
    ┌───集成网关───┐
    │              │
 ┌──┴──┐  ┌──────┐ ┌──────┐
 │IoT  │  │集成  │ │面向  │
 │数据 │  │使能  │ │应用  │
 └─────┘  └──────┘ └──────┘
```

> 🧠 **三层递进**：**数据湖**（原始汇聚）→ **主题库**（结构化建模）→ **专题库**（面向应用场景）

| 层级 | 功能 |
|------|------|
| **数据湖** | 各异构子系统的源数据集中存储 |
| **主题库** | 数据标准化、结构化建模 |
| **专题库** | 面向具体场景（安防/能耗/轨迹等）的专题数据 |

## 第四部分：19.4.3 交互体系

### 4.1 交互体系三要素

> 🧠 **三要素**：**用户 ↔ 系统 ↔ 信息** —— 基于数字孪生中枢实现三者之间的交互

| 交互方式 | 核心能力 |
|------|------|
| 系统间数据调度 | 智慧应用系统之间数据调度，提供全域感知信息 |
| 虚实环境交互 | 数字孪生+虚拟环境实时交互，指导现场人员/机器人操作 |
| 多端用户交互 | 大屏/移动设备/微型设备，个性化智慧服务 |

### 4.2 统一门户

> **核心价值**：统一用户管理 + 单点登录 + 多渠道接入 + 应用集成

| 门户类型 | 服务对象 |
|------|------|
| **外部门户** | 互联网用户，提供相关信息服务 |
| **内部门户** | 功能企业/枢纽管理经营者/政府监督部门 |

### 4.3 多终端触达

| 渠道 | 功能 |
|------|------|
| 园区App | 智慧应用集成入口 |
| 微信公众号/小程序 | 信息推送+消息服务 |
| 微博/微视 | 官方渠道宣传 |
| 反馈通道 | 用户反馈→平台迭代 |

## 五、三架构关系总结

```
应用架构 ← 业务视角 + 数据视角
    │        分层对应原则
    │        应用域 → 应用组 → 应用系统
    │
数据架构 ← 数据使能
    │        数据湖 → 主题库 → 专题库
    │        向下集成 → 向上服务
    │
交互体系 ← 用户 ↔ 系统 ↔ 信息
             统一门户 + 多终端 + 数字孪生
```
