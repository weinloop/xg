# 01 项目全景：华航数据资产平台×智慧园区

> 规划篇的学习模式从本章起确立：华航项目作为"类比素材"而非"逐条映射"，通过对照理解智慧园区建设的核心理念。

## 一、华航平台：一个"数据智慧园区"

华航集团数据资产智能管理平台覆盖了集团120+套业务系统，29个分布式节点，管理50PB数据资产。从智慧园区的视角看，它本质上就是一个**数据空间的智慧园区**——有基础设施（算力/存储/网络）、有入驻"企业"（各业务系统）、有管理服务（API网关/规则引擎）、有安全体系（数据分级/权限管控）、有评价指标（SLA/调用量/数据质量）。

| 智慧园区建设维度 | 华航平台对应实践 |
|:--|------|
| **基础设施集约化** | 29节点统一部署，50PB存储池化，避免各系统重复建设 |
| **运营管理精细化** | 10万资产目录智能分类，5000+规则自动化管控 |
| **园区服务平台化** | API网关统一入口，10亿次/日调用，为120+系统提供标准化服务 |
| **产业发展数字化** | 数据资产从"沉睡"到"活用"，驱动集团各业务线的数字化转型 |
| **数据融合共享** | 打破部门数据壁垒，建立统一数据标准与共享机制 |
| **安全保障** | 数据分级分类 + 细粒度权限 + 全链路审计，99.99%可用性 |
| **运维体系** | 智能化监控告警 + 自动化运维 + 7×24值班 + SLA保障 |

## 二、智慧园区的"数据孤岛"之痛

教材明确指出智慧园区面临**五大问题**：规划不足、数据孤岛、千园一面、安全不健全、标准匮乏。华航平台在建设初期也面临几乎相同的问题：

| 教材五大问题 | 华航平台对应困境及解决方案 |
|-------------|------------------------|
| 技术模型和总体规划不足 | 初期元数据标准不统一，引入DAMA框架统一建模 |
| **数据孤岛** | 120+套系统各自为政，通过数据中台打通，构建统一资产目录 |
| "千园一面" | 不能照搬其他集团方案，深度定制航空行业数据治理模型 |
| 信息安全不健全 | 分类分级+脱敏+审计+99.99%可用性全面保障 |
| 缺乏标准化规范 | 制定集团内部数据标准，对标DCMM三级 |

## 三、投资运营模式的启示

教材提出智慧园区三种投资模式：

| 模式 | 特点 | 华航类比 |
|------|------|---------|
| **政府投资类** | 财政主导，适用于无明确商业价值的公共项目 | 集团统一投资，各子公司共享平台 |
| **平台公司投资** | 自筹资金，政府购买服务 | 数据资产平台作为集团"内部服务商"模式 |
| **PPP合作** | 政企共建，发挥双方优势 | 引入外部数据治理专家团队+内部IT团队联合建设 |

> 💡 华航平台采用的是"**平台公司投资**"的变体——集团集中投入580万/年建设，各业务线作为"入驻企业"按需使用，通过API调用量和数据服务计费实现内部结算。

## 四、三阶段发展路径对照

| 园区发展阶段 | 核心特征 | 华航平台演进 |
|------------|---------|------------|
| **单项应用** | 局部场景，体力替代 | 初期：各部门自建数据报表，手工对接 |
| **平台化发展** | 一体化平台，场景联动 | 当前：数据中台上线，API统一服务 |
| **全要素融合** | AI+数字孪生，自优化 | 规划：引入AI智能标签、预测性数据治理 |
