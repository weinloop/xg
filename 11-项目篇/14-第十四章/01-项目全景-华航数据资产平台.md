## 三、流程体系全景

### 3.1 华航项目的三层流程分类

| 流程类别 | 教材定义 | 华航项目对应 |
|:---:|---|------|
| **战略流程** | 面向未来，提供发展方向 | 《项目章程》《里程碑计划》《CCB章程》 |
| **运行流程** | 直接为业务对象创造价值 | 需求→设计→开发→测试→部署→验收 |
| **支持流程** | 为运行流程提供支持与服务 | 配置管理、风险管控、沟通管理、质量审计 |

### 3.2 端到端流程：「需求到上线」30天闭环

```
业务需求 → T+0需求评审(CCB) → T+3设计评审 → T+15开发完成
→ T+18测试验证 → T+22灰度发布(10%流量) → T+25全量上线(100%)
→ T+30上线回顾(PDCA)
```

### 3.3 流程执行8项保障在华航的实践

| # | 保障措施 | 华航实践 |
|:---:|---|------|
| ① | **理解流程** | 每个里程碑前组织「流程说明会」，确保干系人统一理解 |
| ② | **变更后推广** | CCB审批通过后24小时内更新Wiki和邮件通知全团队 |
| ③ | **新员工培训** | 入职第一周完成「项目流程制度培训」，100%通过考核 |
| ④ | **流程执行负责人** | 每个核心流程指定Owner（开发流程→Tech Lead，变更流程→PM） |
| ⑤ | **流程审计及监控** | 月度质量审计 + 周度变更合规检查 |
| ⑥ | **固化到信息系统** | GitLab CI/CD + 飞书审批流 + 禅道项目管理 |
| ⑦ | **固化到制度** | 变更管理、事故管理纳入绩效考核指标 |
| ⑧ | **流程文化宣导** | 月度「质量之星」评选，表彰流程执行优秀个人 |
