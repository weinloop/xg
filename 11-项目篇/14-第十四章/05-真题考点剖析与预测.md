## 三、12组易混概念对照表

| # | 易混对 | 一句话区分 |
|:---:|------|------|
| ① | 8原理 vs 5方法 | 原理=为什么标准化；方法=怎么标准化 |
| ② | 统一有度（原理） vs 简化（方法） | 统一有度是统一但不单一；简化是缩减类型 |
| ③ | 简化 vs 系列化 | 简化=减少类型；系列化=统一参数 |
| ④ | 综合标准化 vs 超前标准化 | 综合=全面最优（广度）；超前=领先当前（深度） |
| ⑤ | 运行流程 vs 支持流程 | 运行=直接创造价值；支持=保障运行 |
| ⑥ | 流程稽查 vs 流程审计 | 稽查=单个流程检查；审计=整体体系评估 |
| ⑦ | 流程绩效 vs 流程稽查 | 绩效=结果评估（效率/效果/弹性）；稽查=执行合规检查 |
| ⑧ | 固化到信息系统 vs 固化到制度 | 信息系统=技术手段自动约束；制度=管理规范权威强制 |
| ⑨ | 流程管理者 vs 流程助手 | 管理者=设计+推动+检查；助手=执行+督导 |
| ⑩ | 纠正措施 vs 过程控制 | 纠正是系统性问题根因消除；过程控制是不合格纠正+补救 |
| ⑪ | 绩效导向 vs 问题导向 | 绩效=数据驱动（对标差距）；问题=事件驱动（投诉/错误） |
| ⑫ | 岗位职责法 vs 业务模型法 | 岗位=从下到上（细致但量大）；业务=从上到下（快速但易漏） |

## 五、真题出题规律总结

1. **「识别类」是首选**：出卷老师最爱出「以下哪项不属于/属于XX」的选择题，因为本章结构化列表实在太多
2. **「区分类」是难点**：稽查vs审计、统��有度vs简化、运行vs支持——每组都是经典陷阱
3. **「步骤类」适合案例**：稽查7步、审计11步、优化3步——记得住步骤就能拿分
4. **首考之后必定扩容**：首考只出了3道选择，2026年大概率增加案例题
