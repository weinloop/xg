# 📡 卡片15：网络安全设计和安全管理

---

## 📖 教材原文

### 网络安全关注重点

| 关注领域 | 具体内容 |
|---------|---------|
| **网络结构** | 网络结构合理性、安全域划分合理性 |
| **访问控制** | 边界是否部署访问控制设备，访问规则和策略粒度是否合理 |
| **网络入侵防护** | DDoS监控防御，端口扫描/IP碎片攻击/网络蠕虫等攻击监控 |
| **网络安全审计** | 对网络设备运行状况、网络流量、用户行为等进行日志审计 |

### 网络安全设备和手段

| 设备/手段 | 功能 |
|-----------|------|
| **防火墙** | 基本网络层安全防护，内外网边界访问控制，数据包过滤检测，DDoS防御 |
| **VLAN安全域** | 按功能/级别/安全要求划分不同安全域，实现网络结构优化 |
| **IDS/IPS** | 入侵检测/防御系统，对已知网络攻击进行监控和报警/阻断 |
| **SOC/日志系统** | 安全运营中心，统一管理和分析网络安全日志 |

### 安全管理重点内容

| 管理领域 | 核心要求 |
|---------|---------|
| **安全组织和责任** | 建立安全工作组织架构，设置安全分管领导和安全专员，明确人员安全责任 |
| **风险管理工作机制** | 定期安全评估、漏洞管理、安全加固、残余风险评价 |
| **应急处理工作机制** | 安全风险监控、定期安全通告、安全紧急事件处理措施 |
| **容灾备份工作机制** | 制定完善的灾难恢复方案，定期灾难恢复演练计划 |
| **安全运维方案** | 制定系统上线/切换办法及安全运维方案 |

## 🔑 背诵提炼

**网络安全四层纵深防护**：
```
网络结构安全 → 安全域合理划分
    ↓
访问控制 → 防火墙+ACL+VLAN隔离
    ↓
入侵防护 → IDS/IPS+DDoS防御
    ↓
安全审计 → SOC+日志统一分析
```

**安全管理五大机制**：组织责任 → 风险管理 → 应急处置 → 容灾备份 → 安全运维

## 🧠 背诵口诀

**安全设备**：**「墙域侵入」** → 防火墙、VLAN安全域、IDS/IPS入侵检测、SOC日志审计

**安全管理五机制**：**「组风应灾运」** → 安全组织、风险管理、应急处置、容灾备份、安全运维

**纵深防护**：**「结构→控制→入侵→审计」** 层层递进

## 🏢 案例应用

**问**：华航集团项目的网络安全方案是如何设计的？

**答**：华航集团数据资产智能管理平台承载10万+资产目录和50PB敏感数据，安全是规划的重中之重。我们以等保三级为基线，构建了纵深防护体系：

- **网络安全域划分**：通过VLAN+防火墙将全网分为外网接入区、DMZ区、应用服务区、数据核心区、管理区五大安全域。各区域间部署防火墙实现访问控制，仅开放必要的协议和端口。例如数据核心区仅允许应用服务区指定IP访问数据库3306端口。
- **边界防护**：互联网出口部署下一代防火墙(NGFW)，开启IPS、AV、URL过滤功能。配置抗DDoS清洗设备，最大清洗能力10Gbps。总部与区域间MPLS专线双向部署防火墙，区域间流量默认隔离。
- **入侵检测与审计**：核心交换节点部署IDS探针（镜像端口流量），旁路部署IPS阻断已知攻击。部署SOC平台收集全网安全设备日志，关联分析引擎日均处理50万条日志，异常行为自动告警。
- **安全管理体系**：设立首席安全官(CSO)，配备3名专职安全工程师。每季度执行一次渗透测试和漏洞扫描，每月进行安全加固。制定应急预案并每半年演练一次。容灾方案实现数据异地备份（RPO<1小时、RTO<4小时）。

投产后安全体系成功防御DDoS攻击12次、拦截入侵尝试2300+次，通过等保三级测评，获得民航局安全合规认证。
