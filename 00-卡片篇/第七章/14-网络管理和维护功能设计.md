# 📡 卡片14：网络管理和维护功能设计

---

## 📖 教材原文

随着网络规模的不断扩大，需要建设专门的网络管理和维护系统来管理、监测和控制网络的运行。

### 网络管理五大功能（ISO定义）

| 功能 | 核心内容 |
|------|---------|
| **故障管理** | 收集设备告警信息，判定和定位网络故障，为快速排除和网络恢复打下基础 |
| **配置管理** | 配置网络以提供网络服务，采集设备配置数据，管理和分析以使网络整体运行最优 |
| **性能管理** | 采集、分析和处理网络性能数据，了解整个网络和设备的运行状况 |
| **计费管理** | 记录各类网络资源使用情况，控制和监测网络操作的费用和代价 |
| **安全管理** | 提供设备和网络管理层面的安全性管理功能，保障网络安全运行 |

### 网络管理系统功能体系结构（三层）

| 层级 | 功能 | 关键技术 |
|------|------|---------|
| **网元/网络层**（最底层） | 被管理的所有网元设备和网络系统 | MIB（管理信息库）、SNMP（简单网络管理协议） |
| **管理应用层**（中间层） | 实现五大管理功能+附加功能（辅助决策、资源管理、测试评估等） | 功能模块化，可扩展 |
| **表示层**（最上层） | 向用户提供直观友好的人机交互界面 | 图形/文字/表格、大屏/PC/手机、Web/C/S方式 |

**MIB**：定义受管设备保存的数据项、允许的操作及含义
**SNMP**：定义管理站软件如何与管理代理通信（消息分组格式、含义、管理关系）

## 🔑 背诵提炼

**五大功能**：故障管理 → 配置管理 → 性能管理 → 计费管理 → 安全管理

```
故障——发现定位快速恢复
配置——配置采集优化运行
性能——采集分析了解状况
计费——记录监控费用代价
安全——设备管理安全保障
```

**三层体系**：
```
表示层：人机交互（大屏/PC/手机）
   ↓
管理应用层：五大功能+扩展子系统
   ↓
网元/网络层：MIB+SNMP（被管设备信息）
```

## 🏢 案例应用

**问**：华航集团项目的网络管理系统是如何设计的？

**答**：华航集团数据资产智能管理平台覆盖26个节点、300+台网络设备，我们建设了统一的网络管理系统：

- **故障管理**：部署Zabbix+Prometheus双监控平台，所有网络设备开启SNMP Trap告警推送。定义告警级别P0~P4——P0（核心设备宕机）5分钟内电话+短信通知，P1（链路中断）15分钟企微通知，P2~P4分级处理。投产后平均故障发现时间从30分钟缩短到3分钟。
- **配置管理**：部署配置备份系统，每日凌晨自动备份所有网络设备配置到Git仓库，支持配置差异比对和一键回滚。某次区域交换机配置误操作后，5分钟完成配置恢复。
- **性能管理**：通过SNMP采集每台设备的CPU、内存、端口流量、丢包率等指标，Grafana大屏实时展示全网拓扑和性能热力图，带宽利用率>80%自动预警。
- **安全管理**：集成堡垒机实现运维操作审计，所有SSH/Telnet登录全程录像。部署SOC平台统一收集和分析安全日志，日均处理安全事件200+条。
- **计费管理**：对各分公司VPN带宽使用量按月统计，为内部成本分摊提供数据支撑。

网管系统上线后，网络运维效率提升60%，主动发现并预防故障45起。
