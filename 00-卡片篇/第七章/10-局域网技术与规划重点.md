## 📖 教材原文

### 局域网主要技术——VLAN

VLAN相当于OSI第二层的广播域，将局域网设备从逻辑上划分成虚拟网段。一个VLAN内部的广播和单播流量不会转发到其他VLAN，不同VLAN之间的数据传输通过三层路由实现。使用VLAN可搭建安全可靠的网络，控制流量、减少设备投资、简化网络管理、提高网络安全性。

**VLAN划分方法有6类**：

| 划分方法 | 依据 | 优点 | 缺点 |
|---------|------|------|------|
| ①按端口 | 交换机物理端口 | 定义简单，适用任何大小网络 | 用户换端口需重新定义 |
| ②按MAC地址 | 主机MAC地址 | 用户移动位置自动保留VLAN身份 | 初始化需逐个配置，适用小型网 |
| ③按网络层协议 | IP/IPX/DECnet等 | 广播域跨越多个交换机 | 检查每个数据包网络层地址，效率低 |
| ④按IP组播 | IP组播组 | 可扩展到广域网，灵活 | 不适合局域网，效率不高 |
| ⑤按策略 | 多种分配方法组合 | 可自定义策略 | 配置复杂度高 |
| ⑥按用户定义/非授权 | 用户特定需求+密码认证 | 灵活授权 | 依赖认证体系 |

### 局域网规划重点关注的内容

除通用的建设背景、需求分析、项目预算、技术方向、网络拓扑、IP地址规划外，局域网还应重点关注：

| 项目 | 要点 |
|------|------|
| VLAN划分 | 根据业务特性、地理连接、安全要求综合考量 |
| VLAN编号 | ID范围1~4096，大型局域网中应谨慎规划 |
| VLAN间路由设计 | 三种方式：多物理接口/子接口/三层交换机 |
| STP设计 | 阻断二层环路，避免广播风暴 |
| DHCP设计 | 小型→出口路由器，中型→核心三层交换机，大型→专用DHCP代理服务器 |

## 🔑 背诵提炼

**VLAN 6类划分**：端口型 → MAC型 → 协议型 → 组播型 → 策略型 → 用户型

**5大规划重点**：
- **VLAN划分** → 综合业务/地理/安全
- **VLAN编号** → 1~4096，谨慎规划
- **VLAN间路由** → 物理接口/子接口/三层交换
- **STP设计** → 阻断环路防广播风暴
- **DHCP设计** → 小路由/中三层/大专代理

---

## 🧠 背诵口诀

**VLAN六分法**：**「端M协组策用」** → 端口、MAC、协议、组播、策略、用户定义

**规划五重点**：**「划编号由STP配」** → VLAN划分、编号、间路由、STP、DHCP

**DHCP三档**：**「小由路由中三交，大专代理配地址」**

## 🏢 案例应用

**问**：华航集团项目中，你们的局域网VLAN是如何规划的？

**答**：华航集团各节点（总部+区域+分公司）的局域网VLAN规划综合考虑了业务特性和安全隔离需求：

- **VLAN划分策略**：采用组合策略——核心交换机按端口划分（配合MAC地址绑定），接入交换机按端口+MAC双重认证。按业务域分为：数据采集区(VLAN 101-120)、数据处理区(VLAN 201-220)、数据服务区(VLAN 301-320)、管理区(VLAN 401-410)、访客区(VLAN 501)。
- **VLAN编号规划**：总部使用100~199段（预留100个），5个区域分别使用200~299、300~399……600~699段，分公司使用700~999段，避免编号冲突。
- **VLAN间路由**：总部核心三层交换机启用VLAN间路由，通过ACL控制跨VLAN访问——例如管理区可访问所有区域，但数据采集区仅允许访问数据处理区的指定端口。
- **STP设计**：核心层配置RSTP快速生成树，接入层配置BPDU Guard防止边缘端口误接交换机引发环路。
- **DHCP设计**：总部配置专用DHCP服务器（Windows Server双机热备），区域由核心三层交换机兼任DHCP，分配各自网段的IP地址。

通过VLAN精细划分，实现了"同网不同域、跨域需授权"的安全架构，顺利通过等保三级安全域划分检查。
