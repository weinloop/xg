# 📡 卡片17：监控系统与节能降耗

---

## 📖 教材原文

### 监控系统

机房监控系统主要对机房环境自身和所承载的信息网络设备进行集中监控和管理。通过监控系统收集机房运行的各种参数数据，进行实时分析和研判，当出现问题时或有潜在隐患时，及时或预先通知机房及专业维护人员。

**机房监控对象**：内部各类动力设备、各类环境设施、消防设施、安防设施、所承载的信息网络设备等。

**监控系统的作用**：
- 自动预警、报警，机房故障能及时处置，避免扩大故障影响
- 让运维人员从烦琐复杂的运维工作中解脱，实现智能运维管理模式
- 机房得到有效管理，防护效果提升，业务系统长期运行

**典型机房监控功能系统（五个子系统）**：

| 子系统 | 监控内容 |
|-------|---------|
| 机房动力环境系统监测 | 动力系统、环境系统、消防系统、安保系统 |
| 机房网络设备监控 | CPU、内存、端口流量、业务水平等 |
| 机房门禁监控 | 进出人员、摄像头、门禁记录 |
| 机房环境消防监控 | 温湿度、粉尘、气体、消防 |
| 统一运维管理平台 | 网络设备/服务器/存储/应用/无线/日志/动环统一监控 |

### 节能降耗

随着网络通信系统规模不断增长，绿色节能机房、绿色数据中心建设已成为必选项。节能降耗涉及多方面：

| 环节 | 措施 |
|------|------|
| 选址规划 | 选址利于节能和降低能源成本 |
| 建筑结构 | 密封、绝热、配风、气流组织设计合理 |
| 布局排列 | 分隔冷热气流，形成良好气流组织 |
| 设备节能 | 服务器、机柜等本身具备节能降耗措施 |
| 智能管理 | 基于AI实时环境监测，按需调节动态制冷 |

## 🔑 背诵提炼

**监控五大子系统**：
```
① 动力环境监测 —— 动力+环境+消防+安保
② 网络设备监控 —— CPU/内存/端口/业务
③ 门禁监控 —— 进出人员+摄像
④ 消防监控 —— 温湿度/粉尘/气体/消防
⑤ 统一运维平台 —— 全栈集中管理
```

**节能五大环节**：选址 → 结构 → 布局 → 设备 → 智能

**核心理念**：从被动告警→主动预警→智能运维，从粗放能耗→精细节能→绿色数据中心

## 🧠 背诵口诀

**监控五子**：**「动网门消统」** —— 动力环境、网络设备、门禁、消防、统一平台

**节能五环**：**「址构布设智」** —— 选址规划、建筑结构、布局排列、设备节能、智能管理

**趋势口诀**：**「预警代替告警，智能代替人工，绿色代替粗放」**

## 🏢 案例应用

**问**：华航集团数据中心在监控和节能方面采取了哪些措施？

**答**：华航集团总部数据中心在监控和节能方面实施了以下措施：

- **统一监控平台**：部署动环监控+网络监控一体化平台，对接200m²机房内全部基础设施。实时监控温湿度传感器32个、UPS进/出电量、空调运行状态、门禁记录、消防状态，以及60+台服务器的CPU/内存/磁盘/网络指标。监控数据存入时序数据库，保留1年，支持趋势分析和容量预测。
- **智能告警**：设置三级告警阈值——黄色预警（温湿度异常趋势，提前30分钟通知运维）、橙色严重（设备性能超阈值，企微+邮件通知）、红色紧急（宕机/断电/消防，电话+短信通知）。自上线以来，成功预警空调制冷不足3次，避免了机房过热宕机。
- **节能降耗实践**：
  - 采用冷热通道封闭方案，冷热气流分离，空调送风温度从14°C提高至18°C，每年节省空调电费约15万元。
  - 服务器采用高效节能电源（80Plus铂金级），虚拟化整合将物理服务器从80台缩减至60台，节省电力约25%。
  - 部署AI能耗管理平台，基于历史数据预测负载规律，动态调节空调制冷量——夜间低负载时段自动降低风机转速，每年额外节电约8%。
- **成效**：PUE从设计1.5优化至实际1.48，年度电费节省约35万元，碳排放减少约120吨/年。
