# 📡 卡片16：机房建设与综合布线

---

## 📖 教材原文

### 机房建设

现代机房建设工程充分体现了新技术、新材料、新工艺、新设备的特点。一方面，网络机房运转是否正常影响日常业务正常运行，对安全性、可靠性和可管理性要求很高，需符合国家各项标准规定；另一方面，需考虑建设维护性价比，有效降低运行功耗，提升故障处理能力。

机房建设是综合性专业技术系统工程，涉及建筑设计、空调、通风、给排水、强电、弱电等专业技术，同时具有建筑装饰关于美学、光学、色彩学的要求。通常需要专业技术单位完成。

机房建设包括七大系统：

| 系统 | 内容 |
|------|------|
| 机房装修 | 防静电地板、微孔天花板、隔断墙 |
| 空调系统 | 精密空调、下送风/上回风、冷热通道封闭 |
| 电气系统 | UPS不间断电源、配电柜、照明 |
| 接地和防雷系统 | 防雷接地、等电位连接 |
| 消防系统 | 气体灭火（七氟丙烷/IG541）、烟感/温感 |
| 环境监控系统 | 温湿度、漏水、门禁、视频监控 |
| 节能降耗系统 | 智能制冷、变频空调、能耗监测 |

### 综合布线

综合布线系统是按照标准、统一、简单结构化方式编制和布置建筑物（或建筑群）内各种系统的通信线路，包括网络系统、电话系统、监控系统、电源系统和照明系统等。

综合布线基本构成包括三个子系统：

| 子系统 | 范围 |
|-------|------|
| **建筑群子系统** | 建筑物之间的连接 |
| **干线子系统** | 建筑物内垂直主干 |
| **配线子系统** | 楼层水平布线到终端 |

设计要点：应纳入建筑规划设计中同步设计，考虑施工和维护方便，做到技术先进、经济合理；应与信息网络系统、安全技术防范系统、建筑设备监控系统等统筹规划。

## 🔑 背诵提炼

**机房建设七系统**：
```
① 机房装修 → 环境基础
② 空调系统 → 温湿度控制
③ 电气系统 → UPS供电保障
④ 接地防雷 → 电气安全
⑤ 消防系统 → 气体灭火
⑥ 环境监控 → 实时监测
⑦ 节能降耗 → 绿色机房
```

**综合布线三子系统**：建筑群子系统 → 干线子系统 → 配线子系统

**设计原则**：技术先进 + 经济合理 + 施工维护方便 + 统筹规划

## 🧠 背诵口诀

**机房七系统**：**「装空电地消监节」** —— 装修、空调、电气、接地防雷、消防、环境监控、节能降耗

**布线三子**：**「建干配」** → 建筑群子系统、干线子系统、配线子系统

**设计原则**：**「先经便统」** → 技术先进、经济合理、方便维护、统筹规划

## 🏢 案例应用

**问**：华航集团项目总部数据中心的机房是如何建设的？

**答**：华航集团总部数据中心（200m²）按照B级机房标准建设，承载数据资产管理平台所有核心服务器和网络设备：

- **机房装修**：防静电架空地板（高度30cm）配合微孔天花板，形成下送风上回风气流组织。冷通道封闭+热通道回风，冷通道温度维持22±1°C。
- **电气系统**：引入双路市电（不同变电站）+1台柴油发电机。部署2台60kVA UPS（2N冗余），满载后备时间30分钟。列头柜双路供电至每台设备。
- **空调系统**：部署4台精密空调（3+1冗余），下送风方式，单台制冷量30kW，PUE设计值≤1.5。
- **消防系统**：七氟丙烷气体灭火系统+极早期烟雾探测(VESDA)，灭火浓度8%，30秒内完成喷放。
- **环境监控**：部署动环监控系统，监测温湿度（精度±0.5°C）、漏水（定位精度±1m）、门禁、视频，异常告警短信通知。
- **综合布线**：建筑群子系统采用单模光纤连接区域中心；干线子系统采用OM4多模光纤（主干万兆）；配线子系统采用六类双绞线到桌面。机柜间桥架上走线，强弱电分离。

机房投运后保持0重大故障运行，PUE实测1.48，通过B级机房认证。
