# 📡 卡片06：广域网一般架构

---

## 📖 教材原文

广域网是跨地区、省市、国家的更大规模网络的统称，用来连接地区的局域网、城域网、省网和各个国家的网络。广域网一般可分为运营商广域网和企业/行业广域网，规划重点有所差异。

### 运营商广域网架构

典型的运营商网络由全国骨干网、省级骨干网、城域网和接入网组成：
- **全国骨干网**：负责省级骨干网的互联互通，以及与国内其他运营商网络、国际运营商网络的互联互通。
- **省级骨干网**：负责省内各城域网之间的互联互通，业务量大的城域网间设置直达路由。
- **城域网**：以IP技术为基础，光纤为传输媒介，集数据、语音、流媒体等业务于一体的多媒体通信网络。

**城域网三层架构**：
| 层级 | 设备 | 功能 |
|------|------|------|
| 核心层 | 核心路由器 | 互联网出口，上联省级骨干网，接入IDC/CDN |
| 汇聚层 | 汇聚交换机 | 区域性汇接点，上联核心层，下接OLT等接入设备 |
| 接入层 | OLT等接入设备 | 面向园区、楼宇、住宅等用户，提供有/无线接入 |

### 企业广域网架构

企业广域网将总部、分支机构、数据中心、算力中心、云计算资源及移动办公人员进行组网。

- **中小型企业**：企业网关/路由器 + 核心交换机 + 应用服务器/AP/PC等
- **大中型企业（多分支）**：通常分核心层（路由器）、汇聚层（三层交换机）、接入层（二层交换机），分支间租用运营商VPN通道互联

---

## 🔑 背诵提炼

**运营商网络四层**：全国骨干网 → 省级骨干网 → 城域网（核心/汇聚/接入三层） → 接入网

**城域网三层对照**：
```
核心层（路由器） → 出口+上联
汇聚层（汇聚交换机） → 汇接+下联
接入层（OLT等） → 用户接入
```

**企业网大小型对比**：
| | 中小型企业 | 大中型多分支企业 |
|--|---------|-----------|
| 结构 | 网关+交换机二级 | 核心+汇聚+接入三层 |
| 互通 | 直接接入 | 租用运营商VPN通道 |

---

## 🧠 背诵口诀

**运营商四级**：**「全国骨干连省网，省网汇通城域网，城域三层核汇接，接入末端到用户」**

**城域网三层**：**「核路——汇聚——接OLT」** → 核心路由器、汇聚交换机、接入OLT

**企业网**：**「小企两级大企三，分支互通靠VPN」**

## 🏢 案例应用

**问**：华航集团属于典型的大中型多分支企业，请说明你们是如何规划企业广域网架构的？

**答**：华航集团1总部+5区域+23分公司的组织架构，决定了我们必须采用大型企业三层广域网架构：

- **核心层（总部）**：部署2台高端核心路由器（双机热备），通过两条不同运营商的1Gbps MPLS专线上联互联网，同时作为全网路由核心。核心路由器之间运行OSPF+BGP双协议，保障路由收敛速度。
- **汇聚层（5个区域中心）**：每个区域部署2台三层汇聚交换机，通过1Gbps MPLS专线双链路上联总部核心路由器，向下通过100Mbps MPLS/IPSec VPN接入本区域的分公司。
- **接入层（23个分公司）**：各分公司部署二层交换机，通过运营商VPN通道上联所属区域汇聚层。分公司内部通过VLAN隔离办公网、业务网和访客网。

这种三层架构使网络管理分层清晰：核心层只关注全网路由策略和互联网出口；汇聚层承担区域流量汇聚和策略执行；接入层实现终端接入和本地交换。投产后网络平均可用率达99.99%，支持5000并发下的稳定访问。
