# 卡片02：云原生发展概述（烟筒→DevOps→五大趋势）

---

## 📖 教材原文

**从烟筒到上云**：传统IT采用"烟筒"模式，每个应用独立构建、单独分配资源，资源难共享。上云后IaaS层复用程度大幅提升，组织自然想到IaaS以上层系统也需统一，使资源、产品可不断复用，进一步降低建设与运营成本。

**从瀑布到DevOps**：传统瀑布式流程将开发、IT运营、质量保障分别设置，开发人员希望更快响应，运维要求可靠安全，业务希望更快发布。瀑布造成上下游信息不对称、开发周期长。敏捷开发解决了效率与版本更新速度，但未打通运维。DevOps（开发运维一体化）可看作开发、技术运营、质量保障三者交集，促进沟通协作整合，缩短开发周期。

**云原生=DevOps的前提条件**：云原生的容器、微服务等技术为DevOps提供了前提条件，是实现DevOps和持续交付的关键。

**云原生与开源生态**：云原生从一开始与开源生态走在一起，选择"飞轮进化"式道路——通过易用性和开放性实现快速增长的正向循环，通过不断壮大的应用实例推动业务全面上云。

**云原生与新兴场景融合**：
- **AI/大数据**：容器替换传统大数据平台，更小粒度资源划分、更快扩容、更灵活调度
- **边缘计算**：解决轻量化、异构设备管理难题（如全国高速公路取消省界收费站项目，管理10万+异构设备、30万+边缘应用）
- **高性能计算HPC**：科研/生物/制药率先应用（中科院、华大基因等）

**五大价值趋势（10.1.2末尾）**：
1. **多元算力**：满足个性化算力需求，软硬协同，多云治理+边云协同，打造计算存储一体化平台
2. **DevSecOps**：在DevOps周期中建立安全原则，安全是开发/测试/运维/安全团队所有成员的责任，贯穿全生命周期
3. **数据+AI赋能**：帮助组织管理数据，实现数据资产化沉淀和价值挖掘，结合AI赋能业务智能升级
4. **Operator生态**：提供分布式、数据仓库、图计算等丰富工具，支撑分析、商业智能和信息检索
5. **安全合规**：云平台全方位安全服务+云原生数据库弹性伸缩、高可用、自动备份、智能运维

---

## 🔑 背诵提炼

1. **三阶段演进**：烟筒（资源独享/难复用）→ 上云（IaaS复用）→ 云原生（全栈复用/自动化）
2. **开发模式三阶段**：瀑布（慢/信息不对称）→ 敏捷（快/但未通运维）→ DevOps（开发+运维+质保融合）
3. **云原生赋能公式**：容器+微服务 → DevOps前提条件 → 持续交付 → 飞轮进化
4. **五大赛道融合**：AI大数据 + 边缘计算 + HPC + DevSecOps + 安全合规
5. **五大价值趋势**：算力（多元）+ 安全（DevSecOps）+ 数据（AI赋能）+ 工具（Operator）+ 合规（安全合规）

## 🏢 案例应用

**场景**：华航集团数据资产智能管理平台不仅要实现数据管理功能，还需要支撑未来3-5年的业务扩展，包括AI辅助决策、实时数据分析和大规模并发。

**问题**：请从云原生发展五大价值趋势出发，说明华航平台如何借助云原生实现业务创新与降本增效？

**参考答案**：
华航平台从五大趋势全面布局云原生：

（1）**多元算力**：平台部署于混合云架构，TKE容器集群管理K8s节点，根据数据采集（批量）、实时计算（流式）、AI训练（GPU）、OLAP查询等不同场景分配差异化算力。HPA自动扩缩容，实现计算存储一体化。

（2）**DevSecOps**：在CI/CD流水线中集成SonarQube代码扫描、Trivy镜像扫描、安全测试用例，从开发到上线全链路安全左移。安全团队参与Sprint Planning，将等保三级要求转化为可测试的安全AC（验收条件）。

（3）**数据+AI赋能**：借助腾讯云数据湖+EMR，实现50PB数据资产的统一管理和智能分析。AI模块支持异常检测、数据质量自动评分、智能推荐标签，赋能业务用户自助式分析。

（4）**Operator生态**：使用K8s Operator模式管理MySQL/Redis/Kafka等有状态服务，实现自动备份、故障恢复、版本升级。ClickHouse Operator支撑OLAP查询的自动扩缩容。

（5）**安全合规**：全链路SSL/TLS加密，KMS管理密钥，WAF+API网关实现流量安全控制，满足等保三级和《数据安全法》合规要求。云原生数据库自动备份+异地容灾，SLA达到99.99%。
