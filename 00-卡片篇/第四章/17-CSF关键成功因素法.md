# 卡片17：CSF 关键成功因素法

---

## 📖 教材原文

> 关键成功因素法（CSF）由哈佛大学教授William Zani于1970年提出，后由MIT教授John Rochart提高成MIS开发规划战略。CSF认为一个组织的信息需求是由少数的几个关键成功因素决定的。

### 一、CSF核心概念

- **关键成功因素**：帮助组织达到一定目标所不可缺少的业务、技术、资金以及人力因素
- **核心逻辑**：组织通过分解整体目标→识别关键成功因素与核心竞争力及性能指标→根据因素确定资源分配优先级别
- **关注重点**：识别与系统目标相关联的主要数据类及其关系，依托数据为组织发掘新机遇

### 二、关键成功因素四个主要来源

| 来源 | 说明 |
|------|------|
| **①产业结构** | 不同产业因自身特质和结构不同，存在不同的CSF（决定于产品经营特性） |
| **②竞争策略/产业地位/地理位置** | 组织的产业地位由历史和竞争策略决定，大组织行为影响小组织的CSF |
| **③环境因素** | 组织外在因素（总体环境）变动影响CSF（如市场需求波动→存货控制成CSF） |
| **④暂时因素** | 由组织内部特殊原因引起，存在于某一特定时期 |

### 三、关键成功因素四种类型

| 类型 | 说明 |
|------|------|
| 内部型CSF | 针对组织机构内部的活动 |
| 外部型CSF | 与组织的对外活动有关（如与其他组织联系或获得信贷） |
| 监控型CSF | 对现实情况的详细考察（如监测业务缺陷百分比） |
| 建立型CSF | 与组织未来计划的变化有关（如改善产品或服务组合） |

### 四、CSF实施步骤（四步）

1. **确定组织的战略目标**
2. **识别组织的所有成功因素**：逐层分解导出影响战略目标的各种因素及子因素
3. **确定组织的关键成功因素**：对所有因素评价，根据现状和目标确定CSF（可用德尔菲法或模糊综合评价法）
4. **识别各CSF的绩效指标和标准以及测量绩效的数据**：给出每个CSF的绩效指标与衡量标准

### 五、CSF评价

- **优点**：抓住主要矛盾，突出重点、主次分明；简便可行，应用范围广，最常用的规划方法
- **局限**：一般适用于确定管理目标；只考虑了目标怎么分解，很少涉及如何利用信息技术支持目标实现及如何利用信息系统
- **适用对象**：在高层管理者中应用效果好，高层领导能更直观引导各级管理者纵览组织与信息技术之间的关系

## 🔑 背诵提炼

| 维度 | 要点 |
|------|------|
| 核心逻辑 | 战略目标→分解→识别CSF→确定KPI→资源分配 |
| CSF四来源 | 产业结构 + 竞争策略/地位 + 环境因素 + 暂时因素 |
| CSF四类型 | 内部型 + 外部型 + 监控型 + 建立型 |
| 实施四步 | 定目标→识因素→筛关键→定指标 |

**CSF本质**：抓主要矛盾——找到影响组织成功的少数几个关键因素，集中资源攻克

---

## 🧠 背诵口诀

> **CSF四源：产竞环暂** — 产业结构、竞争策略/地位、环境因素、暂时因素

> **CSF四型：内外监控** — 内部型、外部型、监控型、建立型

> **CSF四步：标因关指** — 定战略目标、识所有因素、筛关键因素、定绩效指标

## 🏢 案例应用

**场景**：华航集团数据资产智能管理平台

**问题1**：请运用CSF方法，识别华航集团数据资产管理成功的关键成功因素。

**参考答案**：

**步骤1-确定战略目标**：
华航集团数据资产管理战略目标——实现数据资产"可见、可管、可用、可控、智能"，支撑集团数字化转型。

**步骤2-识别所有成功因素（逐层分解）**：

一级因素：
- 数据资产全面盘点（可见）
- 数据质量有效管控（可管）
- 数据安全高效共享（可用+可控）
- 数据价值智能释放（智能）
- 组织全员参与和认同

二级因素：
- 可见→资产自动发现覆盖率≥95%、资产目录≥10万项、8大业务域全覆盖
- 可管→质量规则≥5,000条、问题闭环率≥95%、三级质量看板
- 可用可控→审批≤3天、脱敏覆盖率100%、年调用≥10亿次
- 智能→语义检索准确率≥85%、血缘自动解析、智能推荐
- 全员参与→8万员工数字素养、各分公司推广覆盖率100%

**步骤3-确定关键成功因素（德尔菲法）**：

经数据治理委员会专家打分，最终确定三个CSF：
1. **数据质量有效管控**（权重最高）——数据质量是平台价值的根基，质量差则一切上层应用失去意义
2. **组织全员参与和认同**——23家分公司推广是必须跨越的门槛
3. **数据安全高效共享**——安全是底线，共享是核心价值

**步骤4-识别绩效指标**：
- CSF1数据质量管控：质量规则执行率≥95%、问题闭环率≥95%、数据差异率从15%降至≤3%
- CSF2全员参与：平台月活用户≥5,000、分公司推广覆盖率100%、用户满意度≥85分
- CSF3安全共享：审批≤3天、数据安全事件=0、API调用成功率≥99.9%

---

**问题2**：华航集团数据质量管控CSF属于哪种类型？来源于哪个方面？

**参考答案**：

数据质量管控CSF属于**内部型CSF**（针对组织内部数据管理活动），主要来源于**②竞争策略/产业地位**（三大航均在推进数据治理，不做好数据质量将在竞争中落后）和**①产业结构**（航空业是数据密集型产业，数据质量直接影响航班安全、旅客体验和经营决策），同时也受**④暂时因素**影响（当前阶段集团数据差异率高达15%-20%，亟需解决）。
