# 卡片06：技术体系定义

---

## 📖 教材原文

> 技术体系是支撑和承载信息系统落地运行的基础，决定了组织的信息技术环境，体现了组织对信息技术开发应用的选择偏好和关键创新点。

### 一、技术体系定义六大原则

| 原则 | 核心内容 | 关键考察点 |
|------|---------|-----------|
| **可用性** | 技术提供的特征和能力满足信息系统建设运行发展需要 | 功能、性能、风险多维度排序抉择 |
| **安全性** | 满足安全要求，确保保密性和完整性 | ①了解技术安全漏洞；②技术组合减少故障影响；③与安全管理体系匹配 |
| **可靠性** | 尽量选择高可靠技术和产品，预测预防故障隐患 | 成熟性（时长/领域/表现）、技术整体性（理论完整/领域多元/系统性）、技术风险性（漏洞/创新案例/稳定性） |
| **灵活性** | 内外部需求变化时，技术体系通过少量变化满足要求 | 技术组件化、技术组合架构 |
| **可扩展性** | 业务系统、用户快速增加时，通过韧性拓展适应 | 用既有技术满足新需求，或扩展组件 |
| **可驾驭性** | 组织能充分掌控技术体系 | 直接/间接/混合方式，或人员/商业/生态掌控 |

### 二、技术体系的范围（9大领域）

应用软件及开发技术（重点关注SOA和微服务架构）、网络技术（重点关注SDN、5G、自组网）、数据库技术、中间件技术、计算机与存储技术（重点关注云计算、虚拟化）、数据资源技术（重点关注大数据、平台化）、客户端访问技术（重点关注移动App、小程序）、容灾技术、信息安全技术（重点关注智能化安全技术）

### 三、技术蓝图绘制（两种方法）

1. **逻辑结构图**：基于信息系统结构逻辑或技术组件结构逻辑绘制，重点表达技术对系统的支撑情况及组件间关系。如"感传智用安"框架中，每个系统框架部分表述对应的技术路线和技术组件。

2. **技术应用图**：将某一组强关联的技术族全面应用于信息系统。如云计算技术族、大数据技术族、物联网技术族、数字孪生技术族等。

## 🔑 背诵提炼

| 维度 | 核心要点 |
|------|---------|
| 六原则 | 可用 → 安全 → 可靠 → 灵活 → 可扩展 → 可驾驭 |
| 可靠性三维度 | 成熟性（时间+领域+表现）、整体性（理论+多元+系统）、风险性（漏洞+案例+稳定） |
| 九大技术领域 | 应用软件、网络、数据库、中间件、计算机存储、数据资源、客户端、容灾、信息安全 |
| 蓝图两方法 | 逻辑结构图（表达支撑关系）+ 技术应用图（技术族全面应用） |

## 🧠 背诵口诀

> **六原则：用安可灵展驭** — 可用性、安全性、可靠性、灵活性、可扩展性、可驾驭性

> **可靠三维：成熟整体风险** — 成熟性、技术整体性、技术风险性

> **蓝图两图：逻技** — 逻辑结构图、技术应用图

## 🏢 案例应用

**场景**：华航集团数据资产智能管理平台

**问题1**：华航平台在技术选型时，如何体现技术体系定义的六大原则？

**参考答案**：

1. **可用性**：选择成熟的分布式数据库（满足10万+资产目录和10亿次/年调用需求），NLP/LLM引擎满足智能问答功能需求，容器云PaaS满足弹性部署需求。

2. **安全性**：采用等保三级标准建设，RBAC+ABAC混合访问控制模型实现细粒度权限，18种脱敏算法保障数据安全，安全态势感知实时监控。

3. **可靠性**：私有云IaaS采用成熟云计算技术（较长应用历史和多元应用领域），分布式架构消除单点故障，系统整体可用性≥99.99%。

4. **灵活性**：微服务架构设计，质量规则支持可视化编辑和自定义SQL模板，数据分类体系支持动态扩展。

5. **可扩展性**：容器化部署支持水平扩展，29个节点可逐步接入，API网关支持协议转换，新增业务系统可快速对接。

6. **可驾驭性**：技术栈选择集团IT团队熟悉的主流开源和国产化技术，设置三期知识转移计划确保运维团队可自主运营。

---

**问题2**：请为华航平台绘制技术蓝图，说明应使用哪种方法。

**参考答案**：

推荐使用**逻辑结构图**方法绘制技术蓝图，按五层架构展开：

- **感知层（感）**：元数据采集适配器技术（Oracle/MySQL/Hive/HBase等多源适配）
- **传输层（传）**：消息队列技术（Kafka/RocketMQ）、API网关（协议转换/流量控制）
- **智能层（智）**：PaaS层（容器编排K8s）、DaaS层（分布式数据库/对象存储）、NLP/LLM引擎
- **应用层（用）**：微服务架构（Spring Cloud）、前端框架（React/Vue）、可视化引擎（ECharts/D3.js）
- **安全体系（安）**：贯穿全层——统一认证（OAuth2.0/JWT）、数据加密（国密SM4）、安全审计（ELK日志分析）

理由：逻辑结构图能清晰表达每层技术对系统的支撑关系和技术组件间的关系，便于各团队理解并遵守技术规范。
