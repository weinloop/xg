# 📖 卡片07：基于指标能力的方法（7步+4级评价）

---

## 📖 教材原文

> 该方法以"决策→指标→数据模型"的分析为切入点，一步步反推出能够支持目标决策应用的核心数据集。不需要关心具体的业务流程，也不需要收集大量的初始数据集，每一步分析的数据信息都是有方向的，服务于最终的能力评价、决策制定等。
>
> 基于指标能力的方法中，比较重要的是建立正确的指标体系。指标体系是否合理决定了能力评价和制定决策的正确程度。此外，在形成的目标数据集中，对于表达相同意义的数据元素需要做一致性检验，避免数据元素重复或同义不同名。
>
> 实施步骤：
> 1. **决策评估收集**：正确收集和分析需要评价的各种能力和制定的各类决策
> 2. **支撑指标分析**：根据能力评估和决策制定需要，转换出相应的支撑指标
> 3. **指标体系构建**：通过分类组合构建指标体系，经专家审核评价
> 4. **建立指标数据模型、分析数据集**：细化后指标→信息逻辑模型→数据元素→数据子集
> 5. **数据子集融合**：根据指标层次结构向上回溯，合并融合上一层次的数据集合
> 6. **核心数据集的一致性检验**：删除重复数据元素，辨别同义不同名的数据元素
> 7. **核心数据集评价**：从准备级、平台级、数据级、利用级四个维度评价

## 🔑 背诵提炼

### 7个实施步骤

| 步骤 | 核心内容 |
|:---|------|
| ①决策评估收集 | 收集需要评价的能力和制定的决策 |
| ②支撑指标分析 | 能力/决策→转换→支撑指标 |
| ③指标体系构建 | 分类组合+专家审核评价 |
| ④建立指标数据模型 | 细化指标→信息逻辑模型→数据元素→数据子集 |
| ⑤数据子集融合 | 按指标层次向上回溯合并 |
| ⑥一致性检验 | 删除重复、辨别同义不同名 |
| ⑦核心数据集评价 | 准备级→平台级→数据级→利用级四维评价 |

### 4级评价体系

| 评价维度 | 包括内容 |
|:---|------|
| **准备级** | 规章制度、行为准则、标准规范 |
| **平台级** | 数据生成、数据收集、工具推荐、成果展现、传播与反馈 |
| **数据级** | 数据数量、质量、标准、范围 |
| **利用级** | 利用促进、成果产出、数据利用 |

### 方法特点
- 不需要关心具体业务流程
- 不需要收集大量初始数据集
- 每一步分析有方向，服务于决策
- 关键是建立正确的指标体系

## 🏢 案例应用

**问**：华航集团如何利用基于指标能力的方法规划"航线效益评估"的数据需求？

**答**：华航在航线效益评估模块中，采用基于指标能力的方法，以决策驱动的方式反推数据需求：

**步骤①决策评估收集**：明确需要评估的决策能力——"是否增开/取消某国际航线""航线定价策略调整""运力如何调配"。这些决策需要精准的效益评估能力支撑。

**步骤②-③支撑指标分析与体系构建**：
- 一级指标：航线综合效益指数
- 二级指标：收入指标（客座率、平均票价、辅营收入）、成本指标（航油成本、起降费、人力成本）、竞争指标（市场份额、竞对价格）
- 三级指标：共细化为32个可量化子指标

**步骤④建立指标数据模型**：为每个三级指标分析所需数据。例如"客座率"指标需要：航班计划数据+订座数据+实际登机数据→构成客座率数据子集。

**步骤⑤-⑥数据子集融合与一致性检验**：将32个数据子集按层次向上融合，发现"航班号"在订座系统和运控系统命名不一致（同一航班前者用"CA1234"，后者用"CA-1234"），通过一致性检验统一为"CA1234"。

**步骤⑦核心数据集评价**：
- 准备级：已制定《航线数据采集规范》
- 平台级：效益评估看板上线，自动生成报表
- 数据级：覆盖200+航线×365天数据
- 利用级：已支撑3条新航线决策，预计年增收800万元
