# 📖 卡片17：数据分类与编码标准化

---

## 📖 教材原文

> 数据分类就是把具有某种共同属性或特征的数据归并在一起，通过其类别的属性或特征来对数据进行区别。
>
> **数据分类基本原则**：
> - 稳定性：选择分类对象的最稳定、最本质的特性作为分类的基础和依据
> - 系统性：按内在规律系统化排列，形成逻辑层次清晰、结构合理、类目明确的分类体系
> - 可扩充性：在类目的设置或层级的划分上留有适当的余地
> - 综合实用性：从实际需求出发，综合各种因素使分类结果总体最优
> - 兼容性：有国标执行国标→无国标执行行标→无行标参照国际标准
>
> **数据编码基本原则**：
> - 唯一性：一个编码对象仅应有一个代码，一个代码只唯一表示一个编码对象
> - 匹配性：代码结构应与分类体系相匹配
> - 可扩充性：代码应留有适当的后备容量
> - 简洁性：代码结构应尽量简单，长度应尽量短
>
> ⚠️ 有些原则彼此冲突，如可扩充性需要留备用码就要牺牲简洁性，需综合考虑使代码设计最优化。

## 🔑 背诵提炼

### 数据分类五原则

| 原则 | 核心要求 |
|:---|------|
| **稳定性** | 选择最稳定、最本质的特性作为分类基础 |
| **系统性** | 逻辑层次清晰、结构合理、类目明确 |
| **可扩充性** | 类目设置和层级划分留有适当余地 |
| **综合实用性** | 综合各种因素，使分类结果总体最优 |
| **兼容性** | 国标优先→行标→国际标准 |

### 数据编码四原则

| 原则 | 核心要求 |
|:---|------|
| **唯一性** | 一个代码只表示一个编码对象 |
| **匹配性** | 代码结构与分类体系相匹配 |
| **可扩充性** | 留有适当后备容量 |
| **简洁性** | 结构简单、长度短 |

### 原则间的冲突

| 冲突 | 说明 |
|:---|------|
| 可扩充性 vs 简洁性 | 留备用码需要更多位，牺牲简洁性 |
| 含义丰富 vs 简洁性 | 携带含义越多，代码越长 |

## 🏢 案例应用

**问**：请以华航飞机型号编码体系为例，说明数据分类与编码标准化的应用。

**答**：华航集团数据平台建立统一的飞机型号分类与编码体系：

**分类设计**：
- 第一层：按制造商分类 → 波音(B)、空客(A)、商飞(C)
- 第二层：按机型系列 → B737、B777、B787、A320、A330、A350
- 第三层：按具体型号 → B737-800、A320-200、A320neo

遵循五大原则：
- **稳定性**：制造商+机型系列是飞机制造业最稳定的特征
- **系统性**：三层树形结构，逻辑清晰
- **可扩充性**：预留新制造商（如C开头给商飞），新系列编码留有空位
- **兼容性**：型号命名兼容ICAO（国际民航组织）标准代码

**编码设计**：
- B738 = 波音(B) + 737系列 + 800型
- A20N = 空客(A) + 320系列 + neo型

遵循四大原则：
- **唯一性**：B738在华航编码体系中唯一对应波音737-800
- **匹配性**：编码结构与三层分类体系完全匹配
- **可扩充性**：备用编码空间支持未来机型加入
- **简洁性**：4位字母数字组合，兼顾含义与简洁

**效果**：统一编码后，飞机维修系统、航班调度系统、财务系统中"波音737-800"均使用B738标识，消除跨系统数据对齐误差。
