# 📖 卡片20：数据安全

---

## 📖 教材原文

> 数据安全包括安全策略和过程的规划、建立与执行，为数据和信息资产提供正确的身份验证、授权、访问和审计。数据安全实践的目标是根据隐私和保密法规、合同协议和业务要求来保护信息资产。
>
> **数据安全要求五大来源**：
> 1. 利益相关方：客户、公民、学生、供应商或商业伙伴的隐私和保密需求
> 2. 政府法规：数据隐私和保护的立法
> 3. 特定业务关注点：专有数据需要保护以维持竞争优势
> 4. 合法访问需求：不同角色需要访问、使用和维护不同数据
> 5. 合同义务：合同中规定的方式保护某些类型的数据
>
> **数据安全六大指导原则**：
> - 协同合作：涉及IT安全管理员、数据管理专员、审计团队、法律部门
> - 企业统筹：保证组织的一致性
> - 主动管理：取决于主动性和动态性
> - 明确责任：明确界定角色和职责
> - 元数据驱动：数据安全分类分级是数据定义的重要组成部分
> - 减少接触以降低风险：最大限度减少敏感/机密数据的扩散
>
> **数据安全活动（5步）**：①识别数据安全需求 → ②制定数据安全制度 → ③定义数据安全细则 → ④评估当前安全风险 → ⑤实施控制和规程（用户访问权限管理、角色分配、权限监控、数据分类、泄露处理）。

## 🔑 背诵提炼

### 五大安全要求来源

| 来源 | 内容 |
|:---|------|
| **利益相关方** | 客户/供应商等的隐私和保密需求 |
| **政府法规** | 数据隐私和保护立法 |
| **特定业务关注点** | 专有数据保护（竞争优势） |
| **合法访问需求** | 不同角色不同数据的访问权限 |
| **合同义务** | 合同中规定的数据保护方式 |

### 六大指导原则

| 原则 | 关键词 |
|:---|:---|
| 协同合作 | IT安全+数据管理+审计+法律 |
| 企业统筹 | 组织一致性 |
| 主动管理 | 主动性+动态性+变更管理 |
| 明确责任 | 跨组织角色和数据"监管链" |
| 元数据驱动 | 安全分类分级纳入数据定义 |
| 减少接触 | 最小化敏感数据扩散（尤其非生产环境） |

### 五步安全活动

①识别安全需求 → ②制定安全制度 → ③定义安全细则 → ④评估安全风险 → ⑤实施控制与规程

## 🏢 案例应用

**问**：华航集团数据平台如何进行数据安全设计以满足等保三级要求？

**答**：华航平台的数据安全设计覆盖五大要求来源和六大原则：

**识别安全需求（步骤①）**：
- 利益相关方：80000名员工的个人信息、千万级旅客数据需隐私保护
- 政府法规：满足网络安全等级保护三级要求、《个人信息保护法》合规
- 业务关注点：航线定价策略、飞机维修关键技术参数属商业机密
- 合法访问：飞行员→飞行数据，维修工程师→维修数据，市场分析师→销售数据，按需分级授权
- 合同义务：与波音、空客的维修数据共享协议有特定安全要求

**制定制度与细则（步骤②③）**：制定《华航数据安全管理制度》，按4级分类（公开→内部→机密→绝密），明确每级数据的存储加密要求、传输加密要求、访问审批流程。制定细则：绝密级数据需双人授权访问、操作全程审计日志。

**安全控制实施（步骤④⑤）**：
- 用户访问权限：RBAC+ABAC混合模型，按角色+属性双重控制
- 数据分类分级：10万数据资产全部分级标注，Atlas+Ranger自动执行分类策略
- 加密措施：存储层AES-256加密，传输层TLS 1.3，密钥由KMS统一管理
- 审计追溯：全量操作日志接入SIEM系统，异常访问实时告警
- 泄露处理：制定数据泄露应急预案，明确通知时限（24小时内上报监管）

**效果**：通过等保三级测评，全年0安全事故。
