# 卡片 09-02：信息安全面临的17种威胁

## 📖 教材原文

对于信息系统来说，威胁可以是针对物理环境、通信链路、网络系统、操作系统、应用系统以及管理系统等方面。

常见的安全威胁有以下几种：信息泄露、破坏信息的完整性、拒绝服务、非法使用（非授权访问）、窃听、业务流分析、假冒、旁路控制、授权侵犯、特洛伊木马、陷阱门、抵赖、重放、计算机病毒、人员渎职、媒体废弃、物理侵入、窃取、业务欺骗。

**按威胁层面分类**：
- **物理环境安全威胁**：自然灾害、电源故障、设备被盗/被毁
- **通信链路安全威胁**：传输线路窃听、通信干扰
- **网络系统安全威胁**：互联网开放性导致的技术窃取
- **操作系统安全威胁**：木马、陷阱门、BIOS万能密码
- **应用系统安全威胁**：网络服务或业务系统的木马/陷阱门
- **管理系统安全威胁**：人员管理疏忽（拷贝、拍照、抄录）

**两个效应**：一是业务运转完全依赖计算机/网络/云存储；二是更多人利用高技术手段非法窃取或攻击。

---

## 🔑 背诵提炼

- **17种威胁速记**（按类型分类）：
  - 信息层面（5种）：信息泄露、破坏完整性、拒绝服务、非法使用、窃听
  - 分析层面（1种）：业务流分析
  - 身份层面（4种）：假冒、旁路控制、授权侵犯、抵赖
  - 程序层面（3种）：特洛伊木马、陷阱门、计算机病毒
  - 物理层面（3种）：媒体废弃、物理侵入、窃取
  - 其他（2种）：重放、业务欺骗、人员渎职
- **6大威胁层面**：物理环境 → 通信链路 → 网络系统 → 操作系统 → 应用系统 → 管理系统
- **核心驱动**：云计算/边缘/AI普及使保护更困难，混合云加剧安全挑战

---

## 🧠 背诵口诀

> **泄破拒非窃分流，假旁授抵特陷毒，媒侵窃重欺渎职**（22字覆盖17种威胁）

- 泄破拒非窃 = 信息泄露/破坏完整性/拒绝服务/非法使用/窃听
- 分流 = 业务流分析
- 假旁授抵 = 假冒/旁路控制/授权侵犯/抵赖
- 特陷毒 = 特洛伊木马/陷阱门/计算机病毒
- 媒侵窃 = 媒体废弃/物理侵入/窃取
- 重欺渎职 = 重放/业务欺骗/人员渎职

---

## 🏢 案例应用

**华航集团**在项目启动前的安全风险评估中，系统梳理了17种威胁在本项目场景中的具体表现：

- **信息泄露风险**：航线和定价数据若被竞争对手获取，将造成重大商业损失 → 部署数据防泄露（DLP）系统，分级管控导出行为；
- **拒绝服务风险**：售票系统遭受DDoS攻击将导致春运期间服务中断 → 部署抗DDoS清洗设备，峰值防护能力≥500Gbps；
- **授权侵犯风险**：内部运维人员越权访问旅客个人信息 → 实施最小特权原则+特权账户管理，所有敏感操作需双人审批；
- **业务欺骗风险**：伪基站冒充华航官方APP窃取旅客账号 → 部署APP安全加固+代码签名+渠道监测；
- **计算机病毒风险**：勒索病毒加密数据分析平台核心数据 → 部署终端EDR+离线备份+3-2-1备份策略。
