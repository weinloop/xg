# 卡片 09-13：信息安全运营体系规划——安全控制方法

## 📖 教材原文

信息安全运营的主要目的是保护资产，包括信息、数据、系统、设备、设施、应用程序等。

**1. 因需可知和最小特权**
- 因需可知（Need to Know）：仅授予用户执行工作所需数据或资源的访问权限，主要目的是让秘密信息保持秘密状态。
- 最小特权（Least Privilege）：主体仅被授予执行指定工作所需的特权，既包括访问数据的权限，也包括执行信息系统任务的权力。限制和控制特权可保护数据的完整性和保密性。

**2. 职责分离和责任**
职责分离形成一个制衡系统，其中两个或多个用户验证彼此的行为并且必须协同完成必要的工作任务。没有任何一个人可危及信息系统或信息安全。需要两人或更多人串通才可能造成危害，增加了风险成本。在信息系统规划中，需要把流程分解为多个任务或职责，并将这些职责分配给不同的人来预防欺诈。

**3. 其他常用安全运营方法**
- 双人控制：要求经过两个人批准后才能执行关键任务
- 岗位轮换：员工岗位轮换，实现同行评审+减少欺诈+交叉培训
- 强制休假：强制休假一到两周，提供同行评审形式，有助于发现欺诈和串通
- 特权账户管理：限制特权账户的访问权限，或检测账户是否使用了提升的特权；设计长期持续的检测手段监控提升特权的使用

**4. 安全培训与意识提升**
- 基础知识培训：了解常见安全威胁和攻击方式
- 操作规范培训：掌握公司信息安全政策和操作规范
- 模拟演练培训：模拟真实安全事件场景
- 持续宣传教育：内部通信、安全提示、宣传海报

---

## 🔑 背诵提炼

- **两大基本原则**：
  - 因需可知：仅授予工作所需的数据访问权限（保护秘密）
  - 最小特权：仅授予执行工作所需的特权（保护完整和保密）
- **职责分离**：制衡系统，无人可单独危及安全，需串通≥2人
- **4种额外方法**：
  - 双人控制：两人批准关键任务
  - 岗位轮换：轮换→同行评审+减少欺诈+交叉培训
  - 强制休假：突然实施→接管者可能发现欺诈
  - 特权账户管理：限制+检测提升特权使用
- **4种培训形式**：基础→操作规范→模拟演练→持续宣传

---

## 🧠 背诵口诀

> **因需最小双分离，岗位休假特权齐，基操演宣四培训**

- 因需可知 + 最小特权（核心两原则）
- 双人控制 + 职责分离（制衡两手段）
- 岗位轮换 + 强制休假 + 特权账户（运营三招）
- 基操演宣 = 基础知识+操作规范+模拟演练+持续宣传

---

## 🏢 案例应用

**华航集团**运营体系设计：

| 方法 | 实践 |
|------|-----|
| 因需可知 | 数据权限按"业务线+数据敏感度"矩阵授权，市场部看不到航班安全数据 |
| 最小特权 | 开发人员仅有测试环境权限，生产环境需走堡垒机审批流程 |
| 职责分离 | 安全策略制定（安全部）与执行（IT运维部）分离；代码开发与上线审批分离 |
| 双人控制 | 数据库管理员(DBA)执行高危操作需安全管理员同时在场输入动态口令 |
| 岗位轮换 | 安全运营组3人每半年轮换值守岗位 |
| 强制休假 | 关键岗位人员每年至少连续休假5个工作日，期间由他人接替 |
| 特权账户管理 | 堡垒机管理所有root/admin账户，每次提权操作录屏+告警 |

**安全培训**：新员工入职培训(4h)+全员年度安全培训(8h)+钓鱼邮件模拟(每季度)+安全宣传月活动。培训覆盖率100%，钓鱼中招率从首次的28%降至第4季度的4%。
