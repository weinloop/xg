# 卡片 09-07：SABSA商业应用安全架构

## 📖 教材原文

SABSA（Sherwood Applied Business Security Architecture）是一套信息系统安全架构框架，它以业务视角作为起点，从6个层面提供了信息系统安全架构的完整解决方案。SABSA是一套开放的架构，将不同的信息安全标准方法进行整合，形成一个端到端的安全解决方案，并可以与其他标准无缝结合（如TOGAF和ITIL）。

**1. 六层模型（5W1H + 时间）**

| 视图 | 安全架构 | 要回答的问题 |
|------|---------|------------|
| 业务视图 | 情境安全架构 | 想做什么（What）？资产是什么？ |
| 架构视图 | 概念安全架构 | 为什么做（Why）？动机/风险？ |
| 设计视图 | 逻辑安全架构 | 怎么做（How）？流程/功能？ |
| 构建视图 | 物理安全架构 | 谁参与（Who）？人员/组织？ |
| 实施视图 | 组件安全架构 | 在哪里做（Where）？位置？ |
| 服务管理视图 | 安全服务管理架构 | 什么时候做（When）？时间？ |

**2. SABSA矩阵**：6×6单元矩阵，横轴=资产/动机/流程/人员/位置/时间，纵轴=情境/概念/逻辑/物理/组件/服务管理，每格填入对应安全内容。

**3. SABSA生命周期**：战略与规划 → 设计（逻辑/物理/组件/服务管理架构） → 实施 → 管理与衡量。关键是：在流程早期设置目标绩效指标，投入运行后根据目标衡量实际绩效并管理偏差。

## 🔑 背诵提炼

- **SABSA核心**：业务视角起点 + 6层模型 + 6×6矩阵 + 4阶段生命周期
- **六层模型（从上到下）**：
  - 业务视图→情境安全架构（What-资产）
  - 架构视图→概念安全架构（Why-动机风险）
  - 设计视图→逻辑安全架构（How-流程功能）
  - 构建视图→物理安全架构（Who-人员组织）
  - 实施视图→组件安全架构（Where-位置）
  - 服务管理视图→安全服务管理架构（When-时间）
- **SABSA矩阵**：6层 × 6维度 = 36个单元，完整覆盖安全架构所有方面
- **生命周期4阶段**：战略规划→设计→实施→管理与衡量（目标绩效指标→衡量实际→管理偏差）

## 🧠 背诵口诀

> **业架设构建施服，SABSA六层递进**（12字）

- 业务=情境，架构=概念，设计=逻辑，构建=物理，实施=组件，服务=管理
- 生命周期：**战设施管**（战略规划→设计→实施→管理与衡量）

## 🏢 案例应用

**华航集团**借鉴SABSA框架进行信息安全架构设计：

- **业务视图（情境安全架构）**：识别核心资产——50PB航空数据资产（航线/定价/旅客/财务/航班），资产分级为公开/内部/机密/绝密4级；
- **架构视图（概念安全架构）**：风险分析确定五大动机——数据泄露风险、业务中断风险、合规处罚风险、供应链攻击风险、内部威胁风险；
- **设计视图（逻辑安全架构）**：设计安全服务目录——身份与访问管理(IAM)、数据安全服务、网络安全服务、安全监测与响应(SOC)、密钥管理(KMS)；
- **构建视图（物理安全架构）**：安全团队组织——首席信息安全官(CISO)→安全运营组+安全架构组+合规审计组+应急响应组；
- **实施视图（组件安全架构）**：选型安全产品——某国产WAF、某国产堡垒机、国密加密网关、SIEM平台；
- **管理与衡量**：设置KPI——漏洞修复SLA<48小时（高危<24小时）、安全事件MTTD<30分钟、MTTR<4小时、年度安全培训覆盖率100%。
