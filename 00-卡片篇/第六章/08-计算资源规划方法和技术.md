# 卡片08：计算资源规划方法和技术

---

## 📖 教材原文

计算资源规划涉及多种方法和技术，可以帮助确定和优化计算资源的配置和利用：

**七大方法和技术**：

**①容量规划**：基于历史数据和趋势分析，预测未来计算资源需求。通过收集和分析工作负载数据、性能指标和业务需求，确定所需计算资源规模和配置。

**②性能优化**：通过优化计算资源配置和使用，提高系统性能和效率。措施包括调整资源分配、优化算法、改进网络和存储性能，以提高响应时间和吞吐量。

**③负载均衡**：将工作负载分布到多个计算资源上，确保资源利用均衡和高效。通过硬件或软件实现，将请求分发到多个服务器或虚拟机，减轻单个资源负荷。

**④弹性伸缩**：根据实际需求变化自动扩展或收缩资源。基于预设规则和阈值，通过自动化工具和云服务功能实现，满足变化的负载需求。

**⑤虚拟化和容器化**：提高计算资源利用率和灵活性。虚拟化将物理服务器划分为多个VM；容器化将应用及依赖打包成轻量级容器，实现更快部署和可移植性。

**⑥自动化管理**：简化计算资源管理和配置，提高效率减少人工错误。包括自动化部署、配置管理、监控报警、自动化修复等。

**⑦云资源管理**：云资源管理平台和工具帮助监控、分配和优化云资源。提供可视化界面、自动化调整和成本优化功能。

## 🔑 背诵提炼

| 方法/技术 | 核心目的 | 实施方式 |
|-----------|----------|----------|
| 容量规划 | 预测需求 | 历史数据+趋势分析→确定规模和配置 |
| 性能优化 | 提升效率 | 调资源分配/优算法/改网络存储→提响应吞吐 |
| 负载均衡 | 分摊压力 | 硬件/软件→分发请求到多节点 |
| 弹性伸缩 | 动态调整 | 预设规则+阈值→自动扩缩 |
| 虚拟化&容器化 | 提高利用 | 物理→VM / 应用→容器 |
| 自动化管理 | 减少人工 | 自动部署/配置/监控/修复 |
| 云资源管理 | 统一管控 | 可视平台+自动调整+成本优化 |

## 🏢 案例应用

**问题**：华航集团数据资产智能管理平台在计算资源规划中采用了哪些方法和技术？请逐一说明。

**参考答案**：

华航集团平台系统性地应用了七大计算资源规划方法：

**①容量规划**：基于50PB存量数据+年增长30%~50%的趋势，采用时间序列预测模型，规划了20节点主集群+5边缘节点+2 GPU节点的初始规模，预留30%扩展空间。

**②性能优化**：数据质量引擎采用流批一体架构（Flink），将实时校验（<100ms延迟）和批量审计（T+1）分离执行，避免资源争抢；对高频元数据查询建立Redis缓存层，命中率达85%，响应时间从800ms降至50ms。

**③负载均衡**：硬件LB（2台）以主备模式部署于入口层，K8s Ingress Controller实现应用层7层负载均衡，按请求路径分发到不同微服务。Kafka 5节点集群通过分区策略均衡消息处理负载。

**④弹性伸缩**：K8s HPA基于CPU（>70%）和内存（>80%）阈值自动扩容，结合自定义指标（Kafka消费延迟>5000条）触发专项扩容。春运期间自动扩展3倍算力，无需人工干预。

**⑤虚拟化和容器化**：VMware实现物理资源虚拟化，Docker+K8s实现应用容器化。200+微服务以容器镜像交付，统一CI/CD流水线（Jenkins+ArgoCD）实现自动化构建部署，从代码提交到上线<30分钟。

**⑥自动化管理**：Terraform管理基础设施即代码，Ansible执行批量配置，Prometheus+AlertManager实现自动告警和部分自愈（如Pod重启）。

**⑦云资源管理**：Rancher统一管理多集群，Grafana Dashboard展示全局资源视图，按月生成资源使用报告指导优化决策。
