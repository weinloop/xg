# 📇 卡片13：应用系统组合法（APA）

---

## 📖 教材原文

> 应用系统组合法（APA）是一种用于评估和管理组织应用系统的方法。它通过对现有应用系统进行分析和评估，以确定哪些应用系统需要保留、更新、替换或淘汰，从而优化应用系统组合，提高组织的业务价值和效率。

### APA的主要目标

帮助组织管理其应用系统组合，确保应用系统与组织的业务目标和战略一致，同时降低应用系统的维护成本和风险。它可以帮助组织识别重复、冗余或过时的应用系统，并提供决策支持，以确定如何优化应用系统组合。

### APA的6个步骤

| 步骤 | 内容 |
|------|------|
| **1.应用系统清单** | 收集和整理组织的应用系统清单，包括系统名称、功能描述、技术平台、使用情况等信息 |
| **2.评估应用系统** | 对每个应用系统进行评估，包括业务价值、技术健康状况、维护成本、风险等方面的评估。评估可通过问卷调查、专家访谈、数据分析等方法进行 |
| **3.分析应用系统组合** | 根据评估结果，对应用系统进行分类和分析，识别重复、冗余或过时的系统，找出存在的问题和瓶颈 |
| **4.制定优化策略** | 根据分析结果，制定优化应用系统组合的策略和计划。可能包括更新或替换旧系统、整合重复系统、淘汰不必要的系统等 |
| **5.实施优化计划** | 根据制定的优化策略，实施相应的优化计划。可能涉及系统开发、数据迁移、培训等工作 |
| **6.监测和评估** | 对优化后的应用系统组合进行监测和评估，确保优化效果的实现，并根据需要进行调整和改进 |

## 🔑 背诵提炼

| 要素 | 核心要点 |
|------|---------|
| **定义** | 评估和管理应用系统的方法，优化应用系统组合，提高业务价值和效率 |
| **目的** | 识别重复/冗余/过时系统→保留/更新/替换/淘汰→降低成本与风险 |
| **6步骤** | 清单→评估→分析→策略→实施→监测 |

## 🧠 背诵口诀

```
APA六步走（清评分策施监），
优化组合提价值（保留更新替换淘汰降本增效）。

清——应用清单全收集（名称功能平台使用），
评——多维评估定状况（业务价值/技术健康/成本风险），
分——组合分析识冗余（重复过时瓶颈问题），
策——优化策略定方向（保留/更新/替换/淘汰），
施——实施计划推落地（开发迁移培训），
监——监测评估持续优（效果验证调整改进）。
```

## 🏢 案例应用

**【华航集团项目场景】**

**问题**：华航集团拥有120余套业务系统，系统建设时间跨度大（2005—2024年），技术栈多样，部分系统已严重过时。在数据资产智能管理平台建设前，需要对现有系统进行应用系统组合评估。

**考题形式**：

> 在"华航集团数据资产智能管理平台"项目启动前，集团信息中心希望对120套现有业务系统进行一次应用系统组合评估。请运用APA方法的6个步骤，说明如何开展此次评估。

**参考答案要点**：

**（1）应用系统清单**：
收集120套系统的完整信息，编制《华航集团应用系统清单》：

| 系统分类 | 数量 | 代表系统 | 建设年份 |
|---------|------|---------|---------|
| 核心业务 | 20套 | PSS/RMS/MRO/FOC | 2005-2018 |
| 管理支撑 | 30套 | HR/FMS/OA | 2010-2022 |
| 数据分析 | 15套 | 报表平台/BI | 2015-2024 |
| 基础设施 | 25套 | 监控/日志/认证 | 2008-2022 |
| 其他 | 30套 | 各类辅助系统 | 2008-2023 |

**（2）评估应用系统**：
从四个维度评估每个系统（1-5分）：

| 评估维度 | 高分示例（PSS系统） | 低分示例（旧版OA） |
|---------|-----------------|-----------------|
| 业务价值 | 5分（核心售票业务不可替代） | 2分（已迁移至新OA） |
| 技术健康 | 3分（架构老旧但稳定） | 1分（技术栈已废弃） |
| 维护成本 | 3分（团队经验丰富） | 5分（维护成本极高） |
| 风险 | 4分（数据安全风险需关注） | 4分（随时可能宕机） |

**（3）分析应用系统组合**：
- **重复系统**：3套报表系统功能高度重叠，建议整合为1套统一BI平台
- **冗余系统**：旧版OA、旧版邮件系统等5套系统已被新系统替代，建议淘汰
- **过时系统**：8套系统运行在Windows Server 2008/EOL版本上，存在严重安全隐患

**（4）制定优化策略**：

| 策略 | 涉及系统数 | 具体措施 |
|------|----------|---------|
| 保留 | 85套 | 正常运行，纳入平台数据采集范围 |
| 更新 | 20套 | 升级技术架构，增强数据接口能力 |
| 替换 | 10套 | 用数据资产平台功能替代（如统一报表替代多套报表系统） |
| 淘汰 | 5套 | 旧版OA、旧版邮件等冗余系统退役 |

**（5）实施优化计划**：
分3批次实施——第1批（高优先级）：淘汰5套冗余系统+替换3套报表系统；第2批：更新10套核心系统数据接口；第3批：更新剩余10套系统。

**（6）监测和评估**：
每季度评估一次优化效果，关键指标：系统总数减少比例、维护成本降低比例、数据接口标准化率。
