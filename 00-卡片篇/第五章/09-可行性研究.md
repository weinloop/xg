# 📇 卡片09：可行性研究

---

## 📖 教材原文

> 可行性研究也称可行性分析，是所有项目投资、工程建设或重大改革在开始阶段必须进行的一项工作。可行性研究是指在项目正式开发之前，为取得最佳经济效果，先投入一定的精力，通过一套准则，从经济、技术、管理、社会等方面对项目的必要性、可行性、合理性以及项目所面临的重大风险进行全面系统的分析和科学论证，得出项目是否可行的结论。

### 可行性研究的三种结果

①**可行**，按计划进行；②**基本可行**，对项目要求或方案做必要修改；③**不可行**，不立项或终止项目。

### 可行性研究的8个步骤

| 步骤 | 内容 |
|------|------|
| **1.复查系统目标和规模** | 通过访问关键人员，阅读分析材料，复查确认系统目标和规模，改正含糊不确切的叙述。确保正在解决的问题确实是需要解决的问题 |
| **2.研究目前正在使用的系统** | 阅读分析现有系统文档资料和使用手册，实地考察，画出高层系统流程图，记录接口情况。了解现有系统能做什么，而非如何做 |
| **3.导出新系统的高层逻辑模型** | 从现有物理系统出发导出其逻辑模型，描绘数据流动和处理情况，概括表达对新系统的设想 |
| **4.重新定义问题** | 和用户一起复查问题定义，再次确定工程规模、目标和约束条件，修改已发现的错误 |
| **5.导出和评价供选择的方案** | 从逻辑模型出发导出若干物理解法，从技术、经济、操作等方面分析比较，进行成本/效益分析 |
| **6.推荐一个方案并说明理由** | 推荐最好方案并说明理由，进行仔细的成本/效益分析 |
| **7.草拟开发计划** | 包括工程进度表、开发人员和资源需求情况、使用时间 |
| **8.书写文档并提交审查** | 写成可行性研究报告，请用户和使用部门负责人审查决定 |

前4个步骤构成一个循环：定义问题→分析问题→导出试探性解→再次定义→再次分析→再次修改，直到逻辑模型完全符合系统目标。

### 可行性研究的四个方面

**（1）经济可行性**
也叫投资/效益分析。总成本 = 建设成本 + 运行成本；总效益 = 直接经济效益 + 间接社会效益。

**总成本构成**：①设备成本（硬件/软件/机房设施）；②人员成本（工资/加班费/培训费）；③材料成本（材料/能源/消耗品）；④其他成本（工作方式改变开支/维修保养费）。

三种结论：①效益大于成本→值得建设；②成本大于效益→不值得建设；③效益和成本基本持平→需综合判断。

**（2）技术可行性**
- 全面考虑系统建设涉及的所有技术问题
- **尽可能采用成熟技术**（已被反复证明行之有效，成功率高，精细程度和可操作性更好）
- **慎重引入先进技术**（需全面分析成熟程度，实验室阶段技术必须慎重）
- **着眼于具体的开发环境和开发人员**（技术成熟但团队无人掌握=不可行）

**（3）社会可行性**
从政策、法律、道德、制度、管理、人员等社会因素论证。还包括**操作可行性**：问题域手动流程与新系统流程的接近程度、系统业务专业化程度、对用户的使用要求、界面友好程度、用户实际能力。

**（4）管理可行性**
- 组织领导、部门主管是否支持、态度是否坚决
- 管理人员对新系统的态度和配合情况
- 管理基础工作如何，业务处理是否规范
- 新系统导致管理模式、工作习惯改变，管理人员能否接受

### 可行性研究报告

包括：建设任务的提出（背景/必要性/意义）→系统的目标（名称/功能/进度要求）→初步调研概况→初步实施方案与比较→可行性研究（经济/技术/社会/管理四方面）→结论（三种之一）。

### 可行性论证会

可行性研究报告提交后召开。讨论结果两种可能：①同意或基本同意→执行/修改/取消；②有不同意见→若不影响整体结论则留待详细调研解决，若影响则重新调查分析。

报告一旦通过，就成为组织各方共同认识，是以后工作的依据。

## 🔑 背诵提炼

| 要素 | 核心要点 |
|------|---------|
| **三种结果** | 可行→按计划；基本可行→修改；不可行→不立项/终止 |
| **8个步骤** | 复查目标→研究现行→导出逻辑→重新定义→评价方案→推荐方案→草拟计划→提交审查 |
| **四方面** | 经济（成本/效益）、技术（成熟/先进/人员）、社会（政策法律操作）、管理（领导态度/基础/改变） |

**8步骤口诀**：**复研导重评推草交**
**4可行性口诀**：**经技社管**

```
可行性研究八步走（复研导重评推草交），

经技社管四面论（经济技术社会管理）。

经济——成本效益比（建设+运行 vs 直接+间接），
技术——成熟慎先进（成熟优先+人员能用），

报告结构六部分（任务/目标/调研/方案/研究/结论），
论证会通过成共识（各方共同认识→工作依据）。
```

## 🏢 案例应用

**【华航集团项目场景】**

**问题**：华航集团在启动数据资产智能管理平台前需要进行可行性研究。

**考题形式**：

> 作为"华航集团数据资产智能管理平台"项目的系统分析师，请从经济、技术、社会、管理四个方面对该项目进行可行性研究，并撰写可行性研究结论。

**参考答案要点**：

**（1）经济可行性分析**：

| 成本项 | 估算 | 说明 |
|--------|------|------|
| 建设成本 | 设备采购280万+软件开发200万+实施服务100万=580万 | 首年投入 |
| 运行成本 | 云资源120万/年+运维人员80万/年+License 30万/年=230万/年 | 年运行成本 |
| 直接经济效益 | 数据分析效率提升50%（70%→35%找数据时间），年节省人力成本约400万 | 8万员工中2000名数据分析师 |
| 间接社会效益 | 数据质量提升→决策准确性提高；数据共享效率提升→15天→1天审批；合规风险降低 | 难以精确量化 |

**结论**：三年总成本 = 580万 + 230万×2 = 1,040万；三年直接效益 = 400万×3 = 1,200万。直接效益大于成本，且间接效益显著，**经济可行**。

**（2）技术可行性分析**：
- **成熟技术**：Hadoop/Hudi数据湖技术在大规模数据管理领域已成熟（阿里/腾讯等大量案例）；ClickHouse在OLAP场景广泛使用
- **慎重引入**：AI智能推荐（数据资产发现）尚在快速迭代中，采用渐进式引入策略，先上线规则推荐再逐步引入ML模型
- **开发人员**：核心团队30人，其中大数据工程师8人（具备Hadoop/Spark经验），Java工程师15人，前端7人，**技术能力匹配**

**结论**：核心技术成熟，团队能力匹配，**技术可行**。

**（3）社会可行性分析**：
- **政策法律**：《数据安全法》《个人信息保护法》要求企业建立数据分类分级和安全管理机制，本项目正满足合规要求
- **操作可行性**：Web端界面设计遵循"减少记忆负担"原则（智能推荐+默认设置），各区域中心员工无需特殊培训即可操作
- **用户能力**：集团信息中心50人技术团队具备运维能力

**结论**：符合政策法规要求，操作层面可行，**社会可行**。

**（4）管理可行性分析**：
- **领导支持**：集团数据治理委员会已审议通过三年行动规划，列为年度一号工程
- **管理基础**：已建立数据治理委员会、信息中心、各区域IT部门三级管理架构
- **改变接受度**：业务部门虽存在"数据话语权"顾虑，但通过高层推动和数据治理制度保障，预期可接受

**结论**：领导坚决支持，管理基础具备，**管理可行**。

**（5）综合结论**：经经济、技术、社会、管理四方面可行性分析，华航集团数据资产智能管理平台项目**可行，条件成熟，可以立即建设**。建议以迭代增量模型分4个阶段实施，每阶段3-4个月，确保快速交付和风险可控。
