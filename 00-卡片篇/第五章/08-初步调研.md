# 📇 卡片08：初步调研

---

## 📖 教材原文

> 系统的开发工作是从接受用户提出的任务开始的。用户最初提出的任务往往只是一个简单的初始需求，而且常常是罗列一些需要解决的问题。开发人员的首要任务是对用户提出的要求做出准确的认识和估计。为此，必须在开展初步调研的基础上明确问题，并且对任务进行可行性分析。

### 初步调研的目标

建设新系统的要求往往是对原系统进行全面优化，但在正式立项之前必须进行可行性研究，而可行性研究的基础是对系统的初步调研。初步调研的目标就是**掌握用户的概况，对用户提出的各种问题和初始要求进行识别，明确新系统的初步目标，为可行性研究提供基础**。

### 初步调研的特点

初步调研主要围绕规划设计工作进行，应立足于宏观和全面，不需要过于具体和细致。通常是在使用组织的高层进行，站在高层角度观察使用组织的现状，分析现有系统的运行情况。

### 初步调研的具体内容（5项）

| 项目 | 内容 |
|------|------|
| **组织概况** | 组织的规模、历史、行业性质、管理目标与模式、人力、物力、技术、设备、组织等 |
| **组织环境** | 组织的自然环境和社会经济环境、上下级关系、横向联系，特别是与外部组织的信息来往等 |
| **现行系统概况** | 现行系统的功能、技术水平、工作效率和可靠性、人才队伍与管理体制、现行系统在组织中的地位和作用以及存在的问题等 |
| **各方面对新系统的态度** | 组织内部对建立新系统的迫切性、领导的决心以及管理人员和技术人员的积极性 |
| **系统研制工作的资源情况** | 组织内部现有的人力、物力、设备、财力和环境条件，以及能够投入新系统的人力、物力、资金、时间和限制条件等 |

## 🔑 背诵提炼

| 要素 | 核心要点 |
|------|---------|
| **目标** | 掌握用户概况→识别问题和初始要求→明确初步目标→为可行性研究打基础 |
| **特点** | 宏观全面，高层视角，不过于具体细致 |
| **重点** | 了解组织概况、系统外部环境、现行系统概况和重要性、各方态度、研制资源 |

**5项内容口诀**：**概况、环境、现状、态度、资源**

---

## 🧠 背诵口诀

```
初步调研五内容（概环现状态资），
宏观高层不细致（立足全面看大局），
为可行性打基础（明确问题定目标）。

概——组织概况知规模（历史行业人财物），
环——组织环境明关系（上下横向内外联），
现——现行系统清状况（功能技术可靠性），
态——各方态度看决心（领导迫切员工积），
资——研制资源估条件（人力物力资金限）。
```

## 🏢 案例应用

**【华航集团项目场景】**

**问题**：华航集团在启动数据资产智能管理平台建设前，需要首先进行初步调研，为后续可行性研究做准备。

**考题形式**：

> 假设你是"华航集团数据资产智能管理平台"项目的前期调研负责人，请按照初步调研的5项内容，说明你将如何开展初步调研工作。

**参考答案要点**：

（1）**组织概况调研**：
- 规模：华航集团员工8万+，下辖5大区域中心、23家分公司
- 行业性质：大型航空运输企业，覆盖客运、货运、机务等全产业链
- 管理目标与模式：集团总部管控+区域中心运营的两级管理模式
- IT现状：已建成核心业务系统约120套，但系统建设分散，缺乏统一的数据资产管理平台

（2）**组织环境调研**：
- 自然环境：总部+5区域中心分布全国（华北/华东/华南/西南/西北），网络条件差异较大
- 上下级关系：集团数据治理委员会为最高决策机构→集团信息中心为执行部门→各区域/分公司IT部门为落地单位
- 外部联系：需与民航局进行数据报送，与机场、空管等外部单位进行数据交换

（3）**现行系统概况调研**：
- 功能：当前各业务系统独立运行（FOC/PSS/RMS/MRO/HR/FMS等），跨系统数据整合需人工操作
- 技术水平：各系统建设年代不一，技术栈差异大（Java/.NET/PHP等），数据标准不统一
- 存在问题：数据孤岛严重（旅客ID 12种编码规则）、数据质量堪忧（报表差异率15-20%）、数据共享困难（审批周期15个工作日）

（4）**各方面对新系统的态度调研**：
- 集团领导：2024年3月数据治理委员会审议通过三年行动规划，平台列为年度一号工程，决心坚定
- 业务部门：数据分析师70%时间用于找数据，迫切希望改变；但部分业务部门担心数据共享后失去"数据话语权"
- IT部门：技术团队积极支持，但担心与120套系统对接的工作量

（5）**系统研制工作的资源情况调研**：
- 人力：集团信息中心现有50人，计划外包核心开发团队30人
- 财力：项目总预算580万/年（三年期1,740万元）
- 物力：现有服务器100+台，计划新增Hadoop集群和GPU服务器
- 限制条件：需在14个月内完成建设，不能影响现有120套业务系统的正常运行

| 调研项目 | 关键发现 | 影响判断 |
|---------|---------|---------|
| 组织概况 | 8万人/29节点/120套系统 | 规模大，需统一平台 |
| 组织环境 | 两级管理/分布全国 | 需B/S架构支撑 |
| 现行系统 | 数据孤岛/质量差/共享难 | 建设需求迫切 |
| 各方态度 | 高层坚定/业务有顾虑 | 需加强沟通 |
| 资源情况 | 580万/年，14个月 | 预算紧张但可行 |
