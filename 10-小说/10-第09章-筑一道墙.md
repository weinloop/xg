# 第09章 筑一道墙

> **教材对照**：第9章 信息安全规划（9.1 概述 · 9.2 信息安全架构 · 9.3 规划主要内容 · 9.4 规划案例）

---

## 一、通报来了

旅客主题库上线第二天，民航局内部通报一例同业事件：某航司旅客行程数据经 API 误配路由，流入境外云节点，被定性为**信息泄露**。集团常委会紧急加开安全专题会，刘总点名数据平台：「咱们刚集中旅客证件、航班、特殊服务，**一条缝就是全行业的事故**。」

赵安全把林小白叫进保密室，桌上三份红头：《数据安全法》《个人信息保护法》《民航数据安全管理办法》。

「第 8 章周数据管**数据治理**，这一章管**信息安全规划**——从战略到技术到运营，筑一道墙。你跟陈工一起，两周出《星河航空数据平台信息安全规划》，局方专项检查跟着来。」

林小白问：「防火墙不是早就装了吗？」

赵安全瞪他：「防火墙是砖，规划是城墙图纸。**等保、零信任、出境评估、应急响应**——砖砌哪、门开多大、谁守夜，得先画出来。」

---

## 二、先定级，再谈墙

专题会第一天，赵安全按教材 **9.4 案例三步** 启动：

1. **现状调研与需求分析**  
2. **总体架构与蓝图设计**  
3. **项目规划与实施设计**

调研从**利益相关方诉求**开始——运控要**可用性**，营销要**效率**，法务要**合规**，旅客要**隐私**，局方要**可追溯**。林小白整理成表，挂在数据委墙上。

**等保定级**争论了一下午。数据平台连接 AOC、CRM、财务，承载旅客证件与航班运行数据——赵安全主张**第三级监督保护级**（重要行业信息系统）；财务认为二级够省钱。陈工调出 GB/T 22240 定级要素：社会影响力、规模、服务重要性——「备降处置、证件数据，二级罩不住。」

常委会拍板：**平台整体按等保三级规划**，运控接口域按三级增强，外站报送模块二级指导保护。

等保 **2.0 基本框架** 写入蓝图：

> **一个中心** — 安全管理中心（SOC）  
> **三重防御** — 安全计算环境、安全区域边界、安全网络通信  

实施六步排进计划：**定级 → 基本/特定要求分析 → 风险评估 → 选措施 → 实施保护 → 测评整改**。

同时对标 **ISO/IEC 27001**（规范）+ **27002**（控制措施），与集团已有 ISMS 合并，避免两套制度打架。

## 三、SABSA：从业务情境到物理组件

陈工请来外部顾问，用 **SABSA** 带团队从业务视角画安全，而不是从防火墙端口反推。

**六层模型**（视图→架构）：

| 视图 | 架构层 | 旅客主题库落点 |
|------|--------|----------------|
| 业务 | 情境 | 备降旅客服务、合规报送 |
| 架构 | 概念 | 数据分级、信任域 |
| 设计 | 逻辑 | 身份、访问、加密策略 |
| 构建 | 物理 | 防火墙、网闸、HSM |
| 实施 | 组件 | IAM、API 网关、DLP |
| 服务管理 | 安全服务管理 | SOC、应急、审计 |

**SABSA 矩阵六列**填一行示例——「旅客证件号码」：

- **资产**：敏感个人信息  
- **动机**：服务旅客 vs 防泄露  
- **流程**：离港写入→主库→脱敏展示  
- **人员**：离港员可明文，客服脱敏  
- **位置**：私有云生产区，禁止公有云裸存  
- **时间**：值机起至航班结束后保留周期  

生命周期四段：**战略与规划 → 设计 → 实施 → 管理与衡量**——与平台三期对齐。

**三道安全防线**同步定义：

1. **系统安全架构** — 主机加固、容器安全基线  
2. **安全技术体系架构** — 防火墙、IDS/IPS、加密、网闸  
3. **审计架构** — 全量日志、不可篡改存储、局方抽查接口  

**GB/T 20274.1 保障模型**三维挂在墙上：**保障要素**（技术/工程/管理/人员）、**生命周期**（规划组织→开发采购→实施交付→运行维护→废弃）、**能力成熟度**（基本执行→持续优化）。林小白自评平台现处**计划跟踪级**，目标**充分定义级**。

## 四、风险：CA2847 的另一面

风险工作坊不按威胁百科念经，只问：「如果主题库上线后重演 CA2847，**安全上会怎样**？」

团队按 **9.1.4** 做**基于业务的风险理解**：识别→分析→应对→监控→培训→应急→审计。风险偏好：**运行安全与合规优先于营销便利**。

威胁对照教材清单勾选：

| 威胁 | 场景 |
|------|------|
| **信息泄露** | API 误配出境（同业通报） |
| **完整性破坏** | 备降状态被篡改 |
| **拒绝服务** | 订阅洪峰击垮网关 |
| **假冒/授权侵犯** | 外站终端被盗登录 |
| **人员渎职** | 客服批量导出旅客表 |
| **重放** | 航班状态包重放误导 CRM |

针对对象：**物理环境**（CDC）、**通信链路**（专线/5G）、**网络**（VLAN）、**操作系统**、**应用**（API）、**管理**（特权账号）。

应对策略写入风险登记册：出境 API **默认拒绝**、备降规则**完整性校验**、网关**限流**、外站**设备绑定+双因素**、导出**审批+水印**、关键接口**防重放 nonce**。

陈工强调 **9.1.3 七原则**：**系统性、适用性、时效性、确定性、可行性、易用性、合规性**。营销副总抱怨「客服多三道登录」——赵安全用**易用性**原则答：「SSO 一次，后台强控，前台不折腾。」

**时效性**分三档：短期（等保整改、出境封堵）、中长期 1–3 年（零信任全面化）、远景 3 年+（行业可信数据空间）。

## 五、技术体系：身份、边界与加密

张架构与赵安全联合设计**信息安全技术体系**，林小白记设备与策略对应表。

### 身份认证与访问控制

平台统一 **IAM**：集团 AD 集成，外站**双因素**（密码+短信令牌），特权运维 **USB Key**。

**访问控制四机制**分工：

| 机制 | 用途 |
|------|------|
| **DAC** | 文件级临时授权（少用） |
| **Role-BAC** | 客服/离港/运控/审计角色 |
| **Rule-BAC** | 备降期间自动收紧导出规则 |
| **MAC** | 运控 VRF 高敏域强制策略 |

原则：**最小特权**、**因需可知**、职责分离——导出旅客明细需**双人复核**。

### 边界与检测

- **防火墙** 四部分：服务访问规则、验证工具、包过滤、应用网关——互联网出口与 DMZ 各一套  
- **网闸** 隔离运控 VRF 与平台生产区——订阅只过**单向光闸**或 API 摆渡，老周签字才肯试  
- **IDS/IPS** 部署核心汇聚与 API 网关前  
- **防病毒** 与容器镜像扫描进 CI 流水线  

### 加密

- **对称** AES 存库字段级加密（证件号列）  
- **非对称** RSA 用于 API 签名与密钥交换  
- 传输：**链路** TLS1.3 全程；**节点** VPN；**端到端** 局方专线 SM 系列算法协商（合规要求处）

### 数据出境

法务红线：**旅客行程与证件默认不出境**。公有云分析节点仅限境内可用区；配置审计机器人扫描路由表与 DNS——同业事故的**技术根因**写进培训 PPT。

## 六、组织与运营：守夜人

**信息安全组织体系**调整：

- **最高管理层** — 常委会（刘总）  
- **协调机构** — 数据委安全专班（赵安全牵头）  
- **内部组织** — SOC 7×24、应用安全组、合规组  
- **外部联系** — 局方网安接口、运营商 CERT、等保测评机构  

**运营体系**写入规划：

- 最小特权 + 特权账号季度审计  
- **岗位轮换** + 关键岗**强制休假**（防渎职）  
- 全员**安全意识培训**（ phishing 演练每季）  
- **应急响应** 六级：从「单条质量告警」到「旅客数据大规模泄露」  
- 事件处理：**隔离→取证→恢复→总结→改进**——CA2847 业务应急与安全应急分册，避免混指挥  

林小白被拉进应急小组写「平台 API 误配出境」剧本。演练夜，运维故意把测试桶策略改错——SOC 17 分钟告警，赵安全 32 分钟掐断路由，老周运控未受影响。刘总看计时：「及格，要压到 15 分钟。」

## 七、评审、测评与一道真的墙

两周后，按 **9.4** 组织**规划评审**三会：

| 评审 | 产出 |
|------|------|
| **安全需求评审** | 《现状调研与需求分析报告》 |
| **体系架构评审** | 《信息安全体系架构设计报告》 |
| **实施规划评审** | 《信息安全体系实施规划报告》 |

等保测评机构预审：「一个中心三重防御有图纸，缺的是**安全管理中心**集中策略与日志留存六个月。」赵安全领任务单，张架构加 SIEM 容量。

投产前渗透测试：发现客服门户一处 **IDOR** 越权——林小白写的接口少校角色，被赵安全骂「第 5 章接口定义白学」。连夜修复，复测通过。

冀南 CDC 机房，运控与平台之间物理 **网闸** 亮绿灯。老周第一次主动伸手：「订阅走闸，我不反对了。」

林小白站在机柜前，看指示灯一排排绿。陈工说：「墙是什么？」

「不是一块防火墙，」林小白说，「是**五属性**——保密、完整、可用、可控、不可否认——落在**定级、架构、技术、组织、运营**一整套。同业泄露是**机密性**塌了一角；咱们备降规则是**完整性**；网闸保**可用**；出境策略是**可控**；审计日志是**不可否认**。」

赵安全难得夸人：「及第。下一章张架构要你搞**云原生**——容器、微服务、DevSecOps，墙从网络中心挪到**身份中心**，叫零信任。」
