## 二、法律：从特征到效力层级

林小白先建立框架。**法的四大基本特征**：①调整人的行为或社会关系的规范；②由国家制定或认可并具普遍约束力；③以国家强制力保证实施；④规定权利和义务。

**世界两大法系**：**大陆法系**（成文法、法典化，我国借鉴德国属此）、**英美法系**（判例法、遵循先例）。

**中国特色社会主义法律体系**以宪法为统帅，七大法律部门：宪法相关法、民法商法、行政法、经济法、社会法、刑法、诉讼与非诉讼程序法。

最核心、真题必背的是**效力层级**：

```
纵向：宪法 > 法律 > 行政法规 > 地方性法规 > 规章
横向：同一机关，特别规定优于一般规定
时间：同一机关，新法优于旧法
```

林小白用它判断数据出境问题：《数据安全法》是全国人大常委会的**法律**，效力高于任何地方规定和公司制度——子公司"图省事不审批"直接违法。

**法的效力三种**：对象效力（对人）、空间效力、时间效力（生效时间三种：公布之日起、规定具体时间、符合一定条件时）。

## 四、标准：层级、分类与代号

红线之外是标尺——**标准规范**。

**标准定义（GB/T 20000.1-2014）**：通过标准化活动，按规定程序经协商一致制定，供共同使用和重复使用的文件。

**主要机构**：ISO（最大最权威）、IEC（成立最早）、ITU（历史最长）。

**标准五个层级**（真题高频）：

```
国家标准 · 行业标准 · 地方标准 · 团体标准 · 企业标准
```

**分级分类**他理成口诀：

- **国家标准**分**强制性 + 推荐性**；行业标准、地方标准是**推荐性**；**强制性标准必须执行**  
- **政府主导制定**：强制性国标、推荐性国标、行业标准、地方标准  
- **市场自主制定**：团体标准、企业标准  

**标准编号代号**（必背），林小白做成对照卡：

| 类型 | 代号 |
|------|------|
| 强制性国家标准 | **GB** |
| 推荐性国家标准 | **GB/T** |
| 国家标准样品 | GSB |
| 指导性技术文件 | GB/Z |
| 行业标准 | 主管部门定（电子 SJ、通信 YD、公共安全 GA、金融 JR…） |
| 地方标准 | DB + 行政区划代码 |
| 团体标准 | T |
| 企业标准 | Q |

他这才恍然——前面章节满篇的 GB/T 37043（智慧城市）、GB/T 43439（数字化转型）、GB/T 39116（智能制造），原来都是**推荐性国家标准**。

**标准有效期**：国家标准一般 **5 年**复审；行业/地方标准复审周期一般不超过 5 年；**企业标准复审周期一般不超过 3 年**（呼应第 14 章）。

## 五、IT 服务标准：国际与 ITSS

最后是和本专业最贴近的**信息技术服务标准**。

**国际标准**林小白串成一张表：

| 标准 | 内容 |
|------|------|
| **ISO/IEC 20000** | 第一部 IT 服务管理国际标准 |
| **ISO/IEC 27000** | 信息安全管理体系系列（**27001 为主标准**，前身 BS 7799） |
| **ISO 9000** | 质量管理体系（9000/9001/9004/19011） |
| **ITIL** | IT 基础架构库；v3/v4 五核心：服务战略、设计、转换、运营、持续改进 |

而我国自己的体系是 **ITSS**（信息技术服务标准），是全书管理篇的"标准化总纲"：

**组成要素 PPTR**：**人员（People）、过程（Process）、技术（Technology）、资源（Resource）**——正好对应第 13 章人员、第 14 章过程、第 15-16 章技术与工具、第 6-8 章资源。

**生命周期 PIOIS 五阶段**：规划设计 → 部署实施 → 服务运营 → 持续改进 → 监督管理——和第 12 章服务生命周期一脉相承。

**ITSS 5.0 六类标准**：通用标准、保障标准、基础服务标准、技术创新服务标准、数字化转型服务标准、业务融合标准。体系结构："以**基础服务标准**为底座，以**通用标准和保障标准**为支柱，以**技术创新服务标准和数字化转型服务标准**为引领。"

林小白看着 PPTR 和 PIOIS，豁然开朗："原来这本书的整个管理篇，骨架就是 ITSS——人员、过程、技术、资源四要素，规划、实施、运营、改进、监督五阶段。我学了一整年，最后发现它早就写在标准里了。"

## 六、底座立起来了

合规体系建立后，集团所有项目上线前先过"合规+标准"双闸门：法律红线一票否决，标准对齐才能验收。那家差点吃罚单的子公司补齐了数据出境审批，平台拿全了直播资质。

陈工问林小白这一章、也是知识部分最后一章的体会。他沉思良久："前面 23 章像盖楼——地基、框架、装修、家具。这一章才发现，整栋楼底下还有一层**看不见的地基：法律和标准**。法律是红线，碰不得；标准是标尺，要对齐。最震撼的是 ITSS——我才明白，自己跌跌撞撞学的人员、过程、技术、资源，规划、实施、运营、改进、监督，**早就是国家标准里写好的体系**。规划与管理师，管的就是让技术在**红线之内、标尺之上**持续创造价值。"

刘总站起身，望向窗外的星河市夜景："小白，从困惑的程序员到今天，你把这本书的 24 章都走完了。还剩最后一关——**考场**。下一章，咱们聊聊怎么把这一整年的经历，变成考卷上的分数。"

## 【林小白的考点笔记本】

### 24.1 法律法规
法四特征；两大法系（大陆法系/英美法系）；七大法律部门；⭐**效力层级**（纵向宪法>法律>行政法规>地方性法规>规章；横向特别优于一般；时间新法优于旧法）；法的效力三种；常用法律（《网络安全法》=第一部全面规范网络空间安全基础性法律）；专利三类型（发明/实用新型/外观设计）。

### 24.2 标准规范
标准定义 GB/T 20000.1；机构（ISO 最权威/IEC 最早/ITU 最长）；⭐**五层级**（国家/行业/地方/团体/企业）；分级分类（国标含强制+推荐，强制必须执行；政府主导 vs 市场自主）；⭐**代号**（GB/GB/T/GSB/GB/Z/DB/T/Q）；有效期（国标 5 年、企业 3 年）。

### IT 服务标准
国际：ISO/IEC 20000（第一部 IT 服务管理）、27000（27001 主）、9000、ITIL 五核心；⭐**ITSS**：组成 **PPTR**、生命周期 **PIOIS** 五阶段、5.0 六类标准及体系结构。

| 题干 | 答法 |
