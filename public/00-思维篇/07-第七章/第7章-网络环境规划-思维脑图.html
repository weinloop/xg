7.1 网络架构和主要技术 模七协传拓 ▼
7.1.1 信息网络系统一般体系框架模型（5大功能模块）传服安管环
  • 网络传输平台 — 负责数据传输：传输/路由/交换/有线和无线接入
  • 网络和应用服务平台 — 管理与业务逻辑：DNS/地址分配/OA/WWW/邮件/视频会议
  • 安全服务平台 — 安全防护：加解密/防火墙/入侵检测/漏洞扫描/病毒查杀/审计/数字证书
  • 网络管理和维护平台 — 管理维护+运营系统
  • 环境系统 — 机房建设/环境监控/智能安防/节能降耗/综合布线
7.1.2 OSI七层模型 物数网传会表应 已考
层名称核心功能口诀 7应用层直接向用户提供通信服务（HTTP/邮件/视频等）应 6表示层数据翻译（编解码/加密解密）、格式化、语法选择表 5会话层建立/管理/拆除会话连接会 4传输层端到端可靠传输，差错纠正+流量控制传 3网络层寻址与路由选择，跨网络通信网 2数据链路层比特流→数据包（帧），MAC地址，差错+流量控制数 1物理层物理信道（光纤/双绞线/无线电），机械/电气/功能/规程特性物

上3层(1-3)解决数据通达 | 上4层(4-7)实现端到端应用 ISO 1984年提出

7.1.3 TCP/IP协议族（4层）应传网链 已考
  • 应用层（对应OSI 5-7层）— Telnet/FTP/SMTP/DNS/HTTP/NAT
  • 传输层（对应OSI 4-5层部分）— TCP（面向连接）/UDP（非连接）
  • 互联网络层（对应OSI 3层）— ICMP/IP/IGMP，IPv4 + IPv6
  • 物理和数据链路层（对应OSI 1-2层）— ARP/RARP，基于物理介质成帧传输
IPv4协议 已考 ABC私组
  • 32位地址，点分十进制（如192.121.123.56），≈42亿地址（2011年IANA用尽）
  • 五类地址：A(1-126, /8) → B(128-191, /16) → C(192-223, /24) → D(224-239组播) → E(240-255保留)
  • 私网地址三段：A:10.0.0.0~10.255.255.255 | B:172.16~172.31 | C:192.168.x.x
  • NAT — 私网↔公网地址转换，在网关/路由器实现 | 127.0.0.1 = 本机回环
  • 路由三种类型：直连路由（自动）→ 静态路由（手动）→ 动态路由（RIP/BGP距离矢量、OSPF/IS-IS链路状态）
IPv6协议 新考点 128位·点分16进制
  • 128位地址（IPv4的4倍），前64位网络前缀+后64位接口标识，几乎无限地址
  • 点分十六进制8段，如ABCD:EF01:2345:6789:ABCD:EF01:2345:6789
  • 包头固定40字节（IPv4是20字节+选项），含传输等级/流标签/载荷长度/下一个包头/路程段限制
  • 支持即插即用、自动配置、QoS，更好支撑物联网/AI
7.1.4 传输平台一般架构和主要技术
  • 传输媒介：有线（光纤/双绞线/同轴电缆）+ 无线（长波/中波/短波/超短波/微波）
  • 传输技术：光纤：SDH/PDH/DWDM | 同轴：HFC | 无线：Wi-Fi/DMC/VSAT/2G~6G
  • 路由交换：自治系统（AS） — 内部用OSPF/RIP/IS-IS，AS间用BGP
  • SDN — 软件定义网络，控制与转发分离，SDN控制器统一控制
  • 接入技术：有线：PON(EPON/GPON/10G-PON) | 无线：Wi-Fi/蓝牙
7.1.5 常见网络拓扑结构（8种）总星树环网孔复层
  • 总线 — 单通道，增减方便，稳定性差
  • 星形/双星形 — 中心节点辐射，链路少经济，但中心是瓶颈（双星解决）
  • 树状 — 星形扩展，层次连接，用户接入网常用
  • 环形 — 首尾相连，自愈环保护，稳定性高 | 线形=环形不开环
  • 网状 — 全互连，冗余大稳定，经济性差 | 网孔形 — 网状变种，部分直连
  • 复合型/层级型 — 网状+星形复合，最普遍采用，分层设计
7.2 广域网规划 架技容 ▼
7.2.1 广域网一般架构
  • 运营商网络：全国骨干网 → 省级骨干网 → 城域网 → 接入网（融合IP承载）
  • 城域网三层：核心层（核心路由器+出口）→ 汇聚层（汇聚交换机+IDC/CDN）→ 接入层（OLT等有线/无线接入）
  • 企业广域网：核心层（路由器）→ 汇聚层（三层交换机）→ 接入层（二层交换机）分支通过VPN互联
7.2.2 广域网主要技术 MPLS标·VPN隧·VXLAN广 高频
  • MPLS — IP包加标签(Lable)转发，LDP协议，支持流量工程/CoS/QoS/MPLS VPN
  • VPN — 公有网建虚拟专网，关键技术：隧道+认证+密钥交换；隧道协议：MPLS/PPTP/L2TP/IPSec/GRE/GTP
  • VLAN — 二层隔离，ID范围1~4096（仅4094可用）
  • VXLAN — 24位VNI，支持16M虚拟网络，满足大规模隔离需求
7.2.3 广域网规划六大内容 建需预技拓址 已考案例
  • 1. 建设背景 — 新建/扩容/整合？内部承载/对外服务？
  • 2. 需求分析 — 功能/业务/运维需求 → 网络能力需求（流量流向/技术选择）
  • 3. 项目预算 — 设备费/线路费/配套费/建设+运维+优化成本
  • 4. 技术方向 — 业务功能+性能指标（吞吐量/时延/抖动/丢包率）+技术成熟度+演进方向
  • 5. 网络拓扑设计 — 物理+逻辑，考虑业务云化/AI算力/VLAN/VXLAN
  • 6. IP地址等逻辑资源规划 — IPv4/IPv6地址规划，公网/私网布局，VLAN/VXLAN规划
7.3 局域网规划 VLAN五重点 ▼
7.3.1 局域网一般架构 三大部件：计连传
  • 计算机设备（服务器+工作站）+ 网络连接设备（网卡/集线器/交换机）+ 传输介质（双绞线/光纤）
  • 三层结构：核心层 → 汇聚层 → 接入层（大中型） | 二层结构：核心-汇聚（中型） | 星形：小型
7.3.2 VLAN 6种划分方法 端MAC协组策户 已考 高频
方法核心优点缺点 1. 按端口物理端口分组简单，适合任何规模换端口需重定义 2. 按MAC地址每个MAC配组移动自动保留VLAN初始化全配，仅小型 3. 按网络层协议IP/IPX等分跨交换机，按应用组织效率低，检查帧头费时 4. 按IP组播组播组=VLAN扩至广域网，灵活不适局域网，效率低 5. 按策略端口+MAC+IP+协议组合灵活多变管理复杂 6. 按用户定义特别需求+密码认证定制化强非标准
7.3.3 局域网规划五大重点 划编由树配 必背
  • 1. VLAN划分 — 综合业务/地理/安全考量，可多种方式并存
  • 2. VLAN编号 — VLAN ID范围1~4096，大型局域网需谨慎规划
  • 3. VLAN间路由 — 三种方式：多物理接口 / 子接口(Sub-Interface) / 三层交换机
  • 4. STP设计 — 生成树协议，阻断二层环路，防广播风暴
  • 5. DHCP设计 — 小：出口路由器 | 中：核心三层交换机 | 大：专门DHCP代理服务器
7.4 无线网规划 5G三大·NB窄带·Wi-Fi瘦胖 ▼
7.4.1 5G移动通信 已考 高频新考点
三大场景全称应用 eMBB增强移动宽带高清视频/VR/大流量 uRLLC超高可靠低时延工业控制/远程医疗/自动驾驶 mMTC海量机器类通信智慧城市/智能家居/环境监测
  • 关键指标：峰值10~20Gbps | 时延1ms | 百万连接/km² | 频谱效率×3 | 移动500km/h
  • SBA微服务架构（总线式）：UE → AN → AMF(接入移动) / SMF(会话) / UPF(用户面) / UDM(数据) / AUSF(鉴权) / PCF(策略) / NEF(开放) / NSSF(切片) / NRF(存储)
  • 核心创新：NFV虚拟化 / 控制用户面分离 / 网络切片 / MEC边缘计算 / Polar码 / 毫米波
  • 4G架构：EPC核心网(MME/S-GW/P-GW) + E-UTRAN(eNodeB Mesh互连) | 2013年发牌
7.4.2 NB-IoT（窄带物联网）新考点 广多快低省
  • 授权频谱，半双工，五大特点：覆盖广/连接多/速率快/成本低/耗电少
  • 应用：远程设备状态传输、工业智能终端低功耗低速率场景
  • 非授权频谱对比：LoRa、Sixfox
7.4.3 无线局域网(Wi-Fi)技术
  • 瘦AP — 需AC集中管理，功能丰富，适合大型环境
  • 胖AP — 自带管理平面，分布式，功能少，适合小型
  • 组网架构：二层组网 vs 三层组网 | 直连 vs 旁挂 | 直接转发 vs 隧道转发
  • SSID — 服务集标识，分不同子网络，独立身份验证
  • 注意：AP物理位置、IP分配、VLAN-SSID映射、AC可靠性、用户接入控制
7.4.4 无线网规划五大内容 频覆容站组
  • 1. 无线频率规划 — 有限排他资源，降低干扰提高效率
  • 2. 无线传输覆盖范围 — 考虑建筑遮挡/环境干扰/穿透特性
  • 3. 无线传输容量规划 — 测算用户规模+业务量→所需基站数量
  • 4. 无线基站站址规划 — 位置/电力/网络/干扰/安全/施工+天线方向/隔离/挂高
  • 5. 无线组网规划 — 组网策略+方案+设备选型+安全方案
7.5 网络整体规划的重点事项 管安机布监节 ▼
7.5.1 网络管理五大功能 FCAPS 故配性费安 已考 必背
  • F 故障管理 — 收集告警，判定定位故障，快速恢复
  • C 配置管理 — 配置网络，采集分析配置数据，优化运行
  • A 性能管理 — 采集分析性能数据，了解网络设备运行状况
  • P 计费管理 — 记录资源使用，控制监测费用代价 (Accounting)
  • S 安全管理 — 设备和管理层面安全，保障安全运行

网管三层体系：网元/网络层（MIB+SNMP）→ 管理应用层（五大功能+扩展）→ 表示层（人机交互/Web+C/S）

7.5.2 网络安全四大手段 + 五大重点 防火墙·VLAN域·IDS·SOC
  • 四大手段：防火墙（DDoS防御/访问控制）→ VLAN安全域划分 → IDS/IPS（入侵检测/防御）→ SOC/统一日志（安全审计）
  • 安全四大关注：网络结构 → 访问控制 → 网络入侵防护 → 网络安全审计
  • 安全管理五大重点：安全组织与责任 / 风险管理机制 / 应急处理机制 / 容灾备份机制 / 上线切换+安全运维
7.5.3 机房建设（七大系统）装空电雷消环节
  • 机房装修 / 空调系统 / 电气系统 / 接地和防雷系统 / 消防系统 / 环境监控系统 / 节能降耗系统
  • 综合性专业工程，涉及建筑/暖通/强电/弱电/美学，需专业单位完成
7.5.4 综合布线（三个子系统）建干配
  • 建筑群子系统 — 建筑间连接 | 干线子系统 — 楼内垂直主干 | 配线子系统 — 楼层水平布线
  • 标准化结构化，纳入建筑规划设计，与信息网络/安防/楼宇监控同步设计
7.5.5 监控系统（五类对象+五子系统）
  • 五类对象：动力设备 / 环境设施 / 消防设施 / 安防设施 / 信息网络设备
  • 五子系统：动力环境监测 → 网络设备监控 → 门禁监控 → 环境消防监控 → 统一运维管理平台
  • 作用：自动预警报警、智能运维、提升防护、保障业务长期运行
7.5.6 节能降耗 选密风设智
  • 选址利于节能降成本 | 密封/绝热/配风/气流组织合理降低空调成本
  • 机柜排列分隔冷热气流 | 设备自身节能 | AI智能分析与动态制冷
