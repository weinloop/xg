## 7.1 网络架构和主要技术

网络环境规划是信息系统规划的重要组成部分，要在客户人、财、物预算范围内，规划选择性价比高的网络架构、技术和设备。

### 7.1.1 信息网络系统一般体系框架模型（五大模块）

| 模块 | 职责 |
|------|------|
| **网络传输平台** | 负责数据传输，包括传输/路由/交换/有线和无线接入设备和系统 |
| **网络和应用服务平台** | 网络管理和业务逻辑处理，包括DNS、地址分配、OA/WWW/邮件/视频会议/VOD等 |
| **安全服务平台** | 安全防护，包括加密/防火墙/入侵检测/漏洞扫描/病毒查杀/安全审计/数字证书 |
| **网络管理和维护平台** | 整个系统的管理和维护，对外服务还需运营系统 |
| **环境系统** | 机房建设/环境监控/智能安防/节能降耗/综合布线 |

**记忆口诀：传应安管网**（传输平台、应用服务平台、安全、管理、环境）

### 7.1.2 开放系统互连（OSI）七层模型

ISO于1984年提出，是信息网络通信系统的基本结构模型。

| 层号 | 名称 | 核心功能 |
|------|------|----------|
| 7 | 应用层 | 直接向用户提供通信服务（HTTP、WWW、邮件等） |
| 6 | 表示层 | 数据翻译（编解码/加密解密）、格式化（压缩）、语法选择 |
| 5 | 会话层 | 建立、管理、拆除会话连接 |
| 4 | 传输层 | 端到端可靠透明数据传输，差错纠正和流量控制 |
| 3 | 网络层 | 不同网络间寻址和路由选择，链路建立/保持/终止 |
| 2 | 数据链路层 | 将比特流组织成数据包（MAC地址），同步/差错/流量控制 |
| 1 | 物理层 | 物理硬件方法，光纤/双绞线/无线等，机械/电气/功能/规程特性 |

**记忆口诀：物数网传会表应**（七层自下而上首字）

### 7.1.3 TCP/IP协议族、IPv4、IPv6

#### TCP/IP协议族（四层 vs OSI七层对应关系）

| TCP/IP四层 | 对应OSI | 主要协议 |
|------------|---------|----------|
| 应用层 | 应用层+表示层+会话层（部分） | Telnet、FTP、SMTP、DNS、HTTP、NAT |
| 传输层 | 传输层+会话层（部分） | **TCP**（面向连接、可靠）、**UDP**（非连接、不保证送达） |
| 网络层（互联网络层） | 网络层 | ICMP、**IP**、IGMP |
| 物理和数据链路层 | 数据链路层+物理层 | ARP、RARP |

#### IPv4协议

- **32位**地址（4字节），点分十进制（如192.121.123.56）
- 由网络位+主机位组成
- **五类地址**：

| 类别 | 范围 | 网络位 | 主机位 | 适用场景 |
|------|------|--------|--------|----------|
| A类 | 1.0.0.0~126.255.255.255 | 7bit（126网络） | 24bit（1677万主机） | 大型网络 |
| B类 | 128.0.0.0~191.255.255.255 | 14bit（16384网络） | 16bit（65534主机） | 中型网络 |
| C类 | 192.0.0.0~223.255.255.255 | 21bit（209万网络） | 8bit（254主机） | 小型网络 |
| D类 | 224.0.0.0~239.255.255.255 | — | — | 组播地址 |
| E类 | 240.0.0.0~255.255.255.255 | — | — | 保留 |

**私网地址**：A类 10.0.0.0~10.255.255.255；B类 172.16.0.0~172.31.255.255；C类 192.168.0.0~192.168.255.255

**NAT**：网络地址转换，私网→公网通信的核心技术

**IPv4数据包**：包头20字节固定+选项可变字段。关键字段：版本号、TTL（跳数）、源/目的IP、协议类型等。

**路由**：路由器根据目的IP查找路由表→找到"最匹配"路由条目→转发。路由类型：直连路由（自动）、静态路由（管理员配置）、动态路由（RIP/BGP距离矢量，OSPF/IS-IS链路状态）

#### IPv6协议

- **128位**地址（IPv4的4倍），点分十六进制，8段每段16位
- 前64位网络前缀（寻址路由），后64位接口标识（主机标识）
- 理论地址数≈2¹²⁸，几乎可为地球上每一粒沙子分配地址
- IPv6包头固定40字节，通过扩展包头实现各种功能
- 关键字段：版本、传输等级、流标签、载荷长度、下一个包头、路程段限制（相当于IPv4 TTL）

**记忆口诀：46比**（IPv4=32位/IPv6=128位=4倍）

### 7.1.4 传输平台一般架构和主要技术

| 分类 | 具体技术 |
|------|----------|
| **传输媒介** | 有线：光纤/双绞线/同轴电缆；无线：长波/中波/短波/超短波/微波 |
| **传输技术** | SDH、PDH、DWDM（光纤）；HFC（同轴）；Wi-Fi、DMC、VSAT、2G~6G（无线） |
| **路由交换组网** | 自治系统（AS）：内部路由协议RIP/OSPF/IS-IS；外部路由协议BGP |
| **接入技术** | 早期：Modem/ADSL/HDSL/Cable Modem；当前：PON（EPON/GPON/10G-PON）、Wi-Fi、蓝牙 |

**SDN（软件定义网络）**：将路由/交换设备的控制功能分离，设SDN控制器统一控制数据转发。

### 7.1.5 常见网络拓扑结构（七种）

| 拓扑 | 特点 | 适用场景 |
|------|------|----------|
| **总线型** | 链路少，增减方便，稳定性差 | 小范围 |
| **星形/双星形** | 链路少、利用率高、经济性好；单中心为瓶颈，双星形解决可靠性 | 通用 |
| **树状** | 星形扩展，节点按层次连接 | 用户接入网 |
| **环形** | 结构简单，自愈环稳定性高 | 专线网 |
| **网状/网孔形** | 全互连冗余大、稳定性好，但链路利用率低 | 局间业务量大的节点 |
| **复合型/层级型** | 网状+星形复合，分层设计各层取不同拓扑 | 通信网普遍采用 |

**记忆口诀：总星树环网复**（七种拓扑首字）

## 7.2 广域网规划

### 7.2.1 广域网一般架构

**运营商网络四级架构**：全国骨干网 → 省级骨干网 → 城域网 → 接入网

**IP城域网三层架构**：核心层（核心路由器，互联网出口）→ 汇聚层（汇聚交换机，区域性汇接）→ 接入层（有线/无线接入）

**企业广域网三层架构**：核心层（路由器、网状/双星形）→ 汇聚层（三层交换机、双星形/星形）→ 接入层（二层交换机）

### 7.2.2 广域网主要技术

| 技术 | 核心要点 |
|------|----------|
| **MPLS** | 在IP包增加标签（Label），基于标签转发。设备：LER（边缘）、LSR（核心）；支持流量工程/QoS/VPN |
| **VPN** | 在公有网络中构建专用虚拟网络，关键技术：隧道技术、认证协议、密钥交换。隧道协议：MPLS、PPTP、L2TP、IPSec、GRE、GTP |
| **VLAN** | 二层虚拟局域网，标准支持4094个；**VXLAN**引入24位VNI，支持高达16M个逻辑网络 |

### 7.2.3 广域网规划六大内容

| 序号 | 内容 | 要点 |
|------|------|------|
| 1 | 建设背景 | 全新建设？扩容升级？整合？自用还是对外服务？ |
| 2 | 需求分析 | 功能需求、业务需求、运维需求→网络能力需求 |
| 3 | 项目预算 | 设备费、线路费、配套设施费、建设/运维/优化成本 |
| 4 | 技术方向 | 性能指标（吞吐量/时延/抖动/丢包率）、IPv6/MPLS、技术成熟度 |
| 5 | 拓扑结构设计 | 物理+逻辑设计，分层级复合型，考虑云化/AI算力/VLAN/VXLAN |
| 6 | IP地址规划 | IPv4/IPv6规划，公网/私网布局，VLAN/VXLAN规划 |

**记忆口诀：背需预技拓址**（建设背景、需求、预算、技术、拓扑、地址）

## 7.3 局域网规划

### 7.3.1 局域网一般架构

局域网三大构成：计算机设备 + 网络连接设备 + 网络传输介质

根据规模分为三类架构：
- **多层级结构（大型）**：核心层（网状/双星形）→ 汇聚层（双星形/星形）→ 接入层
- **二层结构（中型）**：核心层-汇聚层
- **星形结构（小型）**：简单交换机直连

### 7.3.2 局域网主要技术——VLAN六种划分方法

| 方法 | 优点 | 缺点 |
|------|------|------|
| **按端口划分** | 定义简单，适合任何大小网络 | 用户换端口需重新配置 |
| **按MAC地址划分** | 用户移动位置自动保留VLAN | 初始化需全部配置，适合小型 |
| **按网络层协议划分** | 广播域可跨多个交换机 | 效率低，检查IP帧头费时 |
| **按IP组播划分** | 可扩展到广域网，灵活 | 不适合局域网，效率不高 |
| **按策略划分** | 组合多种方式，灵活性高 | 配置复杂 |
| **按用户定义划分** | 可特别定制，支持非VLAN用户访问 | 管理成本高 |

### 7.3.3 局域网规划五大重点

| 重点 | 内容 |
|------|------|
| **VLAN划分** | 根据业务/地理/安全要求综合选择划分方式 |
| **VLAN编号** | VLAN ID 1~4096，大型网需谨慎规划 |
| **VLAN间路由** | 三种方式：多物理接口/子接口/三层交换机 |
| **STP设计** | 生成树协议，阻断二层环路防广播风暴 |
| **DHCP设计** | 小：出口路由充当；中：核心三层交换机；大：专门DHCP代理服务器 |

## 7.4 无线网规划

三大类无线网：移动通信网（4G/5G）、专用无线网（NB-IoT等）、无线局域网（Wi-Fi）

### 7.4.1 4G/5G移动通信技术

#### 4G关键特性
- 2013年12月中国发放4G牌照
- 技术：OFDM、软件无线电、智能天线、MIMO、基于IP核心网
- 优势：高速率（下行100Mb/s）、频谱更宽（100MHz/信道）、智能性高、兼容平滑、安全性好

#### 5G三大应用场景（ITU定义）

| 场景 | 缩写 | 面向领域 |
|------|------|----------|
| 增强移动宽带 | eMBB | 移动互联网极致体验 |
| 超高可靠低时延通信 | uRLLC | 工业控制、远程医疗、自动驾驶 |
| 海量机器类通信 | mMTC | 智慧城市、智能家居、环境监测 |

**5G性能指标**：峰值10~20Gb/s、空口时延1ms、百万连接/km²、频谱效率提升3倍+、支持500km/h移动

**5G关键技术**：网络功能虚拟化、控制面与用户面分离、网络切片、边缘计算、微服务架构、极化码、毫米波、Massive MIMO

**记忆口诀：增高低**（eMBB增强、uRLLC高可靠低时延、mMTC海量）

### 7.4.2 NB-IoT等专用无线通信网络技术

| 类型 | 技术 | 应用场景 |
|------|------|----------|
| 短距离高速率 | Wi-Fi、蓝牙 | 智能家居、可穿戴 |
| 短距离低功耗 | ZigBee | 低速近距人机交互 |
| 广域授权频谱 | **NB-IoT** | 远程设备、低功耗低速率 |
| 广域非授权频谱 | LoRa、Sixfox | 物联网 |
| 广域高速率 | 蜂窝通信 | 导航定位、视频监控 |

### 7.4.3 无线局域网（Wi-Fi）技术

**瘦AP vs 胖AP：**

| 对比 | 瘦AP | 胖AP |
|------|------|------|
| 管理方式 | 需AC集中管理 | 自带管理平面 |
| 适用规模 | 大型无线局域网 | 小型规模 |
| 功能 | 更丰富 | 较少 |
| 扩展性 | 好 | 差 |

**组网架构分类**：二层组网 vs 三层组网（AP-AC间经过几层网络）；直连组网 vs 旁挂组网（AC是否在数据流经路径）；直接转发 vs 隧道转发

**SSID**：服务集标识，标识无线网络，实现不同子网的身份验证隔离

### 7.4.4 无线网规划五大重点

| 重点 | 内容 |
|------|------|
| 无线频率规划 | 降干扰、提效率 |
| 覆盖范围规划 | 考虑建筑遮挡、环境干扰、穿透特性 |
| 容量规划 | 用户规模+业务量→无线基站数量 |
| 站址规划 | 地理/电力/网络连接/环境/安全/施工维护等 |
| 组网规划 | 业务需求+技术特性+网络架构+演进路线 |

**记忆口诀：频覆容站网**（五大重点）

## 7.5 网络整体规划的重点事项

### 7.5.1 网络管理和维护功能设计

**ISO定义的网络管理五大功能：**

| 功能 | 说明 |
|------|------|
| **故障管理** | 收集告警，判定定位故障，快速恢复 |
| **配置管理** | 配置网络提供服务，采集分析配置数据 |
| **性能管理** | 采集分析性能数据，了解设备和网络运行状况 |
| **计费管理** | 记录资源使用，控制费用代价 |
| **安全管理** | 网络设备和管理层面的安全 |

**记忆口诀：故配性计安**（五大功能）

**网管系统三层体系结构：**

| 层级 | 功能 |
|------|------|
| 网元/网络层 | 被管设备的MIB和SNMP定义，保存控制/状态信息 |
| 管理应用层 | 实现五大功能+附加功能（辅助决策/资源管理/测试评估） |
| 表示层 | 人机交互界面，大屏/PC/手机多端接入 |

### 7.5.2 网络安全设计和安全管理

**网络安全关注四大方面**：网络结构、访问控制、网络入侵防护、网络安全审计

**安全设备和手段**：防火墙（DDoS防御）、VLAN安全域划分、IDS/IPS（入侵检测/防御）、SOC/统一日志（安全审计）

**安全管理五大重点**：安全组织和责任、风险管理工作机制、应急处理机制、容灾备份机制、系统上线切换及运维方案

### 7.5.3 机房建设

机房建设包括七大系统：机房装修、空调系统、电气系统、接地和防雷系统、消防系统、环境监控系统、节能降耗系统

### 7.5.4 综合布线

**定义**：按标准、统一、简单结构化方式布置建筑物内各种通信线路。

**三大子系统**：建筑群子系统、干线子系统、配线子系统

### 7.5.5 监控系统

**五大监控子系统**：机房动力环境监测、网络设备监控、门禁监控、环境消防监控、统一运维管理平台

**作用**：自动预警报警、智能运维、提升防护效果、创造直接间接利益

### 7.5.6 节能降耗

绿色数据中心建设涉及：选址、密封绝热配风、冷热气流组织、设备节能、AI智能监测分析+动态调节制冷
