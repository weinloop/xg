```
总体规划（战略→设计→运营→退役→改进）→ 战略层（目录/需求/级别）→ 设计层（模式/人/资/技/过）→ 运营层（业务关系/营销/成本/外包）→ 测量与质量（测什么/怎么评）→ 回顾与改进（四级回顾/四要素改进）→ 退役终止（怎么退）
```

### 一、服务管理五大活动（总纲）
**口诀：战设运退改**
- 服务战略规划
- 服务设计实现
- 服务运营提升
- 服务退役终止
- 持续改进与监督


### 二、服务战略规划

**战略规划三活动 → 口诀：目需级**（目录 → 需求 → 级别）
- 服务目录管理
- 服务需求识别
- 服务级别设计

**1. 服务目录管理步骤 → 口诀：成列类详审善**
- 成立管理小组
- 列举服务清单
- 确定服务类别与代码
- 编制服务详述
- 评审并发布服务目录
- 完善服务目录

**2. 客户服务需求 → 口诀：可连能价报**（可用性 → 连续性 → 能力 → 价格 → 报告）
- 可用性需求
- 连续性需求
- 服务能力需求
- 信息安全需求（与可用性不同，单独列出）
- 价格需求
- 服务报告需求

**可用性指标：**
- MTBF = 系统运行时间 / 故障次数（平均无故障时间）
- MTTR = 系统故障耗时 / 故障次数（平均修复时间）
- MTBSI = MTBF + MTTR（平均故障间隔）

**3. SLA / OLA / UC**
- **SLA**（服务级别协议）：供方与客户间
- **OLA**（运营级别协议）：与内部IT部门间
- **UC**（支持合同）：与外部服务供应商间


### 三、服务设计实现

**设计实现五要素 → 口诀：模人资技过**
- 服务模式设计
- 人员要素设计
- 资源要素设计
- 技术要素设计
- 过程要素设计

**1. 服务模式设计**
- 远程服务：远程集中监控 / 远程技术支持
- 现场服务：上门技术支持 / 驻场技术支持

**2. 人员要素设计**
- 岗位职责 / 绩效方案 / 培训方案
- 团队岗位：管理岗 / 技术支持岗 / 操作岗
- 培训：需求分析→内容设计→实施设计→效果评价

**3. 资源要素设计 → 口诀：工台备知**
- 服务工具
- 服务台
- 备件库
- 知识库

**服务工具分类**：监控类 / 过程管理类 / 其他

**4. 技术要素设计**
- 技术研发
- 发现问题：监控阈值 / 测试环境
- 解决问题：标准操作流程SOP / 应急预案 / 知识转移


### 四、服务运营提升

**运营五活动 → 口诀：关营成外持**（业务关系 → 营销 → 成本 → 外包 → 持续改进，其中持续改进在五大活动中已涵盖，运营层面对应前四项）
- 业务关系管理
- 服务营销管理
- 服务成本度量
- 服务项目预算/核算/结算
- 服务外包收益

**1. 业务关系管理 → 口诀：三客商**
- 客户关系管理
- 供应商关系管理
- 第三方关系管理

**客户关系管理活动：** 定期沟通 / 日常沟通 / 投诉管理 / 表扬管理 / 满意度调查 / 增值服务

**增值服务四原则：**
- 不影响现有协议
- 贴合客户需要
- 投入可接受
- 有能力引申

**供应商关系管理活动：** 选择/推荐 / 审核管理 / 协调 / 争议处理 / 支持合同管理

**第三方关系管理活动：** 定期沟通 / 日常沟通 / 信息收集分享 / 关系协调 / 配合支持

**2. 服务营销过程：** 启动准备 → 调研交流 → 能力展示 → 服务达成

**3. 服务成本度量三因素：** 服务对象规模 / 单位工作量 / 调整因子


### 五、服务测量

**服务测量四领域 → 口诀：人资技过**
- 服务人员测量
- 服务资源测量
- 服务技术测量
- 服务过程测量

**服务台关键指标：**
- 接听率 = 响应总数 / 呼叫总数
- 派单准确率 = 首次派单解决数 / 总事件数
- 录单率 = 记录数 / 呼叫总数
- 平均通话时间 = 通话总时间 / 事件总数


### 六、服务质量

**服务质量特性 → 口诀：安可响有友**
- 安全性（可用/完整/保密）
- 可靠性（完备/连续/稳定/有效/可追溯）
- 响应性（及时/互动）
- 有形性（可视/合规/专业）
- 友好性（主动/灵活/礼貌）

**质量管理三活动：** 质量策划 / 质量检查 / 质量改进

**常见质量活动：** 项目质量保证 / 满意度管理 / 投诉管理 / 日常检查 / 质量文化教育 / 体系内审及管审


### 七、服务回顾

**四级回顾机制：**

| 级别 | 内容 | 频率 | 参与者 |
|------|------|------|--------|
| 一级 | 重大事件/投诉沟通 | 不定期 | 系统规划师+客户接口人 |
| 二级 | 月度SLA报告 | 每月 | 系统规划师+客户接口人 |
| 三级 | 季度运营回顾 | 每季度 | +业务关系经理 |
| 四级 | 年度整体回顾 | 每年 | +高层管理人员 |

**与客户回顾（8项）：** 合同执行 / 目标达成 / 服务绩效 / 满意度 / 范围工作量 / 客户业务变化 / 问题及行动 / 上次行动计划进展
