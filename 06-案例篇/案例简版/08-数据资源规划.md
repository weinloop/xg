### 数据资源规划 · 主线完整版


**总逻辑链：**
```
明确作用（为什么做）→ 选择方法（三条路）→ 方法一：稳定信息过程（最详细）→ 方法二：稳定信息结构→ 方法三：指标能力→ 落地保障（标准化+治理+质量+安全）
```


### 一、数据资源规划的作用
**口诀：提缓标市**
- 提质增效
- 缓解数据孤岛问题
- 标准化与共享
- 市场化发展


### 二、三种规划方法
- 基于稳定信息过程的方法
- 基于稳定信息结构的方法
- 基于指标能力的方法


### 三、方法一：基于稳定信息过程

**核心步骤 → 口诀：定业数理功模关**
- 定义职能域
- 各职能域业务分析
- 各职能域数据分析
- 建立领域数据资源管理基础标准
- 建立信息系统功能模型
- 建立信息系统数据模型
- 建立关联模型

**完整内容 → 口诀：分标准研业数，管主分制审**
- 可行性分析
- 确定目标和范围
- 准备
- 业务活动研究
- 建立业务逻辑模型
- 导出并建立数据模型
- 建立管理标准
- 设计主题数据库
- 数据的分布分析
- 制定方案
- 审核、评价方案

**需注意的问题（无口诀）**
- 方法必须来自最高层策划
- 基础是建立业务模型和数据模型
- 核心是模型分析
- 重点是建立主题数据库
- 系统建设要与管理体制相互适应


### 四、方法二：基于稳定信息结构

**步骤 → 口诀：确获建完立**
- 确定目标与系统边界
- 获取初始数据集
- 建立核心数据集
- 完善目标数据集
- 建立信息模型

**建立核心数据集步骤 → 口诀：数主功任核**
- 数据项审查
- 主题审查
- 功能审查
- 任务审查
- 核心数据集审查


### 五、方法三：基于指标能力

**步骤 → 口诀：决支标立数，核集完规**
- 决策评估收集
- 支撑指标分析
- 指标体系构建
- 建立指标数据模型并分析数据集
- 数据子集融合
- 核心数据集的一致性检验
- 核心数据集评价
- 完善目标数据集
- 完成数据资源规划


### 六、数据标准化

### 九、数据治理、质量、安全

**数据治理活动 → 口诀：规制实嵌**

- 制定数据治理战略

- 嵌入数据治理

- 定义高质量数据
- 定义数据质量战略
- 识别关键数据和业务规则
- 执行初始数据质量评估
- 识别改进方向并优先排序
- 定义数据质量改进目标
- 开发和部署数据质量操作

**数据安全活动（无口诀，5步）：**
- 识别数据安全需求
- 制定数据安全制度
- 定义数据安全细则
- 评估当前安全风险
- 实施控制和规程

### 极简速查版

- **规划作用**：提缓标市 → 提质增效/缓解孤岛/标准化共享/市场化
- **三种方法**：稳定信息过程 / 稳定信息结构 / 指标能力
- **稳定信息过程（核心）**：定业数理功模关 → 定义职能域/业务分析/数据分析/建标准/功能模型/数据模型/关联模型
- **稳定信息过程（完整）**：分标准研业数，管主分制审 → 可行分析/定目标范围/准备/业务研究/业务逻辑模型/数据模型/管理标准/主题数据库/分布分析/方案/审核
- **注意事项5条**：最高层策划 / 基础是业务+数据模型 / 核心是模型分析 / 重点是主题数据库 / 适应管理体制
- **稳定信息结构**：确获建完立 → 定目标边界/获取初始数据集/建立核心数据集/完善目标数据集/建立信息模型
- **建核心数据集**：数主功任核 → 数据项/主题/功能/任务/核心数据集审查
- **指标能力**：决支标立数，核集完规 → 决策收集/支撑指标/指标体系/指标数据模型/数据子集融合/一致性检验/核心数据集评价/完善目标/完成规划
- **标准化内容**：标元分数 → 标准体系/元数据/数据元/分类编码
- **标准分类**：指通专 → 指导/通用/专用
- **元数据结构**：内句语 → 内容/句法/语义
- **元数据作用**：描定寻评选 → 描述/定位/发掘/评价/选择
- **数据元结构**：对象特表 → 对象类/特性/表示
- **数据治理**：规制实嵌 → 规划/制定战略/实施/嵌入
- **数据质量7步**：定义高质量→定义战略→识别关键数据与规则→初始评估→识别改进方向排序→定义目标→部署操作
- **数据安全5步**：识别需求→制定制度→定义细则→评估风险→实施控制
