### 人员管理 · 主线完整版


**总逻辑链：**
```
规划岗位（做什么）→ 选对人（怎么招）→ 育好人（怎么培）→ 用好人（怎么考）→ 留好人（怎么薪）→ 职业发展（怎么升）
```


### 一、人力资源管理内容
**口诀：规招维提评**
- 规划
- 招聘
- 维护
- 提升
- 评价


### 二、工作分析

**工作分析作用 → 口诀：招聘发薪设**
- 招聘和选择员工
- 发展和评价员工
- 薪酬政策
- 组织与岗位设计

**工作分析四阶段 → 口诀：明方收评**（明确范围 → 确定方法 → 收集分析 → 评价方法）
- 明确工作分析范围
- 确定工作分析方法
- 工作信息收集和分析
- 评价工作分析方法

**工作分析核心流程：**
- 明确工作分析对象 → 选择收集信息人员 → 编制工作说明书 → 工作分析评价

**工作分析方法分类：**
- 定性：工作实践法 / 直接观察法 / 面谈法 / 问卷法 / 典型事例法
- 定量：职位分析问卷法 / 管理岗位描述问卷法 / 功能性工作分析法


### 三、工作设计
**口诀：内职关**（工作内容 → 工作职责 → 工作关系）
- 工作内容设计
- 工作职责设计
- 工作关系设计


### 四、人力资源供需

**供需三种结果：** 供需适应 / 需求>供给（短缺）/ 需求<供给（过剩）

**需求>供给（短缺）→ 口诀：增时**（增加录用数量 / 延长工作时间或提高生产率）

**需求<供给（过剩）→ 口诀：减退新外辞**（减少加班/鼓励提前退休/减少新进/外包/辞退）

**人力计划三报表：** 供给报表 / 需求报表 / 人力报表


### 五、招聘

**招聘五过程 → 口诀：计发申录评**
- 招聘计划制订
- 招聘信息发布
- 应聘者申请
- 人员甄选与录用
- 招聘评估与反馈

**招聘计划内容（7项，无口诀）：** 岗位需求量及要求 / 发布时间方式渠道 / 对象来源范围 / 招聘方法 / 测试实施部门 / 预算 / 结束及到位时间

**招聘策略三内容：** 负责招聘的人员 / 招聘的来源 / 招聘方法

**招聘面试三程序：** 面试前准备 → 实施面试 → 评估面试结果

**招聘效果九维度 → 口诀：周满成达成本离库依**
- 招聘周期
- 用人部门满意度
- 招聘成功率
- 招聘达成率
- 招聘成本
- 试用期离职率
- 人才库建立
- 新员工满意度
- 外部渠道依赖性


### 六、培训

**培训四步骤 → 口诀：评设实评**（评估需求 → 设定目标 → 设计项目 → 实施与评估）
- 评估组织开展员工培训的需求
- 设定员工培训的目标
- 设计培训项目
- 培训的实施和评估

**培训类型：** 入职培训 / 员工在职培训


### 七、绩效管理

**绩效管理四环节 → 口诀：计实考反**
- 绩效计划
- 绩效实施与监控
- 绩效考核
- 绩效反馈面谈

**绩效改进三步骤：**
- 分析考核结果，找出问题
- 制定改进方案（如个性化培训）
- 实施方案，提供知识技能帮助


### 八、薪酬管理

**薪酬等级五要素 → 口诀：级目差幅重**
- 薪酬等级数
- 目标薪酬
- 薪酬级差
- 薪酬幅度
- 薪酬重叠情况

**薪酬水平调整：**
- 按性质：主动型 / 被动型
- 按内容：奖励性 / 生活指数性 / 年资性 / 效益性

**薪酬结构调整：**
- 纵向：增加薪酬等级 / 减少薪酬等级
- 横向：调整固定与变动比例 / 调整组合模式


### 九、员工职业规划

**管理人员四责任 → 口诀：催化评估辅跟踪**
- 充当催化剂，鼓励员工建立职业规划
- 评估员工发展目标的现实性和合理性
- 辅导员工制定双方接受的行动方案
- 跟踪员工职业规划并指导调整

**组织三责任：**
- 提供职业规划模型、信息、条件和指导
- 提供建立职业规划所需培训
- 提供技能培训和在职培训
