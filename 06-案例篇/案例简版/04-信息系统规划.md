### 信息系统规划 · 主线完整版


**总逻辑链：**
```
定核（规划什么）→ 选路（什么框架）→ 落地（任务/资源/保障）→ 流程（怎么干）→ 工具（用什么方法）
```


### 一、定核：规划七要素
**口诀：战框组技任资保**

- 发展战略
- 主要系统及框架
- 组织体系优化
- 技术体系定义
- 任务体系部署
- 资源体系调度
- 保障体系设定


### 二、选路：框架演进与组织模式

**框架演进口诀：应平互**
- 应用功能为主线
- 平台能力为主线
- 互联网为主线（App化/微服务）

**组织体系**：集中式 / 分权式 / 平衡矩阵式


### 三、落地执行

**1. 任务体系部署 → 口诀：任明匹制定监**
- 任务拆解
- 明确目标
- 匹配组织
- 制定策略
- 定义计划
- 监控实施

**2. 资源体系调度 → 口诀：识关分风**
- 资源识别与评估
- 资源关系与控制
- 资源分配与调度
- 资源风险与优化

**3. 保障体系 → 口诀：组人技资数安**
- 组织保障
- 人员保障
- 技术保障
- 资源保障
- 数据保障
- 安全保障


### 四、干活流程（五步法）

**总口诀：内场深整持**
```
内外部需求挖掘 → 场景化模型分析 → 深度诊断与评估 → 整体与专项规划 → 持续改进
```

**4.1 内部需求挖掘任务**
- 理解组织战略
- 熟悉业务流程
- 收集用户需求
- 评估现有系统
- 感知数字环境

**内部需求注意事项：**
- 以原始信息获取为主
- 避免直接给出解决方案
- 及时开展引导性培训
- 谨慎信息交叉传递
- 关注隐性需求的推演

**4.2 外部需求挖掘任务 → 口诀：科技归还国行**
- 技术趋势研究
- 竞争环境分析
- 标准与规范引用
- 客户期望调研
- 国家战略导入
- 行业趋势分析

**外部需求注意事项：**
- 国家战略与政策引用
- 定性内容转定量对比
- 避免信息安全事件

**4.3 场景模型组成**
- 场景定义 / 角色分析 / 业务分析 / 数据分析 / 技术分析 / 组织分析 / 风险分析 / 政策法律分析

**场景模型关键价值：**
- 提高规划决策的科学性和实践性
- 确保规划与组织发展的衔接
- 降低规划风险和成本
- 促进信息系统规划的共识和沟通

**4.4 深度诊断与评估**
- 成熟度与需求控制
- 诊断与评估模型确立
- 诊断与评估实施

**4.5 整体与专项规划阶段 → 口诀：认整专一**
- 需求整合与确认
- 整体规划
- 专项规划
- 一致性检查

**需求整合维度：**
- 业务领域维
- 能力建设维
- 技术发展维

**整体 vs 专项：**
- 整体 = 宏观（解决思路/框架/原则）
- 专项 = 具体（应用系统/网络环境/云服务/数据中心/信息安全/云原生系统）

**专项规划重点关注：**
- 明确信息系统的管理和使用主体
- 强调单项领域的规划系统性
- 技术路线和技术属性进一步明确和强化
- 配套更加细致的实施路径或计划

**一致性检查内容：**
- 规划成果与需求的对应关系，与战略的一致性
- 规划内容之间的协调一致性（组织/框架/人员/技术/资源/任务等）
- 规划内容的科学性和可行性
- 规划内容与干系人理解的一致性

**4.6 持续改进关注点**
- 持续跟踪组织战略
- 感知技术发展创新
- 关注数据管理和信息安全
- 注重用户体验和用户参与
- 建立监测和评估机制


### 五、方法论（工具库）

**常用方法清单：** 战略目标集转移法 / 企业信息系统规划法 / 关键成功因素法 / 价值链分析法 / Zachman框架

**SST步骤：**
- 识别和解释组织战略集
- 进一步解释和验证组织战略集

**BSP步骤：**
- 定义管理目标 → 定义管理功能 → 定义数据类 → 定义信息结构

**CSF特征 → 口诀：内外监建**
- 内部型CSF
- 外部型CSF
- 监控型CSF
- 建立型CSF

**CSF实施步骤：**
- 确定组织战略目标
- 识别所有成功因素
- 确定关键成功因素
- 识别绩效指标和标准以及测量数据

**VCA步骤：**
- 识别组织价值链
- 确定关键价值增加环节
- 确定关键价值减少环节
- 明确信息技术对关键价值环节的支持

**Zachman步骤 → 口诀：景现构差制优**
- 愿景和原则
- 现状描述分析
- 目标架构定义
- 差距与改进点分析
- 制订实施计划
- 持续改进优化
