### 三、云服务模式（IaaS / PaaS / SaaS / FaaS）

**四种服务模式串记：基平软函**
- IaaS = 基础设施即服务
- PaaS = 平台即服务
- SaaS = 软件即服务
- FaaS = 函数即服务

**IaaS（基础设施即服务）**
- 优点：灵活性 / 可扩展性 / 高可用性和可靠性 / 成本效益
- 适用场景：Web应用部署 / 大规模数据处理 / 备份和灾难恢复

**PaaS（平台即服务）**
- 优点：灵活性 / 简化部署和管理 / 可扩展性 / 高可用性和可靠性
- 适用场景：Web应用开发 / 移动应用开发 / 物联网应用开发 / 大数据和AI应用开发

**SaaS（软件即服务）**
- 优点：方便性 / 可靠性 / 可扩展性 / 成本效益
- 适用场景：办公软件 / 客户关系管理CRM / 人力资源管理HR / 供应链管理SCM

**FaaS（函数即服务）**
- 优点：灵活性 / 可伸缩性 / 可靠性 / 高效性
- 适用场景：微服务架构 / 事件驱动架构 / 云原生应用
