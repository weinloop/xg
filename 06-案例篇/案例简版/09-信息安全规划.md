### 信息安全规划 · 主线完整版


**总逻辑链：**
```
明确属性（保什么）→ 管好风险（怎么防）→ 规划内容（建什么体系）→ 注意事项（别踩什么坑）
```


### 一、信息安全基本属性
**口诀：保完可不否**（保密性 → 完整性 → 可用性 → 可控性 → 不可否认性）
- 保密性
- 完整性
- 可用性
- 可控性
- 不可否认性


### 二、风险管理过程
**口诀：识分应对监控审**
- 风险识别
- 风险分析
- 风险应对
- 风险监控
- 沟通与培训（属于持续贯穿性活动）
- 应急准备（属于响应保障类活动）
- 审计与改进（属于事后闭环活动）

> *注：后三项可按“沟通培训、应急准备、审计改进”展开，便于与流程本身区分。*


### 三、信息安全规划主要内容
**口诀：关组管技运**（关注诉求 → 组织体系 → 管理体系 → 技术体系 → 运营体系）
- 关注利益相关方的安全诉求
- 信息安全组织体系规划
- 信息安全管理体系规划
- 信息安全技术体系规划
- 信息安全运营体系规划


### 四、信息安全规划注意事项（无口诀，4条）
- 追求有效益的安全
- 信息安全战略的校准
- 基于业务的风险理解
- 识别出合规性要求


**总复习口诀一览表：**

| 知识点 | 口诀 |
|--------|------|
| 安全基本属性 | 保完可不否 |
| 风险管理过程 | 识分应对监控审 |
| 规划主要内容 | 关组管技运 |
