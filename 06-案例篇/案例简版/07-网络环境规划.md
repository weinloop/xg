### 网络环境规划 · 主线完整版


**总逻辑链：**
```
网络分层模型（基础）→ 三类网络规划（广域/局域/无线）→ 整体管理（运维+安全）
```


### 一、网络分层模型

**OSI七层 → 口诀：应表会传网数物**
- 应用层 / 表示层 / 会话层 / 传输层 / 网络层 / 数据链路层 / 物理层

**TCP/IP四层 → 口诀：应传网链**
- 应用层 / 传输层 / 网络层 / 数据链路层


### 二、三类网络规划

**1. 广域网规划内容 → 口诀：建需预技拓IP**
- 建设背景
- 需求分析
- 项目预算
- 技术方向
- 网络拓扑结构设计
- IP地址等逻辑资源规划

**2. 局域网规划重点 → 口诀：划编路STP_DHCP**
- VLAN划分
- VLAN编号
- VLAN间路由设计
- STP设计
- DHCP设计

**3. 无线网规划重点 → 口诀：频覆容站组**
- 无线频率规划
- 无线传输覆盖范围规划
- 无线传输容量规划
- 无线基站站址规划
- 无线组网规划


### 三、网络整体规划重点事项（无口诀，6项）
- 网络管理维护 / 网络安全 / 机房建设 / 综合布线 / 监控系统 / 节能降耗


### 四、网络管理功能
**口诀：故配性计安**
- 故障管理
- 配置管理
- 性能管理
- 计费管理
- 安全管理


### 五、网络安全管理重点
**口诀：安风应容制**
- 安全组织和责任
- 风险管理工作机制
- 应急处理工作机制
- 容灾备份工作机制
- 制定系统上线、切换办法及安全运维方案
