### 规范与过程管理 · 主线完整版


**总逻辑链：**
```
标准化原理（底层逻辑）→ 流程规划（怎么建）→ 流程分类（分几类）→ 执行保障（怎么推）→ 流程检查（怎么查）→ 结果应用与优化（怎么改）
```


### 一、标准化的基本原理
**口诀：超系协统动互阶阻**
- 超前预防原理
- 系统优化原理
- 协商一致原理
- 统一有度原理
- 动变有序原理
- 互换兼容原理
- 阶梯发展原理
- 阻滞即废原理


### 二、流程规划工作路径（两种）

**路径一：基于岗位职责**
- 确定各部门代表性岗位
- 与代表性岗位进行工作访谈
- 分解主要工作并评价重要度
- 梳理流程及关键控制要点
- 与各部门负责人访谈补充完善
- 汇总完成流程清单和框架

**路径二：基于业务模型**
- 绘制业务模式简易模型
- 进行模型分解
- 与流程干系人关联对接
- 无法对接的进行岗位访谈
- 完成流程清单和流程总图


### 三、组织流程分类
**口诀：战运支**
- 战略流程
- 运行流程
- 支持流程


### 四、保障流程执行措施（无口诀，8项）
理解流程 / 变更后推广 / 新员工培训 / 找对负责人 / 审计监控 / 固化到信息系统 / 固化到制度 / 文化宣导


### 五、流程检查方法
**口诀：稽绩满审**
- 流程稽查
- 流程绩效评估
- 满意度评估
- 流程审计


### 六、流程稽查（7步，无口诀）
理解流程目的目标 → 确定稽查关键点 → 确定稽查方法 → 设计稽查线路与计划 → 开展稽查 → 提交报告 → 跟进整改


### 七、流程绩效评估

**评估三维度 → 口诀：效效弹**
- 效果
- 效率
- 弹性

**效率典型指标：** 处理时间 / 投入产出比 / 增值时间比例 / 质量成本

**结果分析四内容：**
- 与绩效目标对比
- 组织内部横向比较
- 与同行业竞争对手对比
- 稳定性分析


### 八、流程审计（11步，无口诀）
制订计划 → 确定范围 → 初步调研 → 编制检查表 → 制订实施计划 → 召开首次会议 → 现场审计 → 补充审计 → 编制审计报告 → 召开末次会议 → 改进追踪


### 九、检查结果应用

- 流程优化
- 绩效考核
- 过程控制
- 纠正措施
- 战略调整


### 十、流程优化需求

### 极简速查版

- **标准化8原理**：超系协统动互阶阻 → 超前预防/系统优化/协商一致/统一有度/动变有序/互换兼容/阶梯发展/阻滞即废
- **流程规划路径一（岗位职责）** ：定岗位→访谈→分解评价→梳理控制点→负责人补充→汇总清单
- **流程规划路径二（业务模型）** ：绘模型→模型分解→干系人关联对接→无法对接则岗位访谈→清单总图
- **流程分类**：战运支 → 战略/运行/支持
- **执行保障8措施**：理解流程/变更推广/新员工培训/找负责人/审计监控/固化为信息/固化为制度/文化宣导
- **检查方法**：稽绩满审 → 稽查/绩效评估/满意度评估/审计

- **绩效评估三维度**：效效弹 → 效果/效率/弹性
