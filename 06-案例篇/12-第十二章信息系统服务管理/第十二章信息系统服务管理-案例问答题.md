# 第十二章 信息系统服务管理 - 案例问答题

---

## 试题一：服务战略规划

### 【情景描述】

某银行数据中心与A公司签订了信息系统运维服务合同，合同期为3年。项目启动后，A公司项目经理张工发现此前未进行有效的服务规划设计，导致服务目录不清晰、服务级别协议中关键指标缺失，客户满意度持续走低。张工决定从服务目录管理、服务需求识别和服务级别设计三个环节重新梳理，以规范服务交付。

### 【问题】

**问题1**（8分）：请列出服务目录管理的6个步骤。

**问题2**（10分）：客户对信息系统服务的需求一般可划分为哪6类？请简要说明可用性需求识别涉及的内容和3个关键可用性指标（含计算公式）。

**问题3**（7分）：请分别说明SLA、OLA、UC三者的定义和区别。

---

### 【参考答案】

**问题1**：服务目录管理的6个步骤：

1. **成立管理小组**：成员至少包括市场销售人员、系统规划与管理人员、信息系统服务工程师
2. **列举服务清单**：列出当前正在提供的服务以及准备开展的服务
3. **确定服务类别与代码**：按服务对象的技术维度或服务性质维度进行分类，赋予唯一代码
4. **编制服务详述**：详细描述服务内容、服务目标、服务级别、技术实现方法等
5. **评审并发布服务目录**：通过内部评审后正式发布，作为供方服务交付和管理的基准
6. **完善服务目录**：根据市场需求及业务发展趋势，对服务目录进行持续改进

**问题2**：6类服务需求：

1. **可用性需求**
2. **连续性需求**
3. **服务能力需求**
4. **信息安全需求**
5. **价格需求**
6. **服务报告需求**

可用性需求识别的内容：
- 服务不可用对业务的影响（客户可承受多长停机时间）
- 从业务角度分析，服务不可用（或质量下降）时造成的成本损失

3个关键可用性指标：

| 指标 | 含义 | 计算公式 |
|------|------|---------|
| **MTBF**（平均无故障时间） | 从一次事件恢复到下一次事件发生之间的平均间隔时间 | MTBF = 系统运行时间 / 系统在运行时间的故障次数 |
| **MTTR**（平均故障修复时间） | 故障发生和服务恢复之间的平均时间 | MTTR = 系统故障耗时 / 故障次数 |
| **MTBSD**（平均故障间隔） | 两次相邻事件之间的间隔时间 | MTBSD = MTBF + MTTR |

信息安全需求3方面：机密性（保密性）、完整性、可用性。

价格需求中服务成本6类：设备成本、软件成本、人力成本、第三方支持成本、管理成本、其他成本。

**问题3**：

| 协议类型 | 定义 | 特点 |
|---------|------|------|
| **SLA**（服务级别协议） | 在一定成本控制下，为保障服务的性能和可靠性，服务供方与客户间定义的双方认可的协定 | 合法文档，包括当事人、协定条款、违约处罚、费用和仲裁机构、政策、修改条款、报告形式和双方义务等 |
| **OLA**（运营级别协议） | 与某个内部信息服务部门就某项信息系统服务所签订的后台协议 | 在内部定义所有参与方的责任，将参与方联合在一起提供某项特别服务。如SLA包含高优先级事件恢复总目标，OLA则包含整个支持链各环节的具体目标 |
| **UC**（支持合同） | 服务供需双方签订的有关服务实施的正式合同 | 正规的、具备法律效力的协议，主要由SLA内容加上法律条文中的责任、权利和义务构成 |

三者关系：SLA是面向客户的总体协议，OLA是支撑SLA的内部协议，UC是外部供应商支持的正式合同。SLA的履行需要OLA和UC的支撑。

## 试题二：服务设计实现

### 【情景描述】

某省政务云运维服务项目由B公司中标，项目团队需要在服务设计实现阶段完成服务模式设计、人员要素设计、资源要素设计、技术要素设计和过程要素设计。项目经理李工发现，团队对人员岗位设计、资源要素设计和技术要素设计的理解不够深入，需要逐一明确。

### 【问题】

**问题1**（6分）：请列出信息系统服务模式的分类（2大类4方式），并说明服务模式设计需要注意的3点。

**问题2**（8分）：请说明人员要素设计中人员岗位的3种类型及其职责重点，以及人员绩效方案设计的5个主要活动。

**问题3**（6分）：请列出资源要素设计的4个方面，并分别说明服务台设计的3个注意点和知识库设计的5个注意点。

**问题4**（5分）：请说明技术要素设计应从哪3个方面进行考量？其中"发现问题的技术"和"解决问题的技术"各包含哪些内容？

---

### 【参考答案】

**问题1**：服务模式分类：

| 分类 | 方式 | 服务内容 |
|------|------|---------|
| **远程服务** | 远程集中监控 | 通过特定监控平台对客户信息系统实时监控，发生异常及时介入处理或告知客户 |
| | 远程技术支持 | 通过电话、邮件、远程登录等方式，在客户配合下处理服务请求和排除故障 |
| **现场服务** | 上门技术支持 | 当远程不能解决时，提供按需或定期的上门技术支持服务 |
| | 驻场技术支持 | 派专人常驻客户现场，随时响应服务请求、处理系统故障 |

服务模式设计3个注意点：
1. 选择的服务模式与客户可用性、连续性、安全性等方面的服务需求相一致
2. 服务供方的人员和资源配置与所设计的服务模式相匹配
3. 服务供方具备同时提供多种服务模式的能力，能够根据客户需求变化及时调整服务模式

**问题2**：人员岗位3种类型：

| 岗位类型 | 职责重点 | 示例 |
|---------|---------|------|
| **管理岗** | ①对需方信息系统服务需求的管理（重点关注真实需求的挖掘、分析和信息传递）；②对信息系统服务过程和结果的管理 | 服务总监、服务项目经理、质量经理 |
| **技术支持岗** | ①专业技术能力（具有对应岗位需要的专业知识和技能）；②对服务需求的响应支持能力（工作经验、服务态度和事件响应处理速度） | 主机工程师、网络工程师、数据库工程师 |
| **操作岗** | 按照信息系统服务规范和操作手册，执行服务交付的各个过程 | 呼叫中心热线工程师、系统监控工程师、机房值守人员 |

人员绩效方案设计5个活动：
1. **确定绩效指标**：依据岗位职责不同，定义差异化的绩效管理目标
2. **明确考核信息来源**：明确信息来源及采集方式（如系统故障日志、客户满意度反馈等）
3. **制定绩效指标计算方法**：设置关键参数及计算公式
4. **定义绩效考核周期**：根据岗位职责和工作性质设定不同周期（一般服务人员每季度1次，高级管理人员每半年或1年1次）
5. **设计绩效考核策略**：通过考核结果的公开和反馈，达到引导激励的作用

人员要素设计的5个目标：①确保服务团队组织架构与服务需求和服务模式相适应；②确保配置的服务人员数量能同时满足服务和成本两方面需求；③确保服务人员的能力持续满足服务需求；④保持服务人员稳定的工作状态；⑤保持服务人员的连续性。

人员培训方案设计4活动：培训需求分析→培训内容设计（管理培训/技术培训/工具培训/过程培训/交付和应急培训）→培训实施过程设计（制订计划/确定形式/规范纪律）→培训效果评价（调查问卷/考试/课堂表现/实际操作）。

**问题3**：资源要素设计的4个方面：**服务工具、服务台、备件库、知识库**。

服务工具3类：①监控类工具（监控服务对象状态数据）；②过程管理类工具（服务级别管理、服务报告管理、事件管理、问题管理、配置管理、变更管理、发布管理等）；③其他工具（自动化管理工具）。

服务台设计3个注意点：
1. 设置专门的沟通渠道作为与需方的联络点（热线电话、传真、网站、电子邮箱等）
2. 设定专人负责服务请求的处理
3. 针对沟通渠道整合服务过程，建立管理制度（服务请求的接收、记录、跟踪和反馈机制，日常工作的监督和考核）

知识库设计5个注意点：
1. 针对常见问题的描述、分析和解决方法建立知识库
2. 确保整个组织内的知识是可用的、可共享的
3. 选择一种合适的知识管理策略
4. 知识库具备知识的添加、更新和查询功能
5. 针对知识管理要求制定相关管理制度，并进行知识生命周期管理

备件库设计4注意点：①备件响应方式和级别定义；②备件供应商管理；③备件出入库管理；④备件可用性管理。

**问题4**：技术要素设计应从3个方面考量：**技术研发、发现问题的技术、解决问题的技术**。

**发现问题的技术**：
1. **制定监控指标及阈值表**：识别需要被监控的设备，制定设备监控指标及阈值表
2. **制订测试环境建设计划**：根据服务内容，在考虑服务成本和客户期望的前提下制订仿真测试环境建设计划

**解决问题的技术**：
1. **制定技术活动标准操作流程**：识别技术活动，根据频率和影响程度列出需要标准化操作的技术活动
2. **制定应急预案**：识别重大突发事件类型和等级，进行风险评估，制定应急预案及演练计划
3. **完成知识转移**：识别过往历史资料、基础架构资料、应用系统资料、业务资料等，完整转移到现有服务团队

## 试题三：服务运营提升

### 【情景描述】

某大型制造企业的IT运维服务项目已运营2年，C公司负责运营。近期，企业CIO对服务质量提出了更高要求，同时希望控制运营成本。C公司系统规划与管理师王工需要从业务关系管理、服务成本度量和项目预算核算等方面进行优化，并考虑将部分非核心业务外包。

### 【问题】

**问题1**（10分）：请说明客户关系管理的目标、7项主要活动，以及增值服务需要把握的4个原则。

**问题2**（8分）：请列出服务成本的4个类别并简要说明。服务成本度量需要充分考虑的3个因素是什么？调整因子包括哪3种类型？

**问题3**（7分）：请列出衡量项目收益的4个指标（含计算公式），以及服务外包带来的6项收益。

---

### 【参考答案】

**问题1**：客户关系管理的目标：**服务并管理好客户需求，培养客户对服务更积极的评价和应用，与客户建立长期和有效的业务关系，实现共赢发展**。

7项主要活动：
1. **定期沟通**：履行SLA约定的定期沟通计划，总结回顾服务达成情况，协商处理重点问题，确立后续改进计划
2. **日常沟通**：在日常工作中与客户保持一定频率的接触，了解客户服务感知和需求变化
3. **高层拜访**：把握时机（重要支持事件、投诉处理等），让客户高层了解服务价值，挖掘引导高层需求和期望
4. **投诉管理**：属于应急处理机制，重视客户投诉并及时有效处理，可提升客户对服务的感知
5. **表扬管理**：对客户表扬进行内外部宣传（公开表扬信、经验分享等），营造积极氛围
6. **满意度调查**：①Case by Case满意度调查（针对特定服务事件）；②公开调查（电话/问卷/网站/走访面谈等方式）
7. **增值服务**：超出协议约定内容之外的服务

增值服务4个原则：
1. 不能影响现有协议约定的服务内容
2. 增值服务贴合客户需要
3. 增值服务投入在可接受的范围内
4. 本身有能力对增值服务内容进行引申

供应商关系管理目标4点：①与供应商建立互信、有效的协作关系；②整合资源，共同开拓保持客户；③与供应商建立长期、紧密的业务关系；④实现与供应商的合作共赢。

供应商审核6个方面：①响应能力；②问题解决能力；③问题解决效率；④人员稳定性；⑤客户反馈；⑥合作氛围。

**问题2**：服务成本4个类别：

| 成本类别 | 说明 |
|---------|------|
| **直接人力成本** | 直接参与服务项目人员的劳动报酬、社保规费、人员福利等 |
| **直接非人力成本** | 为达成项目目标所支付的非人力费用，包括办公费、差旅费、培训费、业务费、采购费、租赁费等（必须为特定项目支出） |
| **间接人力成本** | 非项目组人员的人力资源费用分摊（如部门管理人员、PMO人员、组织级配置管理或质量保证人员） |
| **间接非人力成本** | 与达成项目目标相关但不直接服务于特定项目的非人力费用（日常办公场地租赁、通用设备软件采购等，不因项目结束而停止发生） |

服务成本度量3个因素：
1. **服务对象规模**：应用软件采用功能点方法度量，硬件和基础环境计量设备数量
2. **单位工作量**：一定周期内服务于某一类对象所需的人·日数，体现综合效率
3. **调整因子**：3种类型：
   - **服务要求**：需方对供方提出的服务质量要求（通常存在于SLA中）
   - **服务能力**：供方应具备的能力（人员经验、知识背景、自动化运维工具使用等）
   - **服务对象和业务特征**：服务项目或对象自身特点（系统部署方式、用户规模等）

直接人力成本根据工作量度量结果及单位价格直接计算；间接成本通常与直接人力成本高度正相关，按比例分摊计算；直接非人力成本与直接人力成本没有直接关系，其多少通常与项目特点相关。

**问题3**：衡量项目收益的4个指标：

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| **项目投入产出比** | R = K/IN = 1:N | K为投资总额，IN为收入总额，N值越大经济效益越好 |
| **项目投资回报率** | 项目利润/项目投资总额×100% | 反映项目投资的经济回报 |
| **项目净产出** | 收入 - 所有开支 | 净利润产出总额 |
| **人均产出** | 净利润总额/人员数量 | 一定周期内人均产出的净利润水平 |

服务外包6项收益：
1. **成本效益**：按需采购按需付费，不会产生隐性成本，获取专业IT服务
2. **效率提升**：借鉴外包服务商先进管理理念和资源，提升自身IT服务能力
3. **降低风险**：直接获取外包商成熟的风险控制和应对能力
4. **专注于主营业务**：将基础反复的操作工作外包，将精力投入主营业务
5. **管理简单**：只对外包服务商进行结果考核，避免各部门协调困难
6. **提升满意度**：借助外包商成熟的客户满意度管理体系

## 试题四：持续改进与监督 + 服务退役终止

### 【情景描述】

某电信运营商IT运维服务项目已运营5年，服务供方D公司按照SLA要求定期进行服务测量、服务回顾和服务改进。近期，因业务调整，运营商决定不再续签该运维服务合同，服务项目进入退役终止阶段。D公司系统规划与管理师赵工需要做好持续改进的收尾工作，并确保服务退役终止过程顺利实施。

### 【问题】

**问题1**（10分）：请列出服务测量中服务资源测量的4个方面，并说明服务台的关键测量指标（4项，含计算公式）和备件库的测量指标（4项）。

**问题2**（8分）：请说明信息技术服务质量评价模型的5类特性及其子特性，以及服务质量管理的3项主要活动。

**问题3**（7分）：请说明服务回顾的四级机制（级别/内容/频率/参与者），以及服务退役终止阶段沟通管理的4种会议类型。

**问题4**（5分）：请列出服务退役终止阶段面临的4类风险，以及资源回收的4种类型。

---

### 【参考答案】

**问题1**：服务资源测量的4个方面：**信息系统服务运维工具、服务台、备件库、知识库**。

服务台关键测量指标（4项）：

| 指标 | 计算公式 |
|------|---------|
| **接听率** | 服务台人员响应的电话总数量 / 用户呼叫服务台的总数量 × 100% |
| **派单准确率** | 首次派单得到解决的事件或服务请求总数量 / 事件或服务请求总数量 × 100% |
| **录单率** | 接收用户呼叫并做记录的事件或服务请求总数量 / 服务台接到的所有用户呼叫总数量 × 100% |
| **平均通话时间** | 用户呼叫持续总时间 / 事件或服务请求总数量 × 100% |

备件库测量指标（4项）：盘点备件资产、统计备件损坏率、统计备件命中率、统计备件复用率。

知识库测量指标（6项）：收集知识的积累数量、统计知识的利用率、统计知识的更新率、统计知识的完整性、计算各类知识的比重、统计知识新增数量与事件/问题发生数量的对比关系。
