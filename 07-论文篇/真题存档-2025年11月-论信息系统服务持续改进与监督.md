## 真题原文

**论信息系统服务持续改进与监督**

请以"论信息系统服务持续改进与监督"为题，分别从以下三个方面进行论述：

1. 概要叙述你参与过的或者你所在组织开展过的某信息技术服务项目的基本情况（背景目的、组织结构、服务对象，服务内容、交付成果等），并说明你在其中承担的工作。

2. 结合项目实际，论述你对信息系统服务持续改进与监督的认识，可以包括但不限于以下方面：
   （1）服务改进与监督的主要活动和目标。
   （2）结合你的项目，设计服务过程测量的指标。
   （3）结合你的项目，按照人员、资源、技术、过程四个方面介绍你的服务改进的活动。

3. 请结合论文所提到的信息系统服务项目，介绍你是如何进行信息系统服务持续改进与监督的，包括具体做法和经验教训。

## 真题分析

### 出题规律

| 维度 | 分析 |
|------|------|
| 题目格式 | 三段式：①项目概况+角色 → ②理论认识（含3个子题目） → ③做法+教训 |
| 子题目类型 | 活动内容型（改进与监督的主要活动）+ 设计应用型（设计测量指标）+ 要素分解型（人员/资源/技术/过程） |
| 知识点 | 知识点12：信息系统服务管理 |
| 字数要求 | 2000-2500字 |
| 核心框架 | 服务风险管理 → 服务测量 → 服务质量管理 → 服务回顾 → 服务改进 |

### 子题目拆解

| 子题目 | 对应教材知识点 | 写作要点 |
|--------|--------------|---------|
| （1）主要活动和目标 | 服务持续改进五环节 | 风险管理→测量→质量管理→回顾→改进，每环节1-2句定义+1个项目故事 |
| （2）设计服务测量指标 | 服务过程测量 | 必须用表格呈现，包含：指标名/目标值/实际值/评价，覆盖事件/问题/变更/数据服务等维度 |
| （3）人员/资源/技术/过程四方面 | ITSS四要素改进 | 每个要素1段，遵循"问题发现→改进行动→效果验证"叙事弧 |

## 考试趋势预判

基于首考真题，预判未来考试趋势：

1. **子题目必含三类**：活动内容型 + 设计应用型 + 要素分解型，后续考试大概率沿用
2. **"设计"类子题目**：要求考生不是复述理论，而是结合项目"设计"出具体方案（如测量指标表），必须用表格呈现
3. **"要素分解"类子题目**：按ITSS四要素（人员/资源/技术/过程）分解论述，每个要素需有独立故事
4. **"经验教训"**：结尾必须诚实提不足及解决方案，不能只写成功
5. **量化数据**：每个论点至少1个量化数据支撑
