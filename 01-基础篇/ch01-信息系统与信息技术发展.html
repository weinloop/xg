1.1 信息系统及其发展 ​

1.1.1 信息化内涵与特征 ​

📌 信息化的内涵 ​

定义：信息化是计算机技术、网络技术、通信技术等信息技术的广泛应用与传统产业和现代服务业相结合的动态变化过程。与智能化工具相适应的生产力，称为信息化生产力。

内涵包含四大体系：

体系内容
信息网络体系信息资源、各种信息系统、公用通信网络平台
信息产业基础信息科技研发、信息装备制造、信息咨询服务
社会运行环境现代工农业、管理体制、政策法律、规章制度、文化教育、道德观念
效用积累过程劳动者素质提升、国家现代化水平提升、人民生活质量提升、精神文明和物质文明进步

六大启示（主体-时域-空域-手段-途径-目标）：

维度内涵
主体全体社会成员（政府、企业、事业、团体、个人）
时域一个长期的过程
空域政治、经济、文化、军事、社会的一切领域
手段基于现代信息技术的先进社会生产工具
途径创建信息时代的社会生产力，推动社会生产关系及上层建筑改革
目标推动国家综合实力、社会文明素质和人民生活质量的提升

📌 信息化的九大特征 ​

#特征关键词
1广泛性涉及社会各领域（政府/企业/教育/医疗）
2深度性改变生产/经营/管理/服务方式与内容
3快速性信息技术创新和普及，全球迅速推进
4数据量巨大海量数据爆炸式增长（文字/图像/音视频）
5信息交流快速高速度低成本传输，缩小地理隔阂
6处理能力强大复杂数据挖掘/分析/归类短时间完成
7跨界整合互联网+/大数据/AI与传统产业融合
8生产方式改变远程办公/在线教育/电子商务成主流
9安全问题突出个人隐私/网络攻击/虚假信息传播

记忆口诀：广深快速数据大，交流处理跨界化，生产方式全改变，信息安全问题大

📌 国家信息化发展战略（三步走） ​

步骤时间节点目标
第一步到2020年核心关键技术部分领域达国际先进，信息化成现代化建设先导力量
第二步到2025年建成国际领先移动通信网络，根本改变核心技术受制于人的局面
第三步到21世纪中叶信息化全面支撑社会主义现代化国家建设，网络强国地位巩固

《「十四五」国家信息化规划》十大任务：数字基础设施→数据要素资源→创新发展→数字产业→产业数字化转型→数字社会治理→数字政府→数字民生→国际合作→数字化发展治理

1.1.2 信息系统内涵与特征 ​

📌 信息系统的内涵 ​

狭义定义：由计算机硬件、网络和通信设备、软件、信息资源、信息用户和规章制度组成的以处理信息流为目的的人机一体化系统。

广义定义：包含组织内和组织所处环境中重要人员、地点和事情的信息，通过输入→处理→输出三个基本活动将原始数据转变为有用信息，具有决策支持、协调、控制等功能。

广义信息系统三维度：组织 + 管理 + 信息技术

📌 八大特征 ​

特征说明
复杂性多个子系统组成（硬件/软件/数据/网络），相互关联影响
动态性需不断调整以适应环境变化和业务需求发展
可扩展性可根据实际升级、扩展或重组
易用性简单易用，方便访问和操作
实时性快速处理和响应实时数据
安全性严格安全措施防止未授权访问和破坏
可靠性稳定可靠运行，避免系统故障造成损失
成本效益成本与收益保持合理比例

📌 信息系统抽象模型 ​

信息系统 = 管理模型 + 信息处理模型 + 系统实现条件

要素说明
管理模型服务对象领域的专门知识，分析和处理该领域问题的模型（对象的处理模型）
信息处理模型系统处理信息的结构和方法（获取→存储→传输→加工→使用）
系统实现条件可供使用的计算机和通信技术、人员、资源控制与融合

📌 信息系统生命周期（五阶段） ​

系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行和维护
（可行性分析）（需求分析）（概要+详细）（编码+测试）
阶段对应软件生命周期主要工作
系统规划可行性分析与项目开发计划确定项目可行性和目标
系统分析需求分析明确用户需求
系统设计概要设计 + 详细设计架构设计和详细方案
系统实施编码 + 测试开发和测试
系统运行和维护维护持续运行和改进

1.1.3 信息系统发展 —— 诺兰模型 ​

诺兰（1979年）将计算机信息系统发展道路划分为六个阶段。前三个阶段属「计算机时代」，后三个阶段属「信息时代」。

阶段名称主要特点关键问题
①初始阶段计算机仅作办公设备（报表统计/打字）；少数人使用；一般发生在财务部门需求被当作办公设施改善
②传播阶段应用需求增加，开发软件热情高涨，投入大幅增加数据冗余、不一致、难以共享、效率低
③控制阶段管理者开始整体控制IT投入；职能部门内部网络化「部门壁垒」「信息孤岛」
④集成阶段规划设计，建立基础数据库，建成统一信息管理系统预算费用迅速增长
⑤数据管理阶段统一数据库平台/数据管理体系/信息管理平台；资源整合信息共享信息成为重要资源
⑥成熟阶段满足组织各层次需求；IT与管理结合；内外部资源充分整合提升组织竞争力和发展潜力

🔑 考点：诺兰模型六阶段名称和顺序必记！

1.2.4 信息安全 ​

📌 信息安全五属性 ​

属性含义
保密性信息为授权者享用，不泄露给未授权者
完整性信息传送过程不被非法添加、删除、替换
可用性信息和信息系统随时为授权者提供服务
可控性管理者能对信息实施必要的控制管理
不可否认性人们为自己的信息行为负责，提供公证/仲裁证据

📌 信息安全四层次 ​

设备安全 → 数据安全 → 内容安全 → 行为安全

📌 七大信息安全技术措施 ​

#技术核心要点
1身份认证确认操作者身份；方式：静态密码/智能卡/短信/动态口令/USB Key/PKI/生物识别/虹膜
2访问控制防止未授权访问；机制：自主/基于角色/基于规则/强制
3入侵检测系统监视网络/系统运行；分实时检测和事后检测
4防火墙内部网与外部网之间的安全网关；四部分：服务访问规则/验证工具/包过滤/应用网关
5网闸固态开关读写介质隔离两个系统；无协议摆渡；物理隔离
6防病毒策略准则：拒绝访问/检测/控制传播/清除/恢复/替代操作
7数据加密对称加密(DES)→加解密密钥相同；非对称加密(RSA)→公私钥不同

📌 UEBA与态势感知 ​

技术说明
UEBA用户和实体行为分析；基于用户画像+异常检测；三层架构：数据获取层/算法分析层/场景应用层
态势感知安全大数据基础上数据整合→特征提取→态势评估→预测→可视化；四大关键技术：汇聚融合/威胁评估/评估决策支撑/可视化

1.3 新一代信息技术及其发展 ​

1.3.1 物联网（IoT） ​

📌 定义 ​

通过信息传感设备，按约定协议将任何物品与互联网连接，进行信息交换和通信，实现智能化识别、定位、跟踪、监控和管理的网络。

连接关系：T2T（物-物）+ H2T（人-物）+ H2H（人-人）+ M2M

📌 特点 ​

本质角度（3条）：互联 → 识别与通信 → 智能化

产业角度（6条）：感知识别普适化 / 异构设备互联化 / 联网终端规模化 / 管理调控智能化 / 应用服务链条化 / 经济发展跨越化

📌 三层架构 ​

┌─────────────────────────────────────┐

├─────────────────────────────────────┤

📌 关键技术 ​

技术说明
传感器技术物联网获取物理世界信息的基本手段
RFID（射频识别）无线系统；询问器+应答器；每个标签唯一编码；赋予「可跟踪性」
MEMS（微电子机械系统）微型器件系统；信息获取/处理/执行集成

📌 应用领域 ​

智能家居 / 智慧城市 / 工业自动化 / 医疗健康 / 农业智能化 / 物流追踪 / 能源管理

1.3.2 区块链 ​

📌 定义 ​

狭义：按时间顺序将数据区块以顺序相连组成的链式数据结构，以密码学方式保证不可篡改和不可伪造的分布式账本。

广义：利用块链式数据结构验证存储数据 + 分布式节点共识算法生成更新数据 + 密码学保证安全 + 智能合约编程操作数据的分布式基础架构与计算范式。

📌 七大特点 ​

#特点核心含义
1多中心化纯数学方法代替中心化机构，建立去中心化可信系统
2多方维护激励机制确保所有节点可参与验证
3时序数据时间戳信息 → 数据可追溯性
4智能合约灵活可变的脚本代码
5不可篡改篡改一区块需递归修改所有后序区块（代价巨大）
6开放共识任意节点可自由加入，拥完整数据库拷贝
7安全可信非对称加密 + 共识算法算力抵御攻击

📌 三大关键技术 ​

技术核心
分布式账本交易记账由分布多节点共同完成；每个节点保存唯一真实副本
加密算法哈希算法(SHA256)+非对称加密(RSA/ECC)；保证传输/存储/修改安全
共识机制无中心协调下达成一致；常见：PoW/PoS/DPoS/Paxos/PBFT

📌 应用与发展 ​

  • 数字货币（比特币）、金融服务创新、供应链管理、数据安全与隐私保护
  • 趋势：成为互联网基础协议之一（类似TCP/IP）；分层承载不同功能；螺旋式上升发展

1.3.3 云计算 ​

📌 定义 ​

通过网络「云」将巨大的数据计算处理程序分解成无数小程序，通过多台服务器系统处理分析后返回结果。实现「快速、按需、弹性」的服务。

📌 三种服务模式 ​

模式全称提供内容
IaaS基础设施即服务计算、存储、网络等基础设施资源
PaaS平台即服务应用开发与部署平台
SaaS软件即服务完整的软件应用

📌 部署模式：公有云 / 私有云 / 混合云 ​

📌 七大特征 ​

超大规模 / 高可扩展性 / 虚拟化 / 高可靠性 / 通用性 / 廉价性 / 灵活定制

📌 关键技术 ​

技术要点
虚拟化技术单CPU模拟多CPU；可同时运行多个操作系统；容器技术属于OS虚拟化
云存储技术分布式文件系统；集群管理；解决网络存储/联合存储/多节点存储/备份/负载均衡
多租户访问控制基于任务/属性/UCON/BLP等模型；ABE密码机制；租户隔离
云安全技术云自身安全 + 利用云服务保障客户端安全

📌 四大发展趋势 ​

创新 → 垂直（产业化） → 混合（多云） → 生态

1.3.4 大数据 ​

📌 定义 ​

无法在一定时间范围内用常规软件工具捕捉、管理和处理的数据集合，需要新处理模式才能具有更强决策力、洞察发现力和流程优化能力的海量、高增长率和多样化的信息资产。

📌 5V特征 ​

特征英文含义
规模性VolumePB→EB→ZB级；非结构化数据占80-90%
多样性Variety结构化+非结构化（网络日志/音视频/图片/位置）
价值密度Value单位价值低但整体价值高；需要「提纯」
速度Velocity实时分析而非批量分析（区别于传统数据挖掘的最显著特征）
真实性Veracity数据质量和可信度（第5个V）

📌 技术体系 ​

大数据获取 → 分布式数据处理 → 大数据管理 → 大数据应用与服务
（采集/整合/清洗）（Hadoop/Spark/Storm）（存储/管理）（挖掘/分析/可视化）
技术层核心内容
获取技术分布式爬取/高速采集/全网镜像；数据整合（多源异构融合）；数据清洗（清除错误/修复）
处理技术Hadoop（离线复杂） / Spark（离线快速） / Storm（在线实时）
分析技术数据挖掘：网络挖掘/特异群组挖掘/图挖掘；情感语义分析

1.3.5 人工智能（AI） ​

定义：利用计算机或计算机控制的机器来模拟、延伸和扩展人类的智能和感知环境的能力，获取知识并使用知识获得最佳结果的理论、方法、技术及应用系统。

  • 关键技术：机器学习、深度学习、自然语言处理、计算机视觉、语音识别、知识图谱
  • 应用领域：智能制造、智慧医疗、自动驾驶、智能客服、金融风控、智慧教育

1.3.6 边缘计算 ​

定义：一种将主要处理和数据存储放在网络边缘节点的分布式计算形式，在靠近物或数据源头的网络边缘侧，融合网络、计算、存储、应用核心能力的开放平台，就近提供边缘计算服务。

  • 产生原因：满足实时性、数据优化、应用智能、安全与隐私保护等关键需求
  • 与云计算关系：互补而非替代；云负责全局/非实时/长周期，边缘负责局部/实时/短周期

1.3.7 数字孪生 ​

跨层级、跨尺度的现实世界和虚拟世界建立沟通的桥梁，是第四次工业革命的通用目的技术。

  • 核心：在数字空间再造一个与物理实体实时映射的虚拟模型
  • 应用：智能制造、智慧城市（数字孪生城市）、数字政府

1.3.8 新一代信息技术发展总结 ​

新一代信息技术使信息及其相关数据成为重要生产要素和战略资源，推动传统产业不断升级、社会劳动生产率不断提升，带动全球信息化发展和数字化转型，成为世界各国投资和重点发展的战略性产业。
