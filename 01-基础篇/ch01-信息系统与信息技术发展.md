## 1.1 信息系统及其发展

### 1.1.1 信息化内涵与特征

信息化是计算机技术、网络技术、通信技术等信息技术的广泛应用与传统产业和现代服务业相结合的过程。与智能化工具相适应的生产力，称为**信息化生产力**。

#### 一、信息化的内涵

信息化强调信息技术在社会各领域的应用，核心是在经济和社会各个领域充分应用基于信息技术的先进社会生产工具（信息系统或软硬件产品），提高信息时代的社会生产力，并推动生产关系和上层建筑的改革。

**信息化内涵的四个方面：**

| 方面 | 内容 |
|------|------|
| 信息网络体系 | 信息资源、各种信息系统、公用通信网络平台 |
| 信息产业基础 | 信息科技研发、信息装备制造、信息咨询服务 |
| 社会运行环境 | 现代工农业、管理体制、政策法律、规章制度、文化教育、道德观念 |
| 效用积累过程 | 劳动者素质提高、国家现代化水平提升、物质文明和精神文明进步 |

**信息化内涵的六点启示：**

| 维度 | 启示内容 |
|------|----------|
| 主体 | 全体社会成员（政府、企业、事业、团体、个人） |
| 时域 | 一个长期的过程 |
| 空域 | 政治、经济、文化、军事和社会的一切领域 |
| 手段 | 基于现代信息技术的先进社会生产工具 |
| 途径 | 创建信息时代社会生产力，推动生产关系及上层建筑改革 |
| 目标 | 推动国家综合实力、社会文明素质和人民生活质量的提升 |

#### 二、信息化的特征

| 特征 | 说明 |
|------|------|
| 广泛性 | 涉及政府、企业、教育、医疗等社会各领域 |
| 深度性 | 改变生产、经营、管理、服务等活动的方式和内容 |
| 快速性 | 信息技术不断创新普及，全球化迅速推进 |
| 数据量巨大 | 文字、图像、音视频等海量数据爆炸式增长 |
| 信息交流快速 | 高速度低成本传输，缩小地理距离 |
| 信息处理能力强大 | 复杂数据挖掘、分析短时间内完成 |
| 跨界整合 | 互联网+、大数据、AI与传统产业融合 |
| 社会生产方式改变 | 远程办公、在线教育、电子商务成为主流 |
| 信息安全问题突出 | 隐私保护、网络攻击、虚假信息传播 |

#### 三、我国信息化发展战略

《国家信息化发展战略纲要》（2016年7月）三步走建设网络强国：

| 步骤 | 时间 | 目标 |
|------|------|------|
| 第一步 | 到2020年 | 核心关键技术部分领域达国际先进，信息产业竞争力大幅提升 |
| 第二步 | 到2025年 | 建成国际领先移动通信网络，根本改变核心技术受制于人局面 |
| 第三步 | 到21世纪中叶 | 信息化全面支撑社会主义现代化国家建设，网络强国地位巩固 |

《"十四五"国家信息化规划》部署十大重大任务：数字基础设施体系、数据要素资源体系、创新发展体系、数字产业体系、产业数字化转型体系、数字社会治理体系、数字政府服务体系、数字民生保障体系、数字领域国际合作体系、数字化发展治理体系。

#### 四、我国信息化管理体制演进（五阶段）

| 阶段 | 时间 | 特征 |
|------|------|------|
| 研究探索阶段 | 1982—1992 | 起步探索 |
| 形成实践阶段 | 1993—1997 | 初步实践 |
| 加速推进阶段 | 1998—2001 | 快速推进 |
| 全面发展阶段 | 2002—2011 | 全面铺开 |
| 创新跨越阶段 | 2012年至今 | 创新引领 |

### 1.1.2 信息系统内涵与特征

#### 一、信息系统的内涵

- **狭义**：由计算机硬件、网络和通信设备、软件、信息资源、信息用户和规章制度组成的以处理信息流为目的的**人机一体化系统**。
- **广义**：包含组织内和环境中重要人员、地点和事情的信息，通过**输入、处理和输出**三个基本活动将原始数据转变为有用信息，具有三个维度——**组织、管理和信息技术**。

#### 二、信息系统的特征

| 特征 | 说明 |
|------|------|
| 复杂性 | 多子系统（硬件、软件、数据、网络）相互关联 |
| 动态性 | 不断调整以适应外部环境和内部需求 |
| 可扩展性 | 可根据实际需求升级、扩展或重组 |
| 易用性 | 简单易用，提高工作效率 |
| 实时性 | 快速处理和响应实时数据 |
| 安全性 | 防止未经授权的访问和破坏 |
| 可靠性 | 稳定可靠运行，避免系统故障造成损失 |
| 成本效益 | 成本与收益保持合理比例 |

#### 三、信息系统抽象模型

信息系统 = **管理模型 + 信息处理模型 + 系统实现条件**的结合

- 管理模型：服务对象领域的专门知识及分析处理模型
- 信息处理模型：系统处理信息的结构和方法
- 系统实现条件：可用的计算机和通信技术、人员、资源控制与融合

#### 四、信息系统生命周期

| 阶段 | 对应软件生命周期 |
|------|------------------|
| 系统规划 | 可行性分析与项目开发计划 |
| 系统分析 | 需求分析 |
| 系统设计 | 概要设计、详细设计 |
| 系统实施 | 编码、测试 |
| 系统运行和维护 | 维护 |

#### 五、信息系统的结构

**1. 物理结构**

| 类型 | 特点 | 优点 | 缺点 |
|------|------|------|------|
| 集中式 | 资源空间集中配置 | 便于管理、利用率高 | 维护困难、主机故障全系统瘫痪 |
| 分布式 | 通过计算机网络连接各地资源 | 扩展性好、安全性好、适应扁平化组织 | 标准不易统一、协调困难 |

**2. 逻辑结构（五层通用结构）**

| 层次（自底向上） | 功能 |
|------------------|------|
| 基础设施层 | 信息感知设备、网络传输设备、存储设备（软硬件基础） |
| 资源管理层 | 操作系统、数据库，负责资源管理与调度 |
| 中间件层 | 传输中间件、交易中间件、GIS中间件等，保障数据传输共享 |
| 业务逻辑层 | 工作流引擎、报表引擎、交易处理引擎，创建统一业务流程 |
| 应用表现层 | UI设计，用户交互界面展示 |

### 1.1.3 信息系统发展——诺兰六阶段模型

诺兰（1979年）总结的计算机信息系统进化阶段模型，反映从手工信息系统向计算机信息系统发展的客观规律。

| 阶段 | 核心特征 | 特点 |
|------|----------|------|
| **1. 初始阶段** | 计算机作为办公设备 | 仅财务部门使用，少数人具备使用能力 |
| **2. 传播阶段** | 应用需求激增 | 数据处理能力快速提高；出现数据冗余、不一致、难以共享等问题 |
| **3. 控制阶段** | 统筹控制IT发展 | 出现计算机管理组织；DB技术应用；开始从计算机管理→数据管理转变 |
| **4. 集成阶段** | 统一信息管理系统 | 建立集中式数据库和信息系统；硬件预算大幅增长 |
| **5. 数据管理阶段** | 信息作为重要资源 | 统一数据库平台和管理体系；各部门资源整合、信息共享 |
| **6. 成熟阶段** | 满足各层次需求 | IT与管理过程融合，内外资源充分整合利用 |

> 前三个阶段具有**计算机时代**特征，后三个阶段具有**信息时代**特征。

## 1.2 信息技术及其发展

信息技术是在信息科学基本原理和方法下，获取、处理、传输和使用信息的应用技术的总称。

- **硬技术（物化技术）**：传感器、服务器、智能手机、通信卫星
- **软技术（非物化技术）**：语言文字技术、数据统计分析技术、计算机软件技术

### 1.2.1 计算机软硬件

#### 一、冯·诺依曼结构（五大部件）

| 部件 | 说明 |
|------|------|
| 控制器 | 指挥系统各部件协调工作（现代集成于CPU） |
| 运算器 | 执行算术和逻辑运算（现代集成于CPU） |
| 存储器 | 存储程序和数据 |
| 输入设备 | 向计算机输入数据 |
| 输出设备 | 将计算结果输出 |

#### 二、计算机软件分类

| 类别 | 说明 | 举例 |
|------|------|------|
| **系统软件** | 为整个系统配置的通用软件，控制管理硬件和软件资源 | 操作系统、数据库、中间件 |
| **应用软件** | 为某类应用或特定问题设计的软件 | 图形图像处理、财务软件、游戏；可分为专用/通用 |

### 1.2.2 计算机网络

#### 一、网络分类

| 按作用范围 | 按使用者 |
|------------|----------|
| 个人局域网(PAN)、局域网(LAN)、城域网(MAN)、广域网(WAN) | 公用网、专用网 |

#### 二、OSI七层模型 vs TCP/IP四层模型

| OSI模型 | TCP/IP模型 | 核心协议 |
|---------|------------|----------|
| 应用层 | 应用层 | HTTP, FTP, SMTP, Telnet, NFS, SNMP |
| 表示层 | ↑ | |
| 会话层 | ↑ | |
| 传输层 | 传输层 | TCP, UDP |
| 网络层 | 网际层 | IP, ICMP, ARP, RARP |
| 数据链路层 | 网络接口层 | Ethernet, FDDI, Token-Ring |
| 物理层 | ↑ | |

#### 三、IEEE 802协议族（重点）

| 协议 | 内容 |
|------|------|
| 802.1 | 802协议概论 |
| 802.2 | 逻辑链路控制层LLC协议 |

#### 四、网络性能指标

| 指标 | 含义 |
|------|------|
| 速率 | 数字信道上传送数据的速率（b/s） |
| 带宽 | 单位时间内最高数据率（b/s） |
| 吞吐量 | 单位时间内通过某网络的数据量 |
| 时延 | 数据从一端传送到另一端所需时间（发送/传播/处理/排队时延） |
| 往返时间(RTT) | 发送方发出数据到收到确认的总时间 |
| 利用率 | 信道利用率/网络利用率（加权平均） |

#### 五、软件定义网络（SDN）

SDN是网络虚拟化的一种实现方式，将网络设备的**控制面与数据面分离**，实现网络流量的灵活控制。

| 平面 | 功能 |
|------|------|
| 数据平面 | 交换机等通用硬件，执行数据转发 |
| 控制平面 | SDN控制器（逻辑中心化），掌握全局网络信息，负责转发规则 |
| 应用平面 | 各种基于SDN的网络应用 |

**SDN接口**：南向接口（CDPI，OpenFlow协议为主流）、北向接口（应用程序调用网络资源）、东西向接口（多控制器通信）。

#### 六、第五代移动通信技术（5G）

三大应用场景（ITU定义）：

| 场景 | 面向领域 |
|------|----------|
| **eMBB**（增强移动宽带） | 移动互联网流量爆炸式增长 |
| **uRLLC**（超高可靠低时延通信） | 工业控制、远程医疗、自动驾驶 |
| **mMTC**（海量机器类通信） | 智慧城市、智能家居、环境监测 |

### 1.2.3 数据存储和数据库

#### 一、数据存储技术架构（五层）

| 层次 | 划分方式 |
|------|----------|
| 存储介质 | HDD(机械硬盘)、SSD(固态硬盘)、磁带、光盘 → 磁盘/全闪/混闪存储 |
| 组网方式 | IP组网(以太网)、FC组网(光纤)、IB组网(无线带宽) |
| 存储类型和协议 | 文件存储、块存储、对象存储 |
| 存储架构 | 集中式存储（含存储集群）、分布式存储 |
| 连接方式 | **DAS**（直连）、**NAS**（网络接入）、**SAN**（存储区域网络） |

#### 二、DAS / NAS / SAN 对比

| 维度 | DAS | NAS | SAN |
|------|-----|-----|-----|
| 安装难易度 | 不一定 | 简单 | 困难 |
| 传输协议 | SCSI/FC/ATA | TCP/IP | FC |
| 传输对象 | 数据块 | 文件 | 数据块 |
| 文件共享 | 否 | 是(NFS/CIFS) | 需转换设备 |
| 灾难忍受度 | 低 | 高 | 高（专有方案） |
| 适合对象 | 中小组织、捆绑磁盘 | 文件共享、SOHO | 大型组织、数据中心 |

#### 三、数据结构模型

| 模型 | 特点 |
|------|------|
| **层次模型** | 最早使用，树结构，一对多父子联系，只能处理一对多实体联系 |
| **网状模型** | 有向图结构，突破非树状限制，多双亲节点 |
| **关系模型** | 二维表格表示实体及联系，基于集合论的关系概念 |

#### 四、关系型 vs 非关系型数据库

| 数据库类型 | 优点 | 缺点 |
|------------|------|------|
| **关系型(SQL)** | 容易理解（二维表）、使用方便（通用SQL）、易于维护（完整约束降低冗余） | 大数据高并发下读写性能不足、固定表结构扩展困难、多表关联查询性能欠佳 |
| **非关系型(NoSQL)** | 高并发读写强、基本支持分布式易扩展、弱结构化存储简单 | 事务支持弱、通用性差、无完整约束 |

**NoSQL四类**：

| 类型 | 特点 |
|------|------|
| 键值数据库 | 类似哈希表，通过key访问；简单、易部署、高并发 |
| 列存储数据库 | 数据存储在列族中；用于分布式存储海量数据 |
| 面向文档数据库 | 键值升级版，允许嵌套键值；效率更高 |
| 图形数据库 | 实体为顶点、关系为边 |

**ACID原则**：原子性(Atomicity)、一致性(Consistency)、隔离性(Isolation)、持久性(Durability)

#### 五、数据仓库

**定义**：面向主题的、集成的、非易失的、随时间变化的数据集合，用于支持管理决策。

**四层体系结构**：

| 层次 | 说明 |
|------|------|
| 数据源 | 内部信息（业务数据）+ 外部信息（法规、市场、竞争对手） |
| 数据存储与管理 | 核心层，按主题组织数据；分企业级/部门级（数据集市） |
| OLAP服务器 | 多角度多层次分析：ROLAP / MOLAP / HOLAP |
| 前端工具 | 查询、报表、分析、数据挖掘工具 |

### 1.2.4 信息安全

#### 一、信息安全五大基本属性

| 属性 | 含义 |
|------|------|
| **保密性** | 保证信息为授权者享用而不泄露给未授权者 |
| **完整性** | 保证信息传送过程中不被非法添加、删除、替换 |
| **可用性** | 保证信息和信息系统随时为授权者提供服务 |
| **可控性** | 保证管理者能对信息实施必要的控制管理 |
| **不可否认性** | 提供保证社会依法管理需要的公证、仲裁信息证据 |

信息安全四个层次：**设备安全 → 数据安全 → 内容安全 → 行为安全**

#### 二、信息安全七大技术和措施

| 技术/措施 | 核心要点 |
|-----------|----------|
| **身份认证** | 确认操作者身份；手段：虚拟身份电子标识、静态密码、智能卡、短信密码、动态口令、USB Key、PKI、生物识别、虹膜认证 |
| **访问控制** | 防止未授权访问；机制：自主访问控制、基于角色、基于规则、强制访问控制 |
| **入侵检测系统** | 监视网络/系统运行状况，发现攻击企图/行为/结果；分为实时和事后 |
| **防火墙** | 内部网与外部网之间的安全网关；四个部分：服务访问规则、验证工具、包过滤、应用网关 |
| **网闸** | 固态开关读写介质隔离两个独立主机系统，无协议摆渡，从逻辑上阻断攻击连接 |
| **防病毒** | 准则：拒绝访问、检测、控制传播、清除、恢复、替代操作 |
| **数据加密** | 对称加密（DES，密钥相同）/ 非对称加密（RSA，公钥加密私钥解密） |

#### 三、用户与实体行为分析（UEBA）

提供用户画像及基于各种分析方法的异常检测。从架构看包括**数据获取层、算法分析层、场景应用层**。

#### 四、网络安全态势感知

基于安全大数据，进行数据整合、特征提取，应用态势评估/预测算法，使用可视化技术展示。

**四大关键技术**：

| 技术 | 要点 |
|------|------|
| 海量多元异构数据汇聚融合 | PB级数据采集汇聚、多维度深度融合、统一存储管理 |
| 多类型网络安全威胁评估 | 从流量、域名、报文、恶意代码入手，多层次检测和跟踪分析 |
| 态势评估与决策支撑 | 以安全事件监测为驱动，形成多维安全事件知识图谱（人/物/地/事/关系） |
| 态势可视化 | 数据转化→图像映射→视图变换 |

### 1.2.5 信息技术发展趋势

| 领域 | 发展趋势 |
|------|----------|

## 1.3 新一代信息技术及其发展

> 物联网、区块链、云计算、大数据、人工智能、边缘计算、数字孪生

### 1.3.1 物联网（IoT）

#### 一、定义

通过信息传感设备，按约定的协议将任何物品与互联网相连接，进行信息交换和通信，以实现**智能化识别、定位、跟踪、监控和管理**的网络。解决T2T、H2T、H2H之间的互连。

#### 二、特点

**本质特点（3个）：**

| 特点 | 含义 |
|------|------|
| 互联 | 联网的"物"能实现互联互通 |
| 识别与通信 | 具备M2M（物与物）自动识别通信功能 |
| 智能化 | 自动化、自我反馈与智能控制 |

**产业特点（6个）：** 感知识别普适化、异构设备互联化、联网终端规模化、管理调控智能化、应用服务链条化、经济发展跨越化

#### 三、三层架构

| 层次 | 组成 | 功能 |
|------|------|------|
| **感知层** | 传感器、二维码、RFID、摄像头、GPS | 识别物体、采集信息 |
| **网络层** | 互联网、广电网、网络管理系统、云计算平台 | 传递和处理信息（中枢） |
| **应用层** | 与行业需求结合 | 物联网智能应用 |

#### 四、关键技术

| 关键技术 | 要点 |
|----------|------|
| **传感器技术** | RFID（射频识别）：无线电信号识别特定目标，标签+阅读器，赋予物联网"可跟踪性" |
| **传感网（MEMS）** | 微机电系统：微传感器+微执行器+信号处理+通信接口+电源一体化微型器件 |
| **应用系统框架** | 以机器终端智能交互为核心，涉及机器、传感器硬件、通信网络、中间件、应用5部分 |

#### 五、应用领域

**六大应用**：智能家居、智慧城市、工业自动化、医疗健康、农业智能化、物流追踪、能源管理

### 1.3.2 区块链

#### 一、定义

- **狭义**：一种按时间顺序将数据区块以顺序相连方式组合的链式数据结构，以密码学方式保证的不可篡改和不可伪造的**分布式账本**
- **广义**：利用块链式数据结构验证与存储数据、分布式节点共识算法生成更新数据、密码学保证安全、智能合约编程操作数据的**分布式基础架构与计算范式**

#### 二、七大特点

| 特点 | 说明 |
|------|------|
| 多中心化 | 纯数学方法建立去中心化可信分布式系统 |
| 多方维护 | 激励机制确保所有节点可参与验证 |
| 时序数据 | 时间戳信息实现数据可追溯性 |
| 智能合约 | 灵活可变的脚本代码支持新型合约 |
| 不可篡改 | 篡改需递归修改所有后序区块，代价巨大 |
| 开放共识 | 任意节点自由加入，拥有一份完整数据库拷贝 |
| 安全可信 | 非对称加密+共识算法算力抵御外部攻击 |

#### 三、关键技术

| 关键技术 | 要点 |
|----------|------|
| **分布式账本** | 交易记账由分布在不同地方的多个节点共同完成，每个节点保存唯一真实账本副本 |
| **加密算法** | 散列/哈希算法（SHA256等） + 非对称加密算法（RSA、ElGamal、ECC等） |
| **共识机制** | PoW、PoS、DPoS、Paxos、PBFT等；从合规监管、性能效率、资源消耗、容错性四个维度分析 |

#### 四、发展趋势

- 将成为互联网的基础协议之一（类似TCP/IP）
- 区块链架构不同分层将承载不同功能
- 应用发展呈螺旋式上升趋势，最终构建多样化生态的价值互联网

### 1.3.3 云计算

#### 一、定义

通过网络"云"将巨大的数据计算处理程序分解，通过多台服务器组成的系统处理分析后将结果返回用户。实现"**快速、按需、弹性**"的服务。

**三种服务类型**：

| 类型 | 全称 | 说明 |
|------|------|------|
| **IaaS** | 基础设施即服务 | 提供计算、存储、网络等基础资源 |
| **PaaS** | 平台即服务 | 提供应用开发和部署平台 |
| **SaaS** | 软件即服务 | 提供完整的软件应用 |

**部署方式**：公有云、私有云、混合云

#### 二、七大特征

| 特征 | 说明 |
|------|------|
| 超大规模 | 前所未有的计算能力 |
| 高可扩展性 | 动态伸缩，满足规模增长 |
| 虚拟化 | 资源来自"云"，非固定有形实体 |
| 高可靠性 | 数据保存在云上 |
| 通用性 | 同一"云"支撑不同应用 |
| 廉价性 | 廉价节点构成，低廉服务费用 |
| 灵活定制 | 按需定制服务、应用、资源 |

#### 三、关键技术

| 关键技术 | 要点 |
|----------|------|
| **虚拟化技术** | 单CPU模拟多CPU并行；容器技术属于操作系统级虚拟化 |
| **云存储技术** | 分布式文件系统为核心；解决网络存储、联合存储、负载均衡 |
| **多租户和访问控制** | 访问控制模型（基于任务/属性/UCon/BLP）、基于ABE密码机制、多租户隔离与虚拟机访问控制 |
| **云安全技术** | 云计算安全性、保障云基础设施安全、云安全技术服务 |

#### 四、发展趋势

四大趋势：**创新、垂直、混合、生态**

### 1.3.4 大数据

#### 一、定义

无法在一定时间范围内用常规软件工具进行捕捉、管理和处理的数据集合，是需要新处理模式才能具有更强决策力、洞察发现力和流程优化能力的海量、高增长率和多样化的信息资产。

#### 二、4V特征

| 特征 | 含义 |
|------|------|
| **规模性（Volume）** | 数据量巨大：GB→TB→PB→EB→ZB |
| **多样性（Variety）** | 结构化+非结构化（网志、音频、视频、图片、地理位置等） |
| **价值密度（Value）** | 整体价值高但单位价值稀疏，需"提纯" |
| **速度（Velocity）** | 处理速度快、时效性高，实时分析而非批量分析 |

#### 三、技术架构（四大技术）

| 技术领域 | 核心内容 |
|----------|----------|
| **大数据获取** | 数据采集（分布式爬取）+ 数据整合（多源多模态集成） + 数据清洗（清除错误修复数据） |
| **分布式数据处理** | Hadoop（离线复杂）、Spark（离线快速）、Storm（在线实时）；数据挖掘技术 |
| **大数据管理** | 存储（MPP架构+列存储/Hadoop衍生/大数据一体机）+ 多数据中心协同 + 安全隐私 |
| **大数据应用和服务** | 分析应用技术 + 可视化技术（文本/网络/时空/多维/交互可视化） |

#### 四、应用领域

互联网（社交营销、数据资产化）、政府公共数据（社会治理）、金融（征信）、工业（航运预测）、社会民生（疾病预测）

### 1.3.5 人工智能（AI）

#### 一、定义

利用计算机或计算机控制的机器来模拟、延伸和扩展人类的智能和感知环境的能力，获取知识并使用知识获得最佳结果的理论、方法、技术及应用系统。

#### 二、三大特点

1. **由人类设计，为人类服务** — 本质为计算，基础为数据
2. **能感知环境，能产生反应，能与人交互，能与人互补**
3. **有适应特性，有学习能力，有演化迭代，有连接扩展**

#### 三、十三项关键技术

| 序号 | 关键技术 | 核心要点 |
|------|----------|----------|
| 1 | **机器学习** | 自动将模型与数据匹配；神经网络→深度学习（多等级特征预测） |
| 2 | **自然语言处理(NLP)** | 人与计算机用自然语言有效通信；深度学习方法支撑；应用：机器翻译、语义理解、问答系统、语音识别 |
| 3 | **计算机视觉(CV)** | 模仿人类视觉系统，自动驾驶、机器人、智能医疗核心 |
| 4 | **知识图谱** | 结构化语义知识库，结点+边图数据结构；常用于反欺诈、搜索引擎 |
| 5 | **专家系统** | 六大部件（人机交互界面/知识库/推理机/解释器/综合数据库/知识获取）；模拟人类专家决策 |
| 6 | **人机交互(HCI)** | 传统交互+语音交互+情感交互+体感交互+脑机交互 |
| 7 | **机器思维** | 推理、搜索、规划 |
| 8 | **机器感知** | 机器视觉、模式识别、自然语言处理 |
| 9 | **机器行为** | 智能控制与智能制造 |
| 10 | **计算智能** | 神经计算、进化计算、模糊计算 |
| 11 | **分布智能** | 分布式问题求解 + 多代理系统 |
| 12 | **人工心理和人工情感** | 心理和情感影响认知与思维 |
| 13 | **大模型** | 百万到数十亿参数，深度神经网络构建；NLP/CV/推荐系统 |

#### 四、五大发展趋势

| 趋势 | 方向 |
|------|------|
| 从AI向人机混合智能发展 | 引入人的作用或认知模型 |
| 从"人工+智能"向自主智能发展 | 减少人工干预，提高自主学习 |
| 加速与其他学科交叉渗透 | 与计算机科学、数学、认知科学、神经科学等融合 |
| AI产业蓬勃发展 | "人工智能+X"创新模式 |
| AI社会学提上议程 | 法律法规、规避风险、造福于民 |

### 1.3.6 边缘计算

#### 一、定义

在靠近物或数据源头的网络边缘侧，融合网络、计算、存储、应用核心能力的**开放平台**，就近提供边缘计算服务。可作为连接物理世界和数字世界的桥梁。

#### 二、四大特点

| 特点 | 说明 |
|------|------|
| **联接性** | 基础能力，丰富的网络接口、协议、拓扑 |
| **数据第一入口** | 拥有大量、实时、完整数据；支持预测性维护等创新应用 |
| **约束性** | 适配工业现场恶劣环境（防电磁、防尘、防爆、抗振动） |
| **分布性** | 天然分布式；支持分布式计算存储、动态调度、统一管理 |

#### 三、关键技术

| 关键技术 | 要点 |
|----------|------|
| **边云协同** | 边缘计算与云计算互补协同；涉及IaaS/PaaS/SaaS全面协同（资源/数据/智能/应用管理/业务管理/服务） |
| **边缘安全** | CROSS价值模型；四大价值：可信基础设施、可信安全服务、安全接入和协议转换、安全可信网络覆盖 |

#### 四、应用场景

**智慧园区**（连接管理+数据采集处理+本地自治）、**视频监控**（边缘图像识别+智能存储+边云协同）、**工业物联网**（OPC UA over TSN+虚拟化PLC+质量缺陷检测+边缘安全）

### 1.3.7 数字孪生

#### 一、定义

现有或将来物理实体对象的数字模型，通过实测、仿真和数据分析来实时感知、诊断和预测物理实体对象的状态，通过优化和指令来调控物理实体对象的行为，通过相关数字模型间相互学习来进化自身，同时改进利益相关方在物理实体对象生命周期内的决策。

#### 二、关键技术

| 核心技术 | 要点 |
|----------|------|
| **建模** | 数字化模型化，消除不确定性；三维视角：需求指标×生存期阶段×空间尺度 |
| **仿真** | 验证和确认模型正确性和有效性；将确定性规律和完整机理的模型转化为软件 |
| **数字线程** | 支持多视图模型间协同 |
| **MBSE** | 基于模型的系统工程，顶层框架技术 |
| **其他** | VR/AR/MR、物联网（底层伴生）、云计算/机器学习/大数据/区块链（外围使能） |

#### 三、四大典型应用领域

| 领域 | 核心应用 |
|------|----------|
| **制造** | 设计阶段（数字模型设计+模拟仿真）、制造阶段（数字生产线+共智+敏捷/柔性制造） |
| **产业链** | 市场营销/电子商务、供应链/物流、产品使用/维保服务 |
| **城市** | 数字孪生城市，传感监控即时性、信息集成性、交互性、决策科学性、管理智能性、服务便捷性 |
| **战争** | 单体装备应用（研发/维护）+ 战场综合应用（战略/战役/战术三层次） |

#### 四、发展四阶段

| 阶段 | 时间 | 特征 |
|------|------|------|
| 技术准备期 | 1960—21世纪初 | CAD/CAE建模仿真、传统系统工程 |
| 概念产生期 | 2002—2010 | 数字孪生模型和英文术语确定 |
| 领先应用期 | 2010—2020 | NASA/军方/GE领先应用；IoT/AI/区块链等使能技术准备 |
| 深度开发扩展期 | 2020—2030 | 与技术深度融合，从智能制造向智慧城市等领域拓展 |

### 1.3.8 新一代信息技术发展总结

#### 一、国家战略

新一代信息技术产业位列国家九大战略性新兴产业**首位**。"新基建"七大领域：5G基建、特高压、城际高铁和轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网。

#### 二、新基建三类基础设施

| 类型 | 内容 |
|------|------|
| **信息基础设施** | 通信网络（5G/物联网/工业互联网/卫星互联网）、新技术（AI/云计算/区块链）、算力（数据中心/智能计算中心） |
| **融合基础设施** | 传统基础设施转型升级 |
| **创新基础设施** | 支撑科学研究、技术开发、产品研制 |

#### 三、发展趋势总结

> **创新、智能、跨界、融合**

新一代信息技术各领域已相互融合，实际应用中通常综合运用，相辅相成。例如：物联网完成大数据采集 → 大数据拥抱云计算 → 基于大数据云的人工智能。
