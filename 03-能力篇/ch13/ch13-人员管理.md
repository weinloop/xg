# 第13章 人员管理

> 人员管理是信息系统规划与管理的核心能力之一，涵盖人力资源管理的全生命周期。

---

## 13.1 人力资源管理基础

### 人力资源管理目标

**广义目标**：充分利用组织中的人员使组织的各项工作效率水平达到最高。

**狭义目标**：帮助各团队负责人更加有效地管理团队成员。

**四大具体目标**：
1. 建立员工招聘和选择体系，获得最符合组织需要的员工
2. 充分挖掘每个员工的潜能，服务组织发展同时满足员工事业发展需求
3. 留住高绩效员工，淘汰无法满足组织发展需要的员工
4. 确保组织遵守政府关于人力资源方面的法律、法规、政策和标准

### 人力资源管理五大内容

| 内容 | 说明 |
|------|------|
| 规划 | 确认工作要求，确定人员容量与技术需求，进行工作分析与岗位设计 |
| 招聘 | 根据工作需要确定最合适人选，从申请人中选拔符合需要的员工 |
| 维护 | 维护员工积极性，管理工资薪金，通过绩效福利等措施激励员工 |
| 提升 | 提高员工知识技能和经验，包括培训指导和骨干人才培养 |
| 评价 | 对员工工作结果和表现进行观察、测量和评估 |

**速记口诀：规招维提评，五环全覆盖**

---

## 13.2 工作分析与岗位设计

### 13.2.1 工作分析

**工作分析目的**：明确所要完成的任务以及完成这些任务所需要的人的能力特征。

**工作分析四大作用**：

| 作用领域 | 具体内容 |
|----------|----------|
| 招聘和选择员工 | 人力资源计划、识别人才招聘、选择安置、公平就业、工作概览 |
| 发展和评价员工 | 工作培训和技能发展、角色定位、员工发展计划 |
| 薪酬政策 | 确定工作薪酬标准、确保同工同酬、确保工作薪酬差距公正 |
| 组织与岗位设计 | 高效率和优化激励、明确权责关系、明确工作群之间的内在联系 |

**工作分析过程（4阶段10步骤）**：

| 阶段 | 步骤 |
|------|------|
| 第一阶段：明确范围 | 1.确立目的 2.确定对象 3.确定信息类型 |
| 第二阶段：确定方法 | 4.识别信息来源 5.明确具体步骤 |
| 第三阶段：信息收集分析 | 6.收集工作信息 7.分析所收集信息 8.向组织报告结果 |
| 第四阶段：评价方法 | 9.定期检查 10.以收益成本合规性评价结果 |

**收集信息的三种人员**：
- **工作分析专家** — 最客观公正、方法科学，但成本较高
- **主管人员** — 全面深入了解、速度快，但需培训且时间负担重
- **典型任职者** — 最熟悉工作、速度快，但标准化程度差

**工作说明书**：包括工作描述和工作规范两个方面
- **工作描述**：工作设定（称谓/角色/部门/地点）、工作定义（目的/绩效标准）、工作说明（职责/任务/条件）
- **工作规范**：教育、经验和其他特征的最低要求（非理想形象）

**工作分析方法**：

| 类别 | 方法 | 特点 |
|------|------|------|
| 定性 | 工作实践法 | 亲自从事，适用于短期内可掌握的工作 |
| 定性 | 直接观察法 | 适用于身体活动为主的工作，不适用于脑力劳动 |
| 定性 | 面谈法 | 简单迅速，但容易失真，不应作为唯一方法 |
| 定性 | 问卷法 | 节省时间人力，可大样本，但设计成本高 |
| 定性 | 典型事例法 | 揭示动态性质，但收集归纳耗时 |
| 定量 | 职位分析问卷法(PAQ) | 麦考密克1972年提出，6部分6分制，时间成本高 |
| 定量 | 管理岗位描述问卷法 | 托诺和平托1976年提出，208个问题13个类别 |
| 定量 | 功能性工作分析法 | 依据数据、人和事三项要素关系评估 |

**速记口诀：四阶十步三人员，定质定量五三法**

### 13.2.2 岗位设计

**岗位设计三大内容**：

1. **工作内容设计**（重点）：
   - 工作广度（多样性）
   - 工作深度（层次挑战性）
   - 工作完整性（成就感）
   - 工作自主性（责任感）
   - 工作反馈性（同事+工作本身反馈）

2. **工作职责设计**：责任、权利、方法、相互沟通（垂直/平行/斜向）

3. **工作关系设计**：协作关系、监督关系

**岗位设计四种方法**：

| 方法 | 提出者 | 核心思想 |
|------|--------|----------|
| 传统科学管理方法 | 泰勒 | 职能专业化，"时间-动作"研究，简单化标准化 |
| 人际关系方法 | — | 增加管理成分，工作扩大化/轮调/丰富化 |
| 工作特征模型 | 赫茨伯格 | 五大核心维度→三种心理状态→个人和工作结果 |
| 高绩效工作体系 | — | 科学管理+人际关系结合，工作小组自主决定 |

**工作特征模型五大核心维度**：技能多样性、任务完整性、工作任务意义、任务自主性、反馈

**工作丰富化五措施**：组成自然工作群体、实行任务合并、建立客户关系、让员工规划控制工作、畅通反馈渠道

**速记口诀：内容职责关系三，科学人际特征高**

## 13.3 人力资源战略与计划

### 13.3.1 人力资源战略

**战略性人力资源管理**：有效运用人力资源去实现组织的战略性要求和目标，强调整合适应性。

**两大组成部分**：
- **人力资源战略** — 人力资源在组织目标实现中产生何种作用
- **人力资源管理系统** — 具体如何实现选人、育人、用人和留人

**两种战略模式分类**：

**戴尔和霍德分类（3种）**：

| 战略 | 特点 |
|------|------|
| 诱因战略 | 控制劳工成本、明确工作职责、富有竞争力薪酬、薪酬与绩效密切联系、员工关系简单 |
| 投资战略 | 强调人力资源投资、人才储备、广泛工作职责、注重劳资关系和宽松环境 |
| 参与战略 | 鼓励参与管理决策、管理人员是指导教练、注重自我管理和团队建设 |

**巴伦和克雷普斯分类（3种）**：

| 战略 | 特点 |
|------|------|
| 内部劳动力市场战略 | 层级分明、内部招聘、工作保障和发展机会 |
| 高承诺战略 | 扁平化结构、团队合作、保证一定流动率、工作成果差别薪酬 |
| 混合战略 | 介于两者之间，既有工作保障和内部晋升，也有成果导向薪酬 |

**速记口诀：诱因投资参与，内部高承混合**

### 13.3.2 人力资源预测

**人力资源需求预测**（3种方法）：
- **集体预测方法（德尔菲法）** — 专家匿名问卷，多轮反馈，适合长期趋势
- **回归分析方法** — 趋势分析（简单）和计量模型分析（复杂）
- **转换比率分析法** — 先估计关键技能员工数量，再估计辅助人员

**人力资源供给预测**（6种方法）：
- **人才盘点与技能清单** — 全面人才评价，形成人才地图
- **管理人员置换图** — 记录绩效、晋升可能性、所需培训
- **人力接续计划** — 确定达到工作要求的候选员工
- **转移矩阵法（马尔可夫方法）** — 转移率固定比例，预测人员分布
- **人力资源信息系统** — 收集保存分析人事信息
- **外部人力资源供给** — 了解外部潜在员工数量能力

**速记口诀：需求德尔回归转，供给盘点置换接续转移系统外部**

### 13.3.3 人力资源计划控制与评价

**供需对照三种结果**：需求=供给（适应）、需求>供给（短缺）、需求<供给（过剩）

**短缺解决方法**：①增加录用数量 ②提高员工效率或延长工作时间

**过剩解决策略**：减少加班、鼓励提前退休、减少新进员工、辞退

**整体性人力资源计划三部分**：供给报表、需求报表、人力报表

**速记口诀：供需三果，短缺增录提效，过剩减加退裁**

## 13.4 人员招聘与录用

### 13.4.1 招聘过程

**五个环节**：招聘计划制订 → 招聘信息发布 → 应聘者申请 → 人员遴选与录用 → 招聘评估与反馈

### 13.4.2 招聘渠道（8种）

| 渠道 | 特点 |
|------|------|
| 内部来源 | 发布信息公告，让现有员工有机会对比 |
| 招聘广告 | 信息发布迅速、成本较低、可同时发布多种岗位 |
| 职业介绍机构 | 节省时间，适合无人事部门或急需填补空缺 |
| 猎头组织 | 搜捕推荐高级管理人员和高级技术人员 |
| 校园招聘 | 专业技术人员重要来源，需选派强工作人员 |
| 员工推荐与自荐 | 节省费用，得到忠诚可靠员工 |
| 网络招聘 | 自建网站/第三方网站/社交媒体三种方式 |
| 临时性雇员 | 内部储备/中介临时/自由职业者/短期雇用4种选择 |

### 13.4.3 录用方法

**三大筛选方法**：背景调查、录用测试、建立录用标准

**录用测试8种类型**：能力测试、操作与身体技能测试、人格与兴趣测试、成就测试、工作样本法、测谎器法、笔迹判定法、体检

**录用标准三原则**：
- **补偿性原则** — 成绩高的项目补偿成绩低的项目，设置不同权重
- **多元最低限制原则** — 每个方面都须达到最低标准，低成本测试先安排
- **混合原则** — 先多元最低限制淘汰，再补偿性综合评价

### 13.4.4 招聘面试

**面试程序三阶段**：面试前准备 → 实施面试 → 评估面试结果

**面试三种类型**：
- **非结构化面试** — 完全任意讨论，可即兴提问
- **半结构化面试** — 提前准备重要问题但不要求固定次序
- **结构化面试** — 提前准备好问题和答案，迅速做出结论

### 13.4.5 招聘效果评估

**五个评估维度**：
1. 招聘周期 — 完成一个职位招聘所需时间
2. 用人部门满意度 — 用人部门领导对所招新员工的满意程度
3. 招聘成功率 — 实际上岗人数和面试人数的比例
4. 招聘达成率 — 实际上岗人数与计划招聘人数的比例
5. 招聘成本 — 显性成本+隐性成本

**速记口诀：五环八渠三筛选，周期满意度成功达成成本**

## 13.5 人员培训

### 13.5.1 培训程序与培训类型

**培训四步骤**：评估需求 → 设定目标 → 设计项目 → 实施和评估

**培训两大类型**：
- **入职培训** — 消除新进焦虑，适应环境和形势
- **员工在职培训** — 提升工作绩效，节约成本，学习效果明显

### 13.5.2 培训内容与需求评估

**培训内容三方面分析**：
- **组织分析** — 确定组织范围内的培训需求，符合整体目标与战略
- **绩效分析** — 考察实际绩效与目标绩效的偏离，决定是否可通过培训矫正
- **任务分析** — 分析达到理想绩效必须掌握的技能和能力

**两种需求评估模型**：
- **循环评估模型** — 组织层面→作业层面→员工个人层面，连续反馈
- **前瞻性培训需求分析模型** — 为工作调动/职位晋升/工作变化做准备

### 13.5.3 培训效果评估与迁移

**培训效果四层面评估**：

| 层面 | 内容 | 评估方法 |
|------|------|----------|
| 反应 | 受训者对培训项目的反应 | 问卷调查 |
| 学习效果 | 对培训内容的掌握程度 | 考试或实际操作测试 |
| 行为变化 | 与工作有关的能力变化 | 控制组方法对比 |
| 培训效果 | 对组织结果是否有积极影响 | 工作效率/质量/离职率/风险事件 |

**培训迁移过程模型**（鲍德温和福特1988年提出）：
- **培训输入**：受训者特征（能力/个性/动机）、培训设计（学习环境）、工作环境
- **影响**：学习→保存→迁移
- **促进迁移的工作环境特征**：直接主管鼓励、任务线索、反馈结果、不轻易惩罚、外部强化、内部强化

**速记口诀：四步两类型，组织绩效任务，反应学习行为效果**

## 13.6 组织绩效与薪酬管理

### 13.6.1 组织绩效管理

**绩效管理四环节**（循环系统）：

| 环节 | 活动 | 时间 |
|------|------|------|
| 绩效计划 | 与员工一起确定绩效目标和行动计划 | 新绩效周期开始时 |
| 绩效实施与监控 | 观察、记录、总结绩效，提供反馈和指导 | 整个绩效期间 |
| 绩效考核 | 考核员工的绩效 | 绩效周期结束时 |
| 绩效反馈面谈 | 就考核结果与员工讨论 | 绩效周期结束时 |

**绩效考核五大方法**：

| 方法 | 特点 | 成本 | 适合奖金分配 |
|------|------|------|-------------|
| 员工比较类评价法 | 简单排序/成对比较/强制分布 | 设计应用成本低 | 作用有限 |
| 关键事件法 | 记录特别有效/无效行为 | 设计成本低，应用成本高 | 不适合 |
| 行为对照表法 | 对照描述行为表格 | 设计成本高，执行成本小 | 较好 |
| 等级鉴定法 | 列出几种行为供选择 | 成本低 | 作用有限 |
| 行为锚定评价法 | 定义评价项目+关键事件描述 | 设计成本高，应用成本低 | 适合 |

**绩效反馈面谈四目的**：①达成共识 ②认识进步和缺点 ③制订改进计划 ④修订下一周期目标

**绩效改进三步骤**：①分析考核结果找出问题 ②制定改进方案 ③实施改进方案提供帮助

**速记口诀：计划监控考核反馈，比较关键对照等级锚定**

### 13.6.2 组织薪酬管理

**薪酬体系公平性要求**：外部公平性（竞争力）+ 内部公平性（一致性）

**薪酬构成**：
- **外在薪酬**（重点）：
  - 直接报酬：基本薪酬、绩效加酬、激励性报酬、延期支付
  - 间接报酬：福利保障、带薪休假、服务与津贴
- **内在薪酬**：工作保障、身份标识、挑战性工作、晋升空间、承认、培训机会、弹性工作时间

**三种薪酬体系**：
- **基于职位的薪酬体系**（最常见）— 依据工作自身价值
- **基于技能的薪酬体系** — 依据员工掌握的技能水平
- **基于能力的薪酬体系** — 依据员工具备的能力水平

**工作评价五种方法**：

| 方法 | 量化 | 比较标准 |
|------|------|----------|
| 工作排序法 | 非量化 | 工作间比较 |
| 工作分类法 | 非量化 | 与既定标准比较 |
| 因素比较法 | 量化 | 工作间比较 |
| 点数法 | 量化 | 与既定标准比较 |
| 海氏系统法 | 量化 | 与既定标准比较 |

**薪酬等级结构五要素**：薪酬等级数、目标薪酬（中点）、薪酬级差、薪酬幅度、薪酬重叠情况

**薪酬激励（按员工类别）**：
- **操作人员** — 计件制（完全计件制/部分计件制）
- **销售业务人员** — 佣金制/底薪制/混合制
- **专业技术人员** — 加薪（年资自动增加），非金钱奖励
- **高级管理人员** — 基本薪酬+短期奖励+长期激励（股票）+福利+特殊津贴

**薪酬调整**：
- 水平调整：主动型/被动型；奖励性/生活指数性/年资性/效益性
- 结构调整：纵向等级结构（增加/减少等级）；横向薪酬构成（固定与变动比例/组合模式）

**速记口诀：外公内一，职位技能能力，排序分类因素点数海氏**

## 13.7 人员职业规划与管理

**职业道路四要求**：①代表真实可能性 ②具有尝试性 ③具有灵活性 ④说明职位要求的技能知识

**职业道路确定步骤**：工作分析→找出相同点和不同点→组合成工作族→找出职业道路→连接成完整职业系统

**管理人员四项工作**：①充当催化剂鼓励建立职业规划 ②评估发展目标现实性 ③辅导做出行动方案 ④跟踪并指导调整

**组织在职业规划中的责任**：提供模型/信息/条件/指导；提供培训；提供技能培训和在职培训

**速记口诀：真试灵活说明，分析组合族道系统**
